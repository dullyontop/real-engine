# RE6014: Malformed mesh data

Mesh data cannot be uploaded: an index points past the last vertex, the
index count is not a multiple of three, a vertex has a NaN or infinite value, or
the mesh is larger than a GPU buffer may be.

An empty mesh (no vertices and no indices) is accepted and draws nothing.

## Example

```text
error[RE6014]: index 5 is 12, but the mesh has 12 vertices
```

## How to fix it

Fix the generator or importer that produced the mesh. `MeshData::is_well_formed`
checks the indices before upload.
