# RE6015: Malformed texture data

Texture data cannot be uploaded: its width or height is zero or larger than
the GPU allows, or its bytes do not fit its format.

- RGBA8 (`Rgba8Srgb`, `Rgba8Unorm`): `pixels` is `width * height * 4` bytes
  and `levels` is empty, because the renderer makes the mip chain.
- Block-compressed (`Bc7Srgb`, `Bc7Unorm`, `Bc5Unorm`, ADR-0047): the width and
  height are multiples of 4, `pixels` is the top level and `levels` holds every
  level below it down to 1x1. Each level is 16 bytes per 4x4 block, and a level
  smaller than a block takes one whole block.

## Example

```text
error[RE6015]: a 64x64 RGBA8 texture needs 16384 bytes of pixels, not 12288
error[RE6015]: a 64x64 Bc7Srgb texture needs 6 mip levels below the top one, not 0
```

## How to fix it

Decode images to RGBA8 (RGB images need an alpha channel added).
Block-compressed textures come from the asset importer (`[assets]
texture_compression = "bc"` in `real.toml`), which writes the whole chain; data
made any other way must carry it too. `TextureData::is_well_formed` checks the
sizes.
