# RE6015: Malformed texture data

Texture data cannot be uploaded: its width or height is zero or larger than
the GPU allows, or its pixel buffer is not `width * height * 4` bytes of RGBA8.

## Example

```text
error[RE6015]: a 64x64 RGBA8 texture needs 16384 bytes of pixels, not 12288
```

## How to fix it

Decode images to RGBA8 (RGB images need an alpha channel added).
`TextureData::is_well_formed` checks the buffer length.
