# RE6005: Invalid render target

A render target, capture or UI frame cannot be used:

- a capture of size zero or larger than the GPU allows;
- a capture format other than RGBA8 or BGRA8;
- a texture view without `RENDER_ATTACHMENT` usage, a multisampled or non-2D
  texture, or a format the adapter cannot render to;
- a UI frame tessellated for a different size than the view it is painted into,
  or a non-positive `pixels_per_point`.

## Example

```text
error[RE6005]: the UI frame is 1280x720 pixels but the target is 640x360
  = hint: tessellate the UI for the size of the view it is painted into
```

## How to fix it

Create the target with `Capture::new` (or configure the surface with
`Gpu::surface_config`), and build each `UiFrame` for the size of the view it is
painted into.
