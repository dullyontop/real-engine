# RE6016: Invalid material values

A material has a NaN or infinite value in its base colour, emissive colour,
emissive strength, metallic, roughness or alpha cutoff.

## Example

```text
error[RE6016]: the material has a non-finite value (NaN or infinity)
```

## How to fix it

Check the material file or the script that built the material. Metallic and
roughness are clamped to `[0, 1]` when drawing, so only non-finite values are
rejected.
