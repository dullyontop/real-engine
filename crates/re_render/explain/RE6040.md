# RE6040: GPU skinning unsupported

The adapter cannot read storage buffers from vertex shaders (wgpu's
`DownlevelFlags::VERTEX_STORAGE` is missing, as on some GL ES and WebGL
drivers), so the renderer cannot pose skinned meshes. Skinned items are still
drawn, in their bind pose: the mesh as it was modelled.

## Example

```text
warning[RE6040]: this adapter cannot read storage buffers in vertex shaders; skinned meshes are drawn in their bind pose
```

## How to fix it

Run on a backend that supports vertex storage: Vulkan, Metal, DirectX 12, or
desktop GL 4.3 or later. The warning is given once per renderer.
