# RE6033: Project replaces an engine shader

A file in the project's `shaders/` folder has the name of one of the engine's
own shader files, so it replaces that file. This is a tool for working on the
engine's shaders, not a stable way to customise rendering: the engine's files
can change in any release, and a replaced file then stops matching the rest.
`real verify` and `real build` warn about each such file; the game still runs
with it.

## Example

```text
warning[RE6033]: `shaders/forward.wgsl` replaces the engine's `forward.wgsl`
  --> shaders/forward.wgsl
  = hint: the engine's shader files can change in any release; remove the file once the change is in the engine, or rename it if it is a new file to include
```

## How to fix it

Remove the file once the change is in the engine, or rename it if it is meant
as a new file for other shaders to include. `real explain RE6031` covers
compile errors in such files.
