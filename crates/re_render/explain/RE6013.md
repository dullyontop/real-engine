# RE6013: Material texture not uploaded

A material given to the renderer still names a texture by its asset id
(`TextureRef::Asset`) instead of an uploaded texture (`TextureRef::Handle`). The
renderer cannot load assets: the runtime uploads each texture and replaces the
reference first.

## Example

```text
error[RE6013]: the material names the texture asset `textures/rock.png`, not an uploaded texture
```

## How to fix it

Upload the texture with `Renderer::upload_texture`, replace the reference with
`TextureRef::Handle(handle)`, then call `Renderer::create_material`.
`MaterialDesc::is_resolved` tells whether a material is ready.
