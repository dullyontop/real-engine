# RE6006: Unknown backend in RE_BACKENDS

The `RE_BACKENDS` environment variable names a backend the renderer does
not know.

## Example

```text
error[RE6006]: unknown backend `vulcan` in RE_BACKENDS
  = hint: use vulkan, gl, metal, dx12, primary or all
```

## How to fix it

Set `RE_BACKENDS` to one of `vulkan`, `gl`, `metal`, `dx12`, `primary` (the native
API of the platform, the default) or `all`, or unset it.
