# RE6022: Image file could not be read

A PNG file could not be read or decoded, or it is not an 8-bit RGB or RGBA
image.

## Example

```text
error[RE6022]: could not read the PNG: No such file or directory (os error 2)
  --> crates/re_render/tests/goldens/vulkan/cube_grid.png
```

## How to fix it

Check the path. Golden images that are missing are created by running the tests
with `RE_UPDATE_GOLDENS=1`; review the new images before committing them.
