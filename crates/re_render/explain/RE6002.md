# RE6002: No GPU adapter

No GPU adapter matched the requested backends, so nothing can be drawn.

Real Engine needs a Vulkan, Metal, DX12 or GL driver. Machines without a GPU can
use Mesa's software drivers: lavapipe (Vulkan) or llvmpipe (GL).

## Example

```text
error[RE6002]: no GPU adapter for backends Backends(VULKAN): No suitable graphics adapter found
  = hint: install a Vulkan or GL driver (Mesa's lavapipe or llvmpipe work without a GPU), or choose other backends with RE_BACKENDS
```

## How to fix it

- Install a driver. On Debian or Ubuntu: `sudo apt-get install mesa-vulkan-drivers libegl-mesa0 libgl1-mesa-dri`.
- Or pick other backends: `RE_BACKENDS=gl`, `RE_BACKENDS=all`.
- `vulkaninfo --summary` shows which Vulkan drivers the system sees.
