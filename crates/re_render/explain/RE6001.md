# RE6001: Uncaptured GPU error

wgpu reported an error that no error scope caught: a validation error, an
out-of-memory error or an internal error. By default wgpu panics on such
errors; Real Engine logs them as this diagnostic and keeps running, so one bad
command does not end the session.

The draw or upload that caused it may be missing from the frame, and later
errors that mention an "invalid" object usually follow from the first one.

## Example

```text
error[RE6001]: GPU validation error: Validation Error

Caused by:
  In Device::create_buffer, label = 'invalid-usage'
    Usage flags BufferUsages(MAP_READ | UNIFORM) of Buffer with 'invalid-usage' label are invalid.
```

## How to fix it

This is a bug in the code that called wgpu, not in your project. Read the first
error of the burst: it names the wgpu call and the labelled object. Report it with
that message. In tests, `Gpu::errors()` returns the recent ones.
