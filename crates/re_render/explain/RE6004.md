# RE6004: The window surface could not be created

The renderer could not create a surface for the window, or the surface
offers no format for the chosen adapter.

Some drivers can only render offscreen. SwiftShader, for example, has no
`VK_KHR_xlib_surface`, so it cannot present to an X11 window.

## Example

```text
error[RE6004]: could not create a window surface: Failed to create surface for any enabled backend
```

## How to fix it

- Run with a driver that can present: a GPU driver, or Mesa's lavapipe or llvmpipe.
- On a machine without a display, run under a virtual X server: `xvfb-run -a <command>`.
- For tests and CI, render headless instead (`Gpu::headless`).
