# RE6031: Shader does not compile

A WGSL file given to the renderer at run time (a file in the project's
`shaders/` folder, or an engine shader being edited through
`RE_ENGINE_SHADERS`) makes a shader that naga cannot parse or validate, or the
file cannot be read as text. The message names the file and line of the first
error, which can be in a file the shader includes; the location is the file the
run read, such as `shaders/sky.wgsl`.

The shader's pipelines keep their last good version, so the frame keeps
drawing as it did before the edit until the file is fixed. `real verify` checks
the project's shader files in its compile stage, without a GPU, and `real build`
stops on the error.

## Example

```text
error[RE6031]: `sky.wgsl` line 12: expected expression, found ";"
  --> shaders/sky.wgsl:12:17
```

## How to fix it

Fix the line it names and save; a running game rebuilds the shader when the file
changes. A mistake in a file that several shaders include (such as
`common.wgsl`) is reported once, at that file.
