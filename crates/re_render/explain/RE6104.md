# RE6104: Stale instance set handle

An instance set handle was used after the set was released, or it was never
issued by this renderer.

Handles carry a generation: when a released slot is reused, old handles to it
stop matching, so they are detected instead of drawing the wrong placements. An
`InstanceSet` in a snapshot whose set handle is stale is skipped, counted in
`items_skipped` and reported once per frame as a warning; releasing a stale
handle is an error.

## Example

```text
warning[RE6104]: an instance set of entity 42 uses the instance set handle 3:1, which was released or never issued; the set is skipped
```

## How to fix it

Stop drawing a set once it is released, or upload it again with
`Renderer::upload_instance_set` and use the new handle. Handles from one
`Renderer` are not valid in another.
