# RE6010: Stale mesh handle

A mesh handle was used after the mesh was released, or it was never issued by
this renderer.

Handles carry a generation: when a released slot is reused, old handles to it
stop matching, so they are detected instead of drawing the wrong mesh. A draw
item with a stale handle is skipped and reported once per frame as a warning;
releasing a stale handle is an error.

## Example

```text
warning[RE6010]: a draw item of entity 42 uses the mesh handle 3:1, which was released or never issued; the item is skipped
```

## How to fix it

Stop drawing a mesh once it is released, or upload it again and use the new
handle. Handles from one `Renderer` are not valid in another.
