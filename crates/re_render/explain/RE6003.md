# RE6003: The GPU device could not be created

The adapter was found, but it refused to create a device with the limits
the renderer requests. The renderer asks for the WebGPU default limits, or the
downlevel defaults when the adapter does not meet them, so this usually means a
broken or very old driver.

## Example

```text
error[RE6003]: the adapter `llvmpipe (LLVM 20.1.2, 256 bits)` refused to create a device: Limit 'max_texture_dimension_2d' value 65536 is better than allowed 16384
```

## How to fix it

Update the GPU driver, or try another backend with `RE_BACKENDS` (for example
`gl` instead of `vulkan`).
