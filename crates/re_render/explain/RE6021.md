# RE6021: Image file could not be written

A PNG file could not be written: the directory could not be created, the
file could not be opened, or the pixel buffer does not match the image size.

## Example

```text
error[RE6021]: could not write the PNG: Permission denied (os error 13)
  --> out/frame.png
```

## How to fix it

Check that the directory is writable and that there is free disk space.
