# RE6030: Shader include error

A WGSL file of the renderer has an `#include` that names an unknown file,
forms a cycle, or is not written as `#include "file.wgsl"`.

## Example

```text
error[RE6030]: `#include` cycle: a.wgsl -> b.wgsl -> a.wgsl
```

## How to fix it

Each file is included at most once per shader, so shared declarations go in a
file that both includes name, never in each other. Include names must match the
names in `re_render::shader::SOURCES`.
