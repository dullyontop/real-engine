# RE6100: Malformed instance set

An instance set cannot be uploaded because its placements and clusters do not
describe a set the renderer can cull and draw (ADR-0052):

- it has no placements;
- a cluster holds no placements, or the clusters' counts do not add up to the
  placements;
- a placement's position or scale, or a cluster's bounds or largest scale, is
  not finite;
- a placement's rotation is zero (all four components 0);
- a placement lies outside its cluster's bounds, or its scale is larger (by
  magnitude) than the cluster's largest, so the cluster's box would not hold
  it and culling would drop it while it is still in view.

The placements are uploaded in cluster order: the first cluster holds the
first `count` placements, the next cluster the `count` after them, and so on.

## Example

```text
error[RE6100]: the 4 clusters hold 9998 placements, but the set has 10000
```

## How to fix it

Sort the placements by cluster and make each cluster with
`InstanceCluster::of` over its own placements, which gives the count, the
bounds and the largest scale that hold them. A placement with no rotation is
`Placement::new(position, Quat::IDENTITY, scale, id)`. Make no set where
nothing is placed.
