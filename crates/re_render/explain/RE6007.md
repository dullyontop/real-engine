# RE6007: Invalid camera

The snapshot's camera cannot be drawn from, so the frame was not drawn.

A camera needs a vertical field of view strictly between 0 and pi radians,
`0 < near < far` (all finite), and an invertible, finite transform.

## Example

```text
error[RE6007]: the camera cannot be drawn from: fov_y 1.0471976 rad, near 0, far 1000
  = hint: use a field of view between 0 and pi, 0 < near < far, and an invertible transform
```

## How to fix it

Check the `Camera` component of the active camera: a near distance of 0, a far
distance below the near one, or a scale of 0 in its transform are the usual
causes.
