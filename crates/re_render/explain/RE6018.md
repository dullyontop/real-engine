# RE6018: Too many highlights

A frame asks for more highlights than the renderer draws. It draws the first
31 highlights of the frame and leaves out the rest. An object in two
highlights shows the first one.

## Example

```text
warning[RE6018]: 40 highlights in the frame; only the first 31 are drawn
```

## How to fix it

Remove highlights that are not needed, or put the objects that should look the
same under one model and highlight that model once.
