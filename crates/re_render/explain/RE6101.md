# RE6101: Instance set too large

An instance set's placements take more bytes than the GPU allows in one buffer,
so the set cannot be uploaded. Each placement takes 32 bytes, so WebGL2's
256 MiB limit holds 8,388,608 placements; other backends allow more.

## Example

```text
error[RE6101]: the instance set's 9000000 placements take 288000000 bytes, more than this GPU's 268435456-byte buffer limit (8388608 placements)
```

## How to fix it

Split the placements into several sets, such as one set per streamed cell and
prefab, which is how procedural scatter makes them. A cell rarely needs more
than a few hundred thousand placements.
