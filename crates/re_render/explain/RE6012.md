# RE6012: Stale material handle

A material handle was used after the material was released, or it was never
issued by this renderer. A draw item with a stale material is skipped and
reported once per frame as a warning; releasing a stale handle is an error.

## Example

```text
warning[RE6012]: a draw item of entity 7 uses the material handle 5:0, which was released or never issued; the item is skipped
```

## How to fix it

Create the material again with `Renderer::create_material` and use the new
handle.
