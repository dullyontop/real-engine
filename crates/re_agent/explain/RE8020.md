# RE8020: Unknown template, recipe or parameter

`real new --template`, `recipe.apply` or a template's recipe list named a
template, recipe or parameter that does not exist, a required parameter has
no value, or a `{{name}}` marker in a template file names no parameter.

## Example

```text
error[RE8020]: unknown recipe `falling-bx` (did you mean `falling-box`?)
```

## How to fix it

Use the suggested name. `real new --list-templates` and the `template.list`
and `recipe.list` MCP tools list every template and recipe with its
parameters.
