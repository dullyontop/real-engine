# RE8027: Evaluation run failed

An evaluation run could not be set up or its files written. The message
names the step:

- copying the project into the output directory;
- starting `real mcp` on the copy;
- starting the agent's command;
- writing the transcript, `score.json` or `summary.json`.

## Example

```text
error[RE8027]: out/eval/starter/box/run-1 exists and is not a finished run; choose another --out
```

## How to fix it

Fix the cause the message gives. `real agent eval` replaces a run
directory only when it holds a finished run (`score.json`), so it never
deletes other files. Pick an empty `--out`, or delete the old results
yourself.
