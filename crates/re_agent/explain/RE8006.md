# RE8006: Invalid editor socket message

A line on the editor socket was not a valid message of the editor socket
protocol. Each request is one line of JSON:

```json
{"id": 1, "command": "entity.spawn", "args": {"name": "Rock"}, "dry_run": false}
```

or `{"id": 2, "list_specs": true}`. Each response is one line with the same
`id` and an `outcome` (or `specs`).

## Example

```text
error[RE8006]: invalid editor-socket request: expected value at line 1 column 1
```

## How to fix it

A client that writes to `.real/editor.sock` by hand must send exactly one JSON
object per line. If both ends are Real Engine tools, they are of different
versions: use the same `real` build for the editor and the command.
