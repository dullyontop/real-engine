# RE8018: Unknown name in the coverage table

`compat.coverage` was given a `name` that is not a class, enum or library in
the Roblox-style coverage table (`crates/re_compat/coverage.json`). Names are
exact and case-sensitive. Enums can be written with or without the `Enum.`
prefix.

## Example

```text
error[RE8018]: the coverage table has no class, enum or library "Prt" (did you mean "Part"?)
```

## How to fix it

Use the suggested name, or search instead:
`compat.coverage {"search": "part"}` lists every row whose key contains the
text. A name that is truly absent is not covered yet; the tier-2 gap report
(`real check --corpus`) counts such uses as `missing`.
