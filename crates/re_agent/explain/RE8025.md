# RE8025: Invalid evaluation task

`real agent eval SUITE` could not use a task in the suite directory. The
message names the file and the problem:

- the TOML does not parse;
- a key is unknown;
- the task has no checks, or a check sets no kind or more than one;
- `project = { example = "NAME" }` names no `examples/NAME` in any folder
  above the suite;
- the suite directory has no `*.toml` file.

## Example

```text
error[RE8025]: crates/re_agent/evals/starter/box.toml: a task needs at least one check
```

## How to fix it

Correct the task as the message says. `crates/re_agent/evals/README.md`
describes the format, and the built-in suites are examples of it.
