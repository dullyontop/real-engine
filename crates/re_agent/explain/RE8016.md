# RE8016: Luau tool changed the world directly

A Luau tool changed entities with the `world` library (`world.spawn`,
`entity:set`, `entity:destroy`) instead of through `command.run`. Those writes
would skip undo, dry runs and the agent policy, so the engine reverted them and
the call failed. Nothing changed.

## Example

```text
error[RE8016]: the tool level.ring changed the world directly; the change was reverted
  --> scripts/tools/commands/ring.luau
```

## How to fix it

Make every change with `command.run`, for example
`command.run("entity.spawn", { id = "marker_1" })` or one
`command.run("scene.apply", { ops = {...} })`. Reading the world directly is
fine. Everything a tool changes through `command.run` is one undoable step.
