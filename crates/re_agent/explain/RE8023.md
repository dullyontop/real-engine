# RE8023: Recipe step failed

A step of a recipe returned an error. With `atomic` (the default for
`recipe.apply`), the project is restored to the checkpoint taken before the
first step, so nothing the recipe did is kept. The step's own diagnostics
follow this one.

## Example

```text
error[RE8023]: step 1 (`entity.spawn`) failed
error[RE5012]: component `RigidBody` field `mass` must be positive
```

## How to fix it

Fix the cause the step's diagnostics name, usually a parameter value, and
apply the recipe again.
