# RE8017: Luau tool output

A note carrying one line that a Luau tool printed with `print` or `warn` while
it ran. It is not a problem; it is how a tool reports progress to whoever
called it.

## Example

```text
note[RE8017]: placed 12 markers
  --> scripts/tools/commands/ring.luau
```

## How to fix it

Nothing to fix. Remove the `print` call if the note is not wanted.
