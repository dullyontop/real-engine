# RE8009: Invalid agent policy

`.real/agent-policy.toml` could not be read or parsed.

## Example

```text
error[RE8009]: invalid agent policy: unknown variant `admin`, expected one of `read`, `edit`, `destructive`
  --> .real/agent-policy.toml
```

## How to fix it

The file has `max_tier` (`"read"`, `"edit"` or `"destructive"`), a `[scopes]`
table with `allow` and `deny` glob lists and a `[budgets]` table (`frames`,
`milliseconds`, `memory_mb`, `entities_per_transaction`). Fix the key the
message names, or delete the file and run `real agent init` again.
