# RE8005: Editor socket connection failed

A writer could not bind, connect to or keep its connection to the editor
socket, `.real/editor.sock`. This happens when the editor exits while a
command is in flight, when the socket file belongs to an editor that is no
longer running, or when the project path is too long for a Unix socket path
(about 100 bytes).

## Example

```text
error[RE8005]: could not connect to the editor socket: Connection refused (os error 111)
  --> .real/editor.sock
```

## How to fix it

- Check that the editor is still running for this project (`real editor`).
- If it was closed, run the command again: with no editor holding the lock, the
  command opens the project itself.
- If the path is too long, move the project to a shorter path.
