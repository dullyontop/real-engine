# RE8019: Invalid template or recipe

A template (`templates/<name>/template.toml`) or recipe
(`templates/recipes/<name>.toml`) could not be loaded. The message names the
file and the problem: TOML that does not parse, a `name` that differs from the
file or folder name, a parameter whose default does not fit its type, a
`render` entry with no matching file, a path that is absolute or contains
`..`, or a check that sets none or more than one of `verify`, `verify_stage`,
`command`, `diff_stage` and `no_regressions`.

It is also reported when `real new --template` cannot write a file.

## Example

```text
error[RE8019]: render lists `real.toml` but the template has no such file
  --> templates/native/template.toml
```

## How to fix it

Correct the file as the message says. `real new --list-templates` loads every
built-in template and recipe, so it shows the error again until it is fixed.
