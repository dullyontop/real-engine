# RE8004: Editor socket not available on this platform

Writers reach a running editor through a local socket, `.real/editor.sock`.
In M1 this is a Unix socket; the Windows version (a named pipe) is later work.

## Example

```text
error[RE8004]: the editor socket is not available on Windows in M1
  --> .real/editor.sock
```

## How to fix it

Close the editor and run the command again: when no editor holds the project
lock, `real do` and `real mcp` open the project themselves.
