# RE8004: Editor socket not available on this platform

Writers reach a running editor through a local socket, `.real/editor.sock`,
which is a Unix domain socket. This build of `real` has no editor socket on
Windows, so `real do` and `real mcp` cannot reach an editor that has the
project open there.

## Example

```text
error[RE8004]: this build of `real` has no editor socket on Windows
  --> .real/editor.sock
  = hint: close the editor and run the command again: without an editor it opens the project itself
```

## How to fix it

Close the editor and run the command again: when no editor holds the project
lock, `real do` and `real mcp` open the project themselves.
