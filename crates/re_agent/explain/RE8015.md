# RE8015: Invalid Luau tool

A script under `scripts/tools/commands/` did not load as a tool, so it was not
registered as a command. The other tools are still registered.

A tool script returns one table:

```luau
return {
    name = "level.ring",             -- dotted lowercase words
    summary = "Place markers in a ring.",
    tier = "edit",                   -- "read" or "edit"; never "destructive"
    input = {                        -- JSON Schema of the arguments
        type = "object",
        properties = { count = { type = "integer", minimum = 1 } },
        required = { "count" },
    },
    run = function(args)
        -- change the project with command.run(...)
        return { placed = args.count }
    end,
}
```

## Example

```text
error[RE8015]: scripts/tools/commands/wipe.luau (level.wipe) asks for the destructive tier; tools are capped at `edit`
  --> scripts/tools/commands/wipe.luau
```

## How to fix it

Give the table a `name`, a `summary` and a `run` function, use the `read` or
`edit` tier, and pick a name no other command uses (`describe` lists them).
If the script itself fails to load, the message gives its first error.
