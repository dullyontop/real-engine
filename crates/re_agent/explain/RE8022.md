# RE8022: Recipe step refused

A recipe step names a command that is not registered, or one whose tier is
above `edit` (ADR-0020). Recipes only make edits: deleting, overwriting
outside the project's files or running anything destructive is not allowed in
a recipe. A `command` check must name a `read` command.

## Example

```text
error[RE8022]: step 2 runs `checkpoint.restore`, which is above the edit tier
```

## How to fix it

Change the recipe to use edit-tier commands, or run the destructive command
yourself after the recipe, under your own policy.
