# RE8013: File command failed

A file command (`file.delete`, `script.write`) could not do its work: the file
is missing or is a directory, or it could not be written.

## Example

```text
error[RE8013]: cannot delete assets/old.png: No such file or directory (os error 2)
  --> assets/old.png
```

## How to fix it

Check the path (it is relative to the project root) and that the file exists
and is writable.
