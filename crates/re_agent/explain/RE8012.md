# RE8012: No agent session

`checkpoint.restore` returns to a checkpoint of the current agent session, but
none has started. A session starts when an agent connects (`real mcp`).

## Example

```text
error[RE8012]: there is no agent session to restore
```

## How to fix it

To return to an earlier session's start, use `real agent rollback <session>`
(`real agent status` lists the sessions).
