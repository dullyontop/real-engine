# RE8021: Bad parameter value

A template or recipe parameter got a value of the wrong type, or one outside
its `min`/`max` range. Types are `string`, `int`, `float`, `bool` and `color`
(three or four numbers from 0 to 1). On the command line, `--set k=v` parses
`v` as the parameter's type; a colour is written `0.2,0.6,0.3`.

## Example

```text
error[RE8021]: parameter `height` must be at most 64
```

## How to fix it

Pass a value of the listed type inside the listed range.
