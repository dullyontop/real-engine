# RE8026: Unknown evaluation agent

`real agent eval --agent NAME` runs the agent you configured as NAME. No
`eval.toml` defines it, or a file that was read does not parse. The files
are read in this order, and the first one that defines NAME wins:

1. `eval.toml` in the working directory;
2. `$XDG_CONFIG_HOME/real/eval.toml`;
3. `~/.config/real/eval.toml`;
4. `%APPDATA%\real\eval.toml`.

## Example

```text
error[RE8026]: no eval.toml defines the agent `claude`
```

## How to fix it

Add the agent to one of those files:

```toml
[agents.claude]
command = ["claude", "-p", "{prompt}", "--mcp-config", "{mcp_config}"]
timeout_s = 600
```

Without `--agent`, the suite runs its reference solutions instead, and no
agent is needed.
