# RE8002: Path outside the agent policy's scopes

An agent's call would write a file the agent policy does not let it write.
The policy checks every file a call writes, whatever the command's tier: the
paths the command declares (`command.describe` lists them under `paths`,
with `write` or `output` access), and the files it names itself, such as
`proc.create_source`'s default graph file or what `proc.bake` writes. A dry
run writes nothing, so it is not checked.

A written path must be relative to the project root, with no `..`, outside
`.real/` and `.git/`, match an `allow` glob of the policy's `[scopes]` and no
`deny` glob, and must not lead through a symbolic link. The rules are those
of the strictest file system a project can sit on, on every platform:
`.real/`, `.git/` and the `deny` globs are compared without regard to case
(`.Git/hooks` is `.git/hooks` on Windows and macOS), while an `allow` glob
must match as written; and no part of the path may end in `.` or a space,
contain `:`, have the shape of a Windows 8.3 short name (`~` and a digit in
at most eight characters, with an extension of at most three, such as
`GIT~1`), or be a Windows device name such as `CON` or `NUL`.

An image the agent asks for (a `screenshot`'s `path`) must end in `.png`. It
may go anywhere under `.real/out/`, the engine's output folder; anywhere else
it is checked like any other write, and it must be a new file, because an
agent's screenshot never replaces one.

## Example

```text
error[RE8002]: graph.add_node may not write "levels/x.graph.json": it matches no `allow` scope
error[RE8002]: screenshot may not write "real.toml": an image goes to a `.png` file
```

## How to fix it

Write inside the granted scopes. `real agent init` grants `scripts/**`,
`scenes/**`, `graphs/**`, `anims/**`, `prefabs/**`, `materials/**`, `ui/**`
and `assets/**`. Leave a screenshot's `path` out to write it under `.real/out/`,
or name a new `.png` inside the scopes. A person can widen `[scopes]` in
`.real/agent-policy.toml`; `.real/` (except an image under `.real/out/`) and
`.git/` are never writable by agents.
