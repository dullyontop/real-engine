# RE8002: Path outside the agent policy's scopes

A command that writes or deletes a file was given a path an agent may not
touch. The path must be relative to the project root, must not contain `..`,
must not be inside `.real/` or `.git/`, must match one `allow` glob of the
policy's `[scopes]` and no `deny` glob.

## Example

```text
error[RE8002]: script.write may not write "../outside.luau": the path must not contain `..`
```

## How to fix it

Write inside the granted scopes. `real agent init` grants `scripts/**`,
`scenes/**`, `graphs/**`, `prefabs/**`, `materials/**` and `assets/**`. A
person can widen `[scopes]` in `.real/agent-policy.toml`; `.real/` and `.git/`
are never writable.
