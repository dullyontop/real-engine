# RE8001: Tier refused by the agent policy

Every command has a tier: `read`, `edit` or `destructive` (ADR-0020). An agent
may only call commands up to the `max_tier` of `.real/agent-policy.toml`.
Without that file, agents get `read` only.

## Example

```text
error[RE8001]: entity.spawn needs the edit tier, but the agent policy allows only read
```

## How to fix it

- Call the command with `dry_run: true`: a dry run needs only `read` and returns
  the changes the command would make.
- To let agents edit, run `real agent init` and commit the
  `.real/agent-policy.toml` it writes. Committing it is the opt-in.
- `destructive` is never generated. A person adds `max_tier = "destructive"` by
  hand.
