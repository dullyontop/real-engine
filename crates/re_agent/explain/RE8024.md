# RE8024: Recipe check failed

A check listed in a recipe or template did not hold after its steps ran: a
`real verify` stage failed, a read command's result at a JSON pointer did not
match, or `verify.diff` found a regression against the checkpoint taken
before the recipe. An atomic apply restores the checkpoint.

## Example

```text
error[RE8024]: check `query /data/total at_least 1` failed: got 0
```

## How to fix it

Read the check's message and the diagnostics after it. A template check that
fails right after `real new` is a bug in the template.
