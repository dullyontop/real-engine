# RE8010: Checkpoint file error

An agent session's files under `.real/agent/sessions/` could not be read or
written. Sessions store their checkpoints there: the scene's state and the
contents of every file the session touched.

## Example

```text
error[RE8010]: could not write .real/agent/sessions/s1760000000000-42/session.json: No space left on device (os error 28)
```

## How to fix it

Check that `.real/agent/` is writable and that the disk has room. Old sessions
can be deleted once you no longer need to roll them back.
