# RE8014: Unknown resource

`resource.read` (or an MCP `resources/read`) named a URI that is not one of
the engine's resources. Resources are the explain pages
(`real://explain/RE8001`), the engine documents (`real://docs/ROADMAP.md`) and
the Luau definition files (`real://luau/engine.d.luau`).

## Example

```text
error[RE8014]: no resource "real://docs/ROADMP.md" (did you mean "real://docs/ROADMAP.md"?)
```

## How to fix it

List what exists with `resource.list` (optionally with a `prefix` such as
`real://docs/`) and use one of the URIs it returns.
