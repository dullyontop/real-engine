# RE8011: Unknown session or checkpoint

`checkpoint.restore` or `real agent rollback` named a session or checkpoint
that does not exist.

## Example

```text
error[RE8011]: session s1760000000000-42 has no checkpoint "cp9"
```

## How to fix it

Each session's start checkpoint is `start`, and each restore saves the state it
replaced as `cp1`, `cp2` and so on (the restore's result names it). `real agent
status` lists the sessions.
