# RE8007: Project lock file error

The single-writer lock, `.real/editor.lock`, could not be created, written or
replaced.

## Example

```text
error[RE8007]: could not create the project lock: Permission denied (os error 13)
  --> .real/editor.lock
```

## How to fix it

Check that the project directory exists and that `.real/` inside it is
writable by you. If `.real/editor.lock` was left behind by another user's
process, remove it once that process has exited.
