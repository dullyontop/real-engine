# RE8008: Over the agent budget

The agent policy's `[budgets]` cap how much one call may ask for: `frames` for
`play.run` and `graph.generate`, and `entities_per_transaction` for the number
of operations in one `scene.apply`.

## Example

```text
error[RE8008]: play.run is over the agent budget: 100000 frames asked, 600 allowed
```

## How to fix it

Ask for less: fewer frames, or split a large `scene.apply` into several. A
person can raise the budgets in `.real/agent-policy.toml`.
