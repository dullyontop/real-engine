# RE4500: Invalid heightfield

A heightfield is a square grid of `n × n` height samples, `spacing` metres
apart, stored row by row (`samples[z * n + x]`, the layout Jolt uses). It is
refused when:

- `n` is less than 2;
- the number of samples is not `n * n`;
- `spacing` is not a positive, finite number;
- a sample or the offset is NaN or infinite.

## Example

```text
error[RE4500]: invalid heightfield: 15 samples, expected 4 * 4 = 16
```

## How to fix it

Make the sample count match the size. In a ProcGraph, the field nodes
(`terrain.heightfield`, `terrain.island_mask`) set `size` and `cell`; keep
`size` at 2 or more and `cell` above zero.
