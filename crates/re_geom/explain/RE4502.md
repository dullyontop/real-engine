# RE4502: Mesh too large

Merging meshes would give a mesh with more than `u32::MAX` vertices, which a
32-bit index buffer cannot address.

## Example

```text
error[RE4502]: merged mesh would have 4294967297 vertices, more than a u32 index can name
```

## How to fix it

Merge fewer meshes into one, or split the output into several entities (for
example, several `mesh.merge` nodes feeding a `fragment.merge`).
