# RE4511: Invalid polygon mesh

A polygon mesh breaks one of the rules every mesh keeps, and the message names
the first rule broken:

- `face_start` starts at 0, rises by at least 3 per face and ends at the
  number of corners;
- every corner names an existing point, and no face uses a point twice;
- every position is finite, and every face has a non-zero area (corners in a
  line are allowed, as long as the face as a whole has an area);
- every attribute column is as long as its domain (points, corners or faces),
  holds finite values, and has a valid name and its standard type;
- every face's `material` names an entry of the material table, whose paths
  are distinct.

Modelling operations keep these rules, so the mesh came from outside them: a
corrupt cache entry, or Rust code that built the mesh by hand.

## Example

```text
error[RE4511]: invalid mesh: face 3 uses point 7 twice
```

## How to fix it

If the mesh was built by hand, fix the rule the message names. If it came from
a graph, clear the procedural cache and rebuild; if the error comes back,
report it with the graph file: it is a bug.
