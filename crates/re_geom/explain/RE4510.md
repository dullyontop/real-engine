# RE4510: Invalid modelling argument

A modelling operation on a polygon mesh (a `poly.*` node, or `re_geom::poly`
from Rust) was given an argument it cannot use:

- a size, radius, distance or count that is not finite, or outside the range
  the operation documents (a primitive's segments, a scale of zero);
- an attribute name that is not lowercase letters, digits and `_` starting
  with a letter, at most 32 bytes, or is the reserved `position`;
- an attribute whose type differs from the column already there, or from a
  standard attribute's (`uv` is a corner `vec2`, `normal` a corner `vec3`,
  `color` a `vec3` or `vec4`, `material` a face `int`);
- a group that is not a `bool` face column.

A node checks its parameters first and reports most of these as `RE4005`.

## Example

```text
error[RE4510]: invalid argument: rounded box: radius must be 0 to half the smallest side (0.5), got 0.6
```

## How to fix it

Bring the argument into the range the message gives. For an attribute, pick
a valid name, or remove or rename the existing column of the other type
first.
