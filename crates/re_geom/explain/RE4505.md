# RE4505: Triangulation failed

A polygon with area gave no triangles. This happens with contours that cross
themselves or holes that are not inside their outer contour, which the
polygon operations normally remove, and with a polygon mesh face whose
boundary crosses itself, which modelling operations do not make.

## Example

```text
error[RE4505]: triangulation failed: shape 0 (12 points, 40.000 m²) gave no triangles
```

## How to fix it

Pass the shapes through a `shape.boolean` (union with nothing) or
`shape.offset` of 0 first, which resolves crossings, then mesh the result.
If that still fails, or a polygon mesh face fails, report it with the graph
file: it is a bug.
