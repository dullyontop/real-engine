# RE4504: Invalid polygon or path

A polygon or path cannot be used: a contour has fewer than 3 points, a path
fewer than 2, a point is not a finite number, or a width or distance is not
positive.

## Example

```text
error[RE4504]: invalid polygon or path: shape 0 has 2 points; a contour needs at least 3
```

## How to fix it

Give each contour (`shape.polygon`'s `points` and each of its `holes`) at
least 3 points and each path (`path.spline`'s `points`) at least 2, all with
finite coordinates, and use positive widths.
