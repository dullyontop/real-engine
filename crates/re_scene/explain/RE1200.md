# RE1200: Unknown entity id

No entity has the given stable id. Files, commands, logs, agents and scripts
address entities by their stable id (the scene file's `id`), such as `player_spawn`
or `e7kq2m9x4tb`. Generated entities have ids of the form `<source id>/<key>` and
exist only after their source has been generated.

## Example

```text
error[RE1200]: no entity with id "crates"
  --> entity `crates`
```

## How to fix it

Check the spelling, or list entities with the `query` command (`real do query`).
For a generated entity, make sure its source has been regenerated.
