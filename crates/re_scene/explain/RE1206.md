# RE1206: Unsupported file format or version

The file's `format` is not the expected one (`real-engine/scene` for scenes,
`real-engine/prefab` for prefabs), or its `version` is newer than this build
understands. Older versions are migrated forwards automatically.

## Example

```text
error[RE1206]: parse error: unsupported scene version 7 (this build reads 1)
```

## How to fix it

Open the file with the engine version that wrote it, or check that the file is a
scene (not a prefab or another document).
