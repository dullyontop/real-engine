# RE1207: Generator failed

A procedural source's generator could not produce its output: the generator named
in `Procedural.generator` is not registered, it returned an error, or its output
was invalid (a key produced twice, a parent key that is not generated before its
child, an unknown component or field, a value of the wrong type). The previous
generated output is kept unchanged. A generator's own diagnostic, if it has one, is
attached as a related diagnostic.

## Example

```text
error[RE1207]: island: generation failed: generator graph: node "scatter" has no input "points"
  --> entity `island`
  = hint: the previous generated output is kept
```

## How to fix it

Fix the generator's parameters on the source entity (or the graph it reads), then
regenerate. `real describe` lists the registered generators.
