# RE1201: Duplicate entity id

An entity with this stable id already exists, either in the world or earlier in
the same file. Stable ids are unique.

## Example

```text
error[RE1201]: an entity with id "sun" already exists
  --> entity `sun`
```

## How to fix it

Choose another id, or leave `id` out of a `spawn` operation to get a fresh
engine-made id.
