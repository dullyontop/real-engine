# RE1204: Scene or prefab file does not parse

A scene or prefab file is not valid: bad JSON syntax, an unknown key (unknown
keys are errors), a missing required key, or an entity whose components do not
convert. The message names the entity's index and id, and the component and field;
the specific problem is attached as a related diagnostic with its own code.

## Example

```text
error[RE1204]: parse error: entities[0] (id "a"): Transform.translation: expected vec3 as [x, y, z], found list of 2
  error[RE1003]: Transform.translation: expected vec3 as [x, y, z], found list of 2
```

## How to fix it

Fix the named entity, component and field. `real schema` writes
`scene.schema.json`, which editors can use to validate scene files as you type. A
failed load leaves the world untouched.
