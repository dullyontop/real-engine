# RE1208: Script component schema mismatch

The file's `script_components` list declares a component whose fields, types or
defaults differ from the component of the same name that is already registered
(by a script that ran first, or by another file). A name can only mean one shape
per session.

## Example

```text
error[RE1208]: script component "Health" declared in the file does not match the registered component of that name
```

## How to fix it

Make the declaration in the file match the script's `define_component` call, or
rename one of them. Saving the scene again writes the current declaration.
