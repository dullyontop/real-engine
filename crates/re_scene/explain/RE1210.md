# RE1210: Not a generated entity

Only generated entities (ids of the form `<source id>/<key>`) can be suppressed.
Suppression stops a regeneration from spawning that key again for the rest of the
play session.

## Example

```text
error[RE1210]: "crate" is not a generated entity
```

## How to fix it

Despawn authored entities normally; suppress only generated ids.
