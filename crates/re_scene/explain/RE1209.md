# RE1209: Override not applied

After a regeneration, an override of a generated entity could not be applied: the
entity no longer has that component, the field no longer exists, or the stored
value no longer fits the field. The override stays in the source's list (and in the
file); the generated value is used instead. This is a warning.

## Example

```text
warning[RE1209]: grid: override on "pillar_0_0" not applied: entity has no Primitive component
  --> entity `grid`
```

## How to fix it

Remove the override (undo the edit, or edit the field again), or change the
generator so the entity has the component again.
