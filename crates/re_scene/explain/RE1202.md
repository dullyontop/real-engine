# RE1202: Invalid entity id

An authored id is empty or contains `/`. The `/` character is reserved for
generated ids, which have the form `<source id>/<key>`.

## Example

```text
error[RE1202]: id "crates/1" must be non-empty and must not contain '/'
  = hint: '/' is reserved for generated ids (<source id>/<key>)
```

## How to fix it

Use a non-empty id without `/`, such as `crate_1`.
