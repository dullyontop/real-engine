# RE1205: Parent not defined before its child

An entity names a `parent` that is not defined earlier in the file and does not
exist in the world. Scene files list parents before their children.

## Example

```text
error[RE1205]: parse error: entities[0] (id "a"): parent "b" is not defined earlier in the file or in the world
```

## How to fix it

Move the parent's entry before its children, or fix the parent id. Files written
by the engine always have this order.
