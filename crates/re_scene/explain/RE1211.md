# RE1211: Unsupported scene content

The content is well-formed but not supported: for example a procedural source
without a stable id, a generated entity whose source does not exist, or an
entity-typed field with a non-null value inside a prefab (a fragment cannot
reference other entities in M1).

## Example

```text
error[RE1211]: Weld.other: entity references are not supported in prefabs
```

## How to fix it

Restructure the content as the message says. Entity references inside prefabs are
planned for a later milestone.
