# RE3091: Type checker failed

The external type checker started but failed: it exited with an internal error
(exit code 2), was killed, or printed output that could not be read. Its own
output is included in the hint.

## Example

```text
error[RE3091]: the type checker /usr/local/bin/luau-lsp failed (exit code 2)
  = hint: thread 'main' panicked at src/Definitions.cpp: ...
```

## How to fix it

Check the checker version (luau-lsp 1.70.1 is the one CI pins) and run it by hand
on the same files to see its full output.
