# RE3080: Static scan cannot parse the file

The static API scan (validation tier 2) parses each script with full_moon to list
the engine and platform APIs it uses. This file could not be read or parsed, so
it is left out of the gap report. The scan never fails a run; this diagnostic
only explains why a file is missing from the report.

## Example

```text
warning[RE3080]: the static scan cannot parse this file: unexpected token `=`
  --> scripts/broken.luau:1:11
```

## How to fix it

Usually the file also fails to compile (`RE3001`); fix that first. If it compiles
but does not parse here, report the construct: the scan's parser may lag behind
a new Luau syntax feature.
