# RE3090: Type checker not found

Type checking (validation tier 3) runs an external checker: `luau-lsp` 1.70.1 on
`PATH` by default, or the program named by `--checker` or `real.toml [scripts]
checker` (luau-lsp, or a `luau-analyze` patched to load definitions). None was
found, so no types were checked.

When types are asked for explicitly (`real check --types`) this is an error, so
the check can never pass without checking anything. Elsewhere it is a note.

## How to fix it

Install luau-lsp 1.70.1 (a release binary from its GitHub releases) and put it on
`PATH`, or pass `--checker <PATH>`.
