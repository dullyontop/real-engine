# RE3082: Type checker warning

The external Luau type checker reported a lint, such as an unused local or a
shadowed variable. Warnings never fail a check.

## Example

```text
warning[RE3082]: LocalUnused: Variable 'x' is never used; prefix with '_' to silence
  --> scripts/game/main.luau:4:7
```

## How to fix it

Follow the message, or prefix intentionally unused names with `_`.
