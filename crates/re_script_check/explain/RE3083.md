# RE3083: `^` calls the platform's pow

A script raises a number to a power with `^` (or `^=`), and the exponent is not
the literal `2`, `0.5` or `3`. Luau computes such a power with the C library's
`pow`, which rounds differently on Linux, Windows, macOS and the web, and it
folds a constant expression such as `2 ^ 10` with the `pow` of the machine that
compiled the script. A game whose state depends on the result can then end in a
different `state_hash` on each platform (ADR-0036). The exponents 2, 0.5 and 3
are exact everywhere, because Luau compiles them to a multiplication or a
square root.

The engine's `math` functions, `math.pow` among them, run on the same portable
maths library on every platform.

## Example

```text
warning[RE3083]: scripts/game/jump.luau:12:24: `^` with this exponent calls the platform's `pow`, which differs between Linux, Windows, macOS and the web
  = hint: write `math.pow(x, y)`, which gives the same result everywhere (only the exponents 2, 0.5 and 3 are exact with `^`)
```

## How to fix it

Write `math.pow(height, 1.5)` instead of `height ^ 1.5`. A square stays
`x ^ 2` (or `x * x`). The warning does not matter for values that never reach
game state, such as a UI animation curve.
