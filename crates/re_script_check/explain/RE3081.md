# RE3081: Type error

The external Luau type checker (luau-lsp, validation tier 3) found an error,
checking the script against the engine's API definitions (`engine.d.luau`). The
message is the checker's own.

Type results are advisory in `real verify` and the corpus run, and an error when
`real check --types` is asked for explicitly.

## Example

```text
error[RE3081]: TypeError: Key 'Spawn' not found in table 'world'. Did you mean 'spawn'?
  --> scripts/game/main.luau:3:1
```

## How to fix it

Fix the call to match the engine API (`real describe --luau-defs` prints the
definitions), or add a type annotation where the checker cannot infer a type.
