# RE5008: Invalid constraint

A constraint could not be created. Only fixed, hinge and distance constraints exist in
this version.

## How to fix it

- Both entities (`a` and `b`) must already have bodies, and must be different.
- A hinge needs a non-zero axis. Its limits, if any, are radians with
  `-π <= min <= 0 <= max <= π`.
- A distance constraint needs `0 <= min <= max`.
- At least one of the two bodies should be able to move.
