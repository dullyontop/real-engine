# RE5004: Physics command for an entity without a body

A physics command named an entity that has no body, character or constraint in the
physics world. It is usually a command sent before the body was added, or after it was
removed.

## Example

```text
error[RE5004]: entity #12 has no body
  --> entity `#12`
  = hint: add the body or character before sending commands to it
```

## How to fix it

- Add the `RigidBody` and `Collider` (or `CharacterController`) before moving, pushing
  or removing the entity's body.
- Character commands (`MoveCharacter`) need a `CharacterController`; body commands
  (`ApplyImpulse`, `SetVelocity`, `SetShape`) need a `RigidBody`.
