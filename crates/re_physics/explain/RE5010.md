# RE5010: Command does not suit the body kind

A command was sent to a body whose `RigidBody.kind` cannot take it:

- impulses move only `Dynamic` bodies;
- kinematic targets move only `Kinematic` bodies;
- velocities can be set on `Dynamic` and `Kinematic` bodies, never on `Static` ones.

## How to fix it

- Change the body's kind, or use the command meant for it. A static body only moves
  by teleporting it (setting its transform).
