# RE5003: Mesh collider on a dynamic body, or heightfield on a moving one

Jolt cannot compute the mass of a triangle mesh or a heightfield, and cannot collide
two of them, so:

- a triangle-mesh collider can be used on static and kinematic bodies (a kinematic
  mesh takes its mass from `RigidBody.mass`, and touches dynamic bodies only), but not
  on a dynamic one;
- a heightfield collider can only be used on a static body.

A body with a shape it cannot have is refused.

## Example

```text
error[RE5003]: a heightfield collider can only be used on a static body, not a Dynamic one
  --> entity `#12`
  = hint: make the body static, or use a box, sphere, capsule or convex collider
```

## How to fix it

- Set the body's `RigidBody.kind` to `Static` (terrain, level geometry), or to
  `Kinematic` for a mesh moved by its `Transform` (a lift, a door, a moving platform).
- For an object that falls, rolls or is pushed, use a box, sphere, capsule or convex
  hull collider, or a convex hull of the mesh's vertices.
