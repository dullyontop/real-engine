# RE5003: Mesh or heightfield collider on a moving body

Triangle-mesh and heightfield colliders can only be used on static bodies. Jolt cannot
compute their mass and cannot collide two of them, so a dynamic or kinematic body with
one is refused.

## Example

```text
error[RE5003]: a heightfield collider can only be used on a static body, not a Dynamic one
  --> entity `#12`
  = hint: make the body static, or use a box, sphere, capsule or convex collider
```

## How to fix it

- Set the body's `RigidBody.kind` to `Static` (terrain, level geometry).
- For a moving object, use a box, sphere, capsule or convex hull collider, or a convex
  hull of the mesh's vertices.
