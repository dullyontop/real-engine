# RE5009: Invalid character

A character could not be created or moved. The message names the problem.

## How to fix it

- `height` must be more than twice `radius`, and both must be positive.
- `max_slope_deg` must be between 0 and 90 (exclusive); `step_height` must be zero or
  positive; `mass` must be positive.
- Desired velocities must be finite and below 500 m/s.
