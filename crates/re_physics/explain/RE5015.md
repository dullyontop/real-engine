# RE5015: Unknown collision layer

A body or character used a `Collider.layer` that is not in the world's layer table.
The standard table has layers 0 to 7: 0 is the default and 1 is debris (moving debris
collides with static geometry only).

## Example

```text
error[RE5015]: layer 9 is not in the layer table (layers 0 to 7)
  --> entity `#12`
  = hint: use a layer below the table's count, or add layers to PhysicsConfig::layers
```

## How to fix it

- Use a layer below the table's count.
- To use more layers, create the world with a bigger `LayerTable` in
  `PhysicsConfig::layers` (up to 32 layers).
