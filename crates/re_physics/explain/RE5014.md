# RE5014: Constraint removed with its body

A body was removed while constraints still joined it to other bodies. Physics removed
those constraints first, because a constraint cannot outlive its bodies.

## Example

```text
warning[RE5014]: constraint #14 was removed because its body #12 was removed
  --> entity `#14`
  = hint: remove constraints before the bodies they join
```

## How to fix it

- If this was intended (an object breaking off), nothing is needed.
- Otherwise remove the constraint entities before the bodies they join, so the
  constraint's entity does not stay behind without a constraint.
