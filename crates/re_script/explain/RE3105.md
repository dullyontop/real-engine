# RE3105: Save migration step failed

A `save.migrate` step raised an error, or returned something other than a
table, while `save.read` migrated a slot. The message names the step (the
version it migrates from), the slot and the step's error. The slot is
unchanged: a read never rewrites it, and the game writes it when it chooses.

## Example

```text
error[RE3105]: save.read: the step from version 1 failed on slot "slot-1": scripts/progress.luau:4: attempt to perform arithmetic on nil
```

## How to fix it

Make each step handle every shape the old data can have, and return the new
table:

```luau
save.migrate(1, function(data)
    data.coins = (data.gold or 0) * 10
    data.gold = nil
    return data          -- a step returns the migrated table
end)
```

A step runs inside `save.read`, so it cannot wait (`task.wait`): it gets the
data and returns it.
