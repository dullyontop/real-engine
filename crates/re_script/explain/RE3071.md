# RE3071: The debugger's DAP server failed

The script debugger speaks the Debug Adapter Protocol over TCP on
`127.0.0.1` (port 4711 by default). This error means it could not listen on
the port, usually because another process (or another editor or `real run
--debug`) already uses it. It is also reported when a client sends something
that is not a DAP message.

## Example

```text
error[RE3071]: the debugger cannot listen on 127.0.0.1:4711: Address already in use (os error 98)
  = help: another process uses the port; pick another one
```

## How to fix it

- Close the other debugging session, or give this one another port
  (`real run --debug 4712`).
- Point your editor's DAP client at the same port.
