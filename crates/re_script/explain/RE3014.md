# RE3014: Too many deferred threads

More than 10 000 `task.defer` calls ran in one scheduler cycle. That almost always
means a deferred function defers itself unconditionally, which would never let the
frame finish. The remaining deferred threads were dropped.

## Example

```text
error[RE3014]: more than 10000 task.defer calls in one cycle; 1 deferred threads were dropped
```

## How to fix it

Use `task.wait()` or `task.delay` to continue work on a later step instead of
deferring in a loop.
