# RE3015: Engine service unavailable

A script called an engine function whose service is not available where it runs,
such as `physics.impulse` or `audio.play` in a builder script or a tool run with no
game running.

## Example

```text
error[RE3015]: audio.play is not available here: no game is running
```

## How to fix it

Call gameplay services from `game` scripts while the game runs, and keep builder
and tool scripts to the `world`, `proc` and `command` libraries.
