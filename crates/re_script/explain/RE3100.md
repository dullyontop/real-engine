# RE3100: Unknown scene

`scene.switch`, `scene.load` or `scene.unload` named a scene the game does not
have. A game's scenes are the entry scene (`[project] entry_scene`, named after
its file without `.scene.json` unless `[scenes]` names it) and the scenes that
`[scenes]` in `real.toml` lists by name. Scripts name scenes, never paths.

## Example

```text
error[RE3100]: scene.switch: no scene is named "harbor" (did you mean "harbour"?)
```

## How to fix it

Use a name from `scene.list()`, or add the scene to `real.toml`:

```toml
[scenes]
harbour = "scenes/harbour.scene.json"
```
