# RE3104: Missing save migration step

`save.read` found data of an older version than `[saves] version` in
`real.toml`, and no `save.migrate` step turns one of the versions in between
into the next. A read runs one step per version, from the slot's data version
up to `[saves] version`, and finds every step before it runs any, so nothing
was migrated and the slot is unchanged.

## Example

```text
error[RE3104]: save.read: slot "slot-1" holds version 1 data, and no step migrates version 1 to 2; add save.migrate(1, step)
```

## How to fix it

Register a step for each version the game's data has had, before the game
reads a slot (at the top of the script that loads saves, for instance):

```luau
-- Version 2 renamed `gold` to `coins`.
save.migrate(1, function(data)
    data.coins = data.gold
    data.gold = nil
    return data
end)
```

Keep old steps when the version goes up again: a player may still have a
slot from the first version.
