# RE3009: Commands unavailable

`command.run` was called in a context that has no command registry attached. The
`command` library exists only in the `tools` context, and only hosts that carry a
command registry (the editor, `real` tool runs) can dispatch commands.

## Example

```text
error[RE3009]: command.run("entity.spawn"): no command registry is attached to this context
```

## How to fix it

Run the tool script from the editor or the CLI, which attach the registry, or use
the `world` library for runtime changes that do not need undo.
