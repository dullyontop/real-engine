# RE3001: Luau syntax error

The script does not compile. The message is the Luau compiler's, with the file and
line where parsing stopped. A script with a syntax error never runs, and a hot
reload with a syntax error keeps the version that was already running.

## Example

```text
error[RE3001]: Expected identifier when parsing expression, got '='
  --> scripts/game/player.luau:12
```

## How to fix it

Fix the code at the line shown. The error is often a few characters earlier than
the reported position, for example a missing `end` or `)` on the line before.
`real check` compiles every script of a project without running it.
