# RE3011: Script memory limit reached

A script context used more memory than its limit (`real.toml [scripts]
memory_limit_mb`, 256 MiB by default) and the allocation that crossed it failed.
The context keeps working once memory is freed; the engine collects garbage after
this error.

## Example

```text
error[RE3011]: not enough memory
  --> scripts/game/cache.luau:14
```

## How to fix it

Look for tables that grow without bound (caches, logs, event queues) and for
pending `task.delay` calls that pile up. Each suspended script thread costs about
half a kilobyte plus its arguments. Raise `memory_limit_mb` only if the memory is
really needed.
