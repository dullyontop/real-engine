# RE3106: Save from a newer version

`save.read` found a slot whose data version is higher than `[saves] version`
in this build's `real.toml`: a newer build of the game wrote it, and this
build has no way back to an older version of the data. The slot is left as it
is, so the newer build still reads it.

## Example

```text
error[RE3106]: save.read: slot "slot-1" holds version 3 data, newer than this build's [saves] version 2
```

## How to fix it

Play the slot with the build that wrote it, or newer. A game that wants to
offer something else (start over, or keep the slot) can read it in a
`pcall` and tell the player:

```luau
local ok, data = pcall(save.read, "slot-1")
if not ok then
    show_message("This save comes from a newer version of the game.")
end
```
