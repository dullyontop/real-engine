# RE3026: Frame-only read in a fixed step

A script read something that depends on frame timing or on live output during a
fixed step (a `time.on_step` or `time.on_post_step` callback, or a thread resumed
there). Fixed steps must replay exactly, and these values differ from machine to
machine and from frame to frame:

- `Entity:drawn_transform()`: where an entity is drawn, which moves with the
  frame's interpolation between the last two steps;
- `audio.levels(bus)`: the mixer's live output.

## Example

```text
error[RE3026]: Entity:drawn_transform is not available during a fixed step: where an entity is drawn depends on frame timing; read it from time.on_late_frame or time.on_frame
```

## How to fix it

Read these values from `time.on_late_frame` or `time.on_frame`. In a fixed step,
use what the simulation knows: `e:get("Transform", ...)` or the physics queries.
