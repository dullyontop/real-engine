# RE3012: Invalid ProcGraph builder

A builder script made an invalid ProcGraph or did not return one: a node id was
used twice, an input was not a node or port of the same graph, the seed was not an
integer, or the script returned something other than the graph from `proc.graph`.

## Example

```text
error[RE3012]: a node with id "n2" already exists in graph "island"
  --> scripts/tools/island.luau:6
```

## How to fix it

Build every node with `g:node(...)` on one graph, wire inputs with node handles or
`node:out("port")`, and end the script with `return g`.
