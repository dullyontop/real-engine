# RE3003: Cannot read script

The engine could not read a script or module file: the path does not exist, is
not a file, or is not readable. Script paths are relative to the project root and
start with `scripts/`.

## Example

```text
error[RE3003]: cannot read scripts/game/plyer.luau: No such file or directory
```

## How to fix it

Check the path in the entity's `ScriptRef` (or the `require` call) for typos, and
that the file exists under the project's `scripts/` folder.
