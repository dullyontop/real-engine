# RE3007: Entity handle is stale

A script used an entity handle after the entity was despawned. Handles stay valid
as values (they compare and print), but reading or writing through them fails once
the entity is gone.

## Example

```text
error[RE3007]: Entity(12v1) is no longer alive (stale handle)
  --> scripts/game/coins.luau:21
```

## How to fix it

Check `e.alive` before using a handle you kept across frames, and drop handles
when you destroy their entity.
