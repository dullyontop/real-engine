# RE9001: Unsupported API member

A script read a member that the engine API does not have, such as `world.Spawn`
or `entity.Position`. Engine libraries and handles are strict: an unknown member
raises this error instead of quietly returning `nil`, so typos and Roblox-style
names show up where they are used.

## Example

```text
error[RE9001]: unsupported API member: world.GetChildren
  --> scripts/game/main.luau:3
```

## How to fix it

Check the name against `engine.d.luau` (`real describe --luau-defs`). The native
API has no Roblox-style members: use the native equivalents (`e:children()`,
`e:get("Transform", "translation")`), or, for scripts written for Roblox, make a
Roblox-style project with `real new DIR --template roblox`.
