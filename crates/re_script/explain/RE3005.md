# RE3005: task.wait cannot yield here

`task.wait` suspends the current script thread and hands it to the engine's
scheduler. It can only do that from a thread the scheduler runs: a script's main
body, a callback connected with `time.on_step` and friends, or a function started
with `task.spawn`, `task.defer` or `task.delay`.

Inside a coroutine made with `coroutine.create` or `coroutine.wrap`, the yield
would go to that coroutine instead of the scheduler, which silently breaks both.
M1 refuses it with this error. Engine calls that run Luau synchronously (a
builder script, `exec`) cannot wait either.

## Example

```text
error[RE3005]: task.wait inside a coroutine made with coroutine.create or coroutine.wrap is not supported in M1; use task.spawn
  --> scripts/game/door.luau:12
```

## How to fix it

Start concurrent work with `task.spawn(function() ... end)` instead of a
coroutine, and keep `task.wait` out of builder scripts.
