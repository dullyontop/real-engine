# RE3002: Script runtime error

A script raised an error while it ran: an `error(...)` call, indexing `nil`,
calling something that is not a function, or a bad argument to an engine function.
The diagnostic carries the file, the line of the first Luau frame and a traceback.

An error in one script callback does not stop the frame or disconnect anything;
the failing thread ends and the others keep running.

## Example

```text
error[RE3002]: attempt to index nil with 'field'
  --> scripts/game/player.luau:2
```

## How to fix it

Read the traceback from the bottom up to see how the failing line was reached.
Errors raised by engine functions carry their own code (for example `RE1003` for a
field value of the wrong type); `real explain` describes those.
