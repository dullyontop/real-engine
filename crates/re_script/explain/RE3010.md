# RE3010: Script exceeded its CPU budget

A script ran longer than the context's CPU budget (`real.toml [scripts]
cpu_budget_ms`, 4 ms by default) in one resume and was stopped. Usually this is an
endless loop, or a loop that does far more work in one frame than intended.

The budget cannot be caught: once it trips, every check point raises until the
engine re-arms it, so `pcall` around a runaway loop does not keep the script alive.
The context itself stays usable; only the thread that ran too long ends.

## Example

```text
error[RE3010]: script exceeded its time budget
  --> scripts/game/spawner.luau:8
```

## How to fix it

Split long work across frames with `task.wait()` (each resume gets a fresh
budget), or move heavy work into engine functions such as `world.query`. Raise
`cpu_budget_ms` only if the work is genuinely needed every frame.
