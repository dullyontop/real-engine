# RE3006: Bad argument to an engine function

An engine function was called with an argument it cannot use: the wrong type (a
string where an `Entity` is expected), an unknown option key, or a value out of
range. The message names the function and what it expected.

## Example

```text
error[RE3006]: physics.impulse expects an Entity, got string
  --> scripts/game/cannon.luau:7
```

## How to fix it

Pass the documented types; `engine.d.luau` (`real describe --luau-defs`) lists the
signature of every engine function, and the type checker reports most of these
before the script runs.
