# RE3008: Invalid component definition

`world.define_component(name, fields)` could not register the component: a field
type is unknown, a default does not fit its type, the name is already used by a
native component, or a script component with that name already exists with
different fields. Defining the same shape again (for example when a script is
reloaded) is allowed.

## Example

```text
error[RE3008]: world.define_component("Collectible"): field "value" has unknown type "int"
```

## How to fix it

Use the field types `bool`, `i32`, `i64`, `f32`, `f64`, `vec3`, `quat`, `color`,
`string`, `entity`, or `{ type = "enum", variants = { ... } }`, and give each
script component a unique name.
