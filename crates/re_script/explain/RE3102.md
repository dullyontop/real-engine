# RE3102: Invalid save slot name

A `save` call named a slot that is not 1 to 64 characters from `a`–`z`,
`0`–`9`, `_` and `-`. A slot is a file name (`saves/<slot>.json` in the data
folder), so the name is lowercase only: two slots never share a file on a
file system that ignores case.

## Example

```text
error[RE3102]: save.write: "Slot 1" is not a slot name; use 1 to 64 characters from a-z, 0-9, _ and -
```

## How to fix it

Name slots with lowercase words, digits, `_` and `-`:

```luau
save.write("slot-1", progress)
save.write("autosave", progress)
```
