# RE7402: Audio clip cannot be decoded

The clip file exists but could not be decoded. M1 plays WAV files: PCM
(8, 16, 24 or 32 bit) or 32-bit float, mono or stereo. Other formats (Ogg
Vorbis, MP3, FLAC) are not enabled yet.

## Example

```text
error[RE7402]: cannot decode audio clip `assets/music/theme.wav`: ...
  --> assets/music/theme.wav
```

## How to fix it

Convert the file to a mono or stereo WAV, for example with
`ffmpeg -i theme.ogg -c:a pcm_s16le theme.wav`.
