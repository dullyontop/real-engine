# RE7400: No audio output device

No audio output device could be opened, so audio continues on the silent
headless backend. The game runs normally; sounds are mixed but not heard.

This is expected on servers, in CI and in containers. On Linux it also happens
when no ALSA or PulseAudio/PipeWire device is configured; alsa-lib may print a
few `ALSA lib ... Unknown PCM default` lines while the engine probes.

## Example

```text
warning[RE7400]: no audio output device; continuing with silent headless audio
```

## How to fix it

Nothing is needed for headless runs. On a desktop, check that a sound device
is connected, enabled and set as the default output.
