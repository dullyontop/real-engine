# RE7410: Audio stream failed

A long Ogg Vorbis clip, which plays streamed from its file, failed while it
played: a read or decode error part-way through the file, or a decoder that
met damage it does not expect. Only that sound stops; other sounds and other
streams play on. The message says where in the clip it failed.

## Example

```text
error[RE7410]: audio stream `assets/music/theme.ogg` failed: an audio packet is damaged: ... (at 74.2 s)
  --> assets/music/theme.ogg
```

## How to fix it

Re-encode the file, for example with `oggenc` or
`ffmpeg -i theme.wav -c:a libvorbis theme.ogg`, and check that it plays to the
end. `real build` decodes every Ogg file it packs once, so a damaged file
fails the build with `RE7402` before it ships.
