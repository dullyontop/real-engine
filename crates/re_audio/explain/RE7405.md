# RE7405: Invalid playback rate

A playback rate must be a finite number above zero. 1 plays the clip at its
own speed and pitch, 2 plays it twice as fast and an octave higher, and 0.5
plays it half as fast and an octave lower.

## Example

```text
error[RE7405]: playback rate 0 is not a finite number > 0
```

## How to fix it

Clamp computed rates, for example `math.max(rate, 0.01)` in a script. To stop
a sound, stop it instead of setting its rate to 0.
