# RE7404: Invalid volume

A volume must be a finite number of zero or more. Volumes are linear: 1 plays
the clip unchanged, 0.5 is about 6 dB quieter, 0 is silent, and values above 1
amplify.

A bus volume changes over a tween of 0 to 3,600 seconds (an hour); a longer,
negative or non-finite length is refused with this code.

## Example

```text
error[RE7404]: volume -1 is not a finite number >= 0 (1 is unchanged, 0 is silent)
error[RE7404]: tween length 7200 s is not a number of seconds from 0 to 3600
```

## How to fix it

Clamp computed volumes, for example `math.clamp(v, 0, 1)` in a script, and keep
tween lengths within an hour.
