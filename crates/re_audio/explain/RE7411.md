# RE7411: Invalid sound control

A command that controls a playing sound has a fade that is not a number of
seconds from 0 to 3,600 (an hour), or a seek time that is not a finite number
of seconds, 0 or more. Scripts send these commands when they stop, pause,
resume, seek or fade an entity's sound or a sound that `audio.play` returned.
A fade is seconds of real time, unaffected by the time scale; 0 is at once. A
seek is seconds from the start of the clip. The command does nothing.

## Example

```text
error[RE7411]: fade -1 s is not a number of seconds from 0 to 3600
```

## How to fix it

Clamp computed times, for example `math.clamp(seconds, 0, 3600)` for a fade in
a script. To jump back to the start of a clip, seek to 0.
