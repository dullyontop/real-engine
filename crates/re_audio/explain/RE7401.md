# RE7401: Audio clip not found

A sound names a clip that is not loaded and not found as a file. Clip names
are paths relative to the project root, such as `assets/sfx/pickup.wav`, the
same path the `AudioSource` component and `audio.play` use.

## Example

```text
error[RE7401]: audio clip `assets/sfx/pikcup.wav` not found: no file at /game/assets/sfx/pikcup.wav
  --> assets/sfx/pikcup.wav
```

## How to fix it

Check the spelling and that the file is inside the project. Paths use `/` on
every platform.
