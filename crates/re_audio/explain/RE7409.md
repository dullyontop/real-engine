# RE7409: Unsupported audio file

An audio clip is a file the engine does not play. The engine plays WAV files
(PCM or float) and Ogg Vorbis files, mono or stereo. It refuses an Ogg file
that is not Vorbis (Opus or FLAC in Ogg), that has more than two channels, or
that holds several chained or multiplexed streams, and a file named `.ogg`
that is not an Ogg file at all. The sound does not play.

`real check` and `real build` report the same files earlier, with `RE7070`,
so a packaged game never ships one.

## Example

```text
error[RE7409]: audio clip `assets/music/theme.ogg` is not a file the engine plays: it has 6 channels; only mono and stereo play
  --> assets/music/theme.ogg
```

## How to fix it

Convert the file to mono or stereo Ogg Vorbis, one stream per file, for
example `ffmpeg -i theme.flac -ac 2 -c:a libvorbis theme.ogg`, or to a WAV
file.
