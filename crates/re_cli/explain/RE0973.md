# RE0973: wasm-opt is not installed

`real build --target web` shrinks the web runtime with binaryen's `wasm-opt`
when it is on the `PATH`. It was not found, so the build copied the module as
cargo and wasm-bindgen wrote it. The game works the same; the download is
larger (about 9 MB compressed instead of 7 MB).

## Example

```text
warning[RE0973]: wasm-opt was not found, so real_bg.wasm is not optimised
```

## How to fix it

Install binaryen (version 133 is the one the engine's CI uses; the engine's
`tools/ci/binaryen.sh` downloads it) and build again.
