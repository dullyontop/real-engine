# RE0974: The web build's archive is large

A web game downloads its whole `game.rpak` before it starts, and holds it in
the page's memory, which a browser may limit to less than 4 GiB. The archive
is over 256 MiB, so some players may wait long or run out of memory.

## Example

```text
warning[RE0974]: game.rpak is 312.4 MiB; a web game downloads all of it before it starts
```

## How to fix it

Leave out what the game does not need with `[package] exclude`, store
assets processed (`[package] assets`), or compress textures and audio further.
