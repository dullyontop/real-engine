# RE0950: Invalid [package] section

`[package]` in `real.toml` tells `real build` how to pack the game. One of its
values is not valid: `identifier` must be dot-separated parts of ASCII letters,
digits and `-` (such as `com.example.island`), `icon` must name a PNG in the
project, and the patterns must be project paths.

As a warning, it says `real build` chose a default: without `identifier` the
game builds as `local.<name>`. The identifier names the folders where the game
keeps its saves, so two games that share one share their saves.

## Example

```text
warning[RE0950]: [package] has no identifier; building as `local.island`
```

## How to fix it

```toml
[package]
identifier = "com.example.island"
```
