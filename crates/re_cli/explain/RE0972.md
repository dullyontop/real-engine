# RE0972: wasm-bindgen CLI version differs

The wasm-bindgen CLI writes the JavaScript glue for the web runtime, and it
must be exactly the version of the `wasm-bindgen` crate in the engine's
`Cargo.lock`: another version writes glue that does not match the module.

## Example

```text
error[RE0972]: wasm-bindgen 0.2.100 is installed; this engine needs 0.2.129
```

## How to fix it

Install the version the message names:

```sh
cargo install --locked wasm-bindgen-cli --version 0.2.129
```
