# RE0903: Script uses an API the engine does not provide

The static scan (`real check`, and the `scan` stage of `real verify`) found a
global or a member of an engine library that scripts use but the engine does
not define, such as `game:GetService` or `physics.overlap`. Calling it will fail
at run time. It is a warning: the scan cannot tell a missing API from a name a
script defines itself on a library table.

## Example

```text
warning[RE0903]: scripts use `physics.overlap` (2 times), which the engine does not provide
```

## How to fix it

Use the engine API instead. `real describe --luau-defs` prints every global and
member with its signature; the M1 API has no Roblox-style layer (`game`,
`Instance`, services), which comes in a later milestone.
