# RE0904: Needs the tooling build of real

`real` comes in two builds. The default one has the tooling: the editor,
`real do`, `real mcp`, the template library and the rest. A runtime-only build
(`--no-default-features`) runs, verifies, describes and explains a project,
and its `real new` makes only the plain `native` project. It refuses the rest
of `real new` with this error: another template, `--set`, `--check` and
`--list-templates`.

## Example

```text
error[RE0904]: this build of `real` has only the plain `native` template
  = hint: use the default (tooling) build of `real` for templates, `--set` and `--check`
```

## How to fix it

Use the default build of `real`, which cargo builds unless it is given
`--no-default-features` (in the engine's repository,
`cargo run --release -p re_cli -- new DIR --template terrain`), or run
`real new DIR` without `--template`, `--set` and `--check`.
