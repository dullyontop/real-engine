# RE0951: real build stopped on errors

Before packing, `real build` runs `real verify`'s content and compile checks
and imports every asset. One of them reported an error, so no archive was
written. The errors are listed above this one.

## Example

```text
error[RE3001]: scripts/main.luau:3: Expected identifier when parsing expression, got '='
error[RE0951]: real build stopped: the project has 1 error
```

## How to fix it

Fix the listed errors; `real verify` reports the same ones.
