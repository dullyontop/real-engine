# RE0956: Packaged run differs from the project

`real verify --package DIR` runs the packaged game in `DIR` (a boot, and each
`tests/replays/*.replay.json` of the project) and compares each run's state
hash with a run of the project itself. They differ, so the packaged game does
not behave as the project does: a file the game reads may be missing from the
archive (`[package] exclude`), found only by ignoring case (`RE0603`), or read
in another form.

## Example

```text
error[RE0956]: tests/replays/walk.replay.json: the packaged game ended with state hash 1f0c…, the project with 9a42…
```

## How to fix it

Run the packaged game with `--json` and read its diagnostics, check the build
report (`real build --json`) for what was packed and in which form, and run
`real build` again after fixing.
