# RE0954: Third-party notices could not be written

`real build` writes `THIRD_PARTY_NOTICES.txt` beside the game with the license
of every crate the runtime links. A crate's license is not on the allow-list,
the crate list could not be read from cargo, or `--runtime` was given without a
`THIRD_PARTY_NOTICES.txt` beside the binary.

## Example

```text
error[RE0954]: the runtime at ./runtime/island has no THIRD_PARTY_NOTICES.txt beside it
```

## How to fix it

Put the notices from the runtime's own build beside it, or let `real build`
build the runtime. A license outside the allow-list must be approved first
(`deny.toml`, ADR-0019).
