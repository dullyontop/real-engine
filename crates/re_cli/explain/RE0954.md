# RE0954: Third-party notices could not be written

`real build` writes `THIRD_PARTY_NOTICES.txt` beside the game with the license
of every crate the runtime is built from, then the game's own notices. A
crate's license is not on the allow-list, a crate ships no license file and
there is no standard text of its license, the crate list could not be read from
cargo, `--runtime` was given without a `THIRD_PARTY_NOTICES.txt` beside the
binary, or a `[package] notices` pattern matches no file.

## Example

```text
error[RE0954]: the runtime at ./runtime/island has no THIRD_PARTY_NOTICES.txt beside it
```

## How to fix it

Use the whole runtime folder (`real build --runtime-only` writes one, and each
release publishes them), or let `real build` build the runtime. A license
outside the allow-list must be approved first (`deny.toml`, ADR-0019). Fix or
remove a `[package] notices` pattern that matches nothing.
