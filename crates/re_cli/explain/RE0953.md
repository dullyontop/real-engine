# RE0953: Game runtime build or check failed

`real build` builds the game's executable with cargo (`--profile packaged`,
the `game` feature, no tooling), or takes a prebuilt one from `--runtime`. The
build failed, or the prebuilt runtime reports other engine, Luau or bytecode
versions or compiler options than this `real` (its `--runtime-info`), so its
VM could not load the archive's bytecode.

## Example

```text
error[RE0953]: the runtime at ./island-runtime was built for engine 0.3.0; this build needs 0.4.0
```

## How to fix it

Read cargo's output above the error. Outside the engine's own workspace, pass
`--runtime PATH` with a runtime built from the same engine version, or use
`--archive-only`.
