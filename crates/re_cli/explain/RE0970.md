# RE0970: The web build's toolchain is missing

`real build --target web` builds the web runtime (the crate `re_web`) with
cargo, and that needs three tools besides Rust:

- Rust's `wasm32-unknown-unknown` target,
- wasi-sdk 34, which compiles Luau and Jolt's C++ for the browser, with
  `WASI_SDK_PATH` naming the folder it is unpacked in,
- the wasm-bindgen CLI, at the version the engine's `Cargo.lock` pins.

One of them was not found.

## Example

```text
error[RE0970]: wasi-sdk was not found: WASI_SDK_PATH is not set
```

## How to fix it

Install what the message names:

```sh
rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.129
```

For wasi-sdk, the engine's `tools/ci/wasi-sdk.sh` downloads wasi-sdk 34,
checks its sha256, and prints the environment to set (`eval "$(tools/ci/wasi-sdk.sh)"`
on Linux). Or skip the toolchain: pass `--runtime DIR` with a prebuilt web
runtime of this engine version, such as the folder of an earlier
`real build --target web`.
