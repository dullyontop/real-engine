# RE0902: Output file could not be written

A command could not write one of its output files: a JSON Schema (`real
schema --out`), a screenshot (`real run --screenshot`) or a report.

## Example

```text
error[RE0902]: cannot write out/f600.png: No such file or directory
```

## How to fix it

Check that the output directory exists and is writable. `mkdir -p out` creates
the usual output directory.
