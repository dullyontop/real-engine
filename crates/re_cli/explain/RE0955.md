# RE0955: A game folder step failed

`real build` could not lay out the game folder: `--out` names a folder that
holds other files (it writes only into an empty folder or one an earlier
`real build` made, marked by `.real-build`, so a wrong path never deletes your
files), or a file could not be copied or written.

## Example

```text
error[RE0955]: --out dist holds files real build did not write; choose an empty folder
```

## How to fix it

Point `--out` at a new or empty folder, or at the folder of an earlier build.
