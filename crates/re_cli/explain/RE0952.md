# RE0952: Two project paths differ only by case

Two files `real build` would pack have names that differ only by upper and
lower case, such as `assets/Rock.png` and `assets/rock.png`. A packaged game
finds files ignoring case when the exact spelling is missing (so a game made on
Windows or macOS still works), which needs every name to be unique ignoring
case.

## Example

```text
error[RE0952]: `assets/Rock.png` and `assets/rock.png` differ only by case
```

## How to fix it

Rename or remove one of the files, or exclude it with `[package] exclude`.
