# RE0971: Web runtime build or check failed

`real build --target web` could not build the web runtime with cargo, or the
folder given with `--runtime` is not a web runtime of this engine: a file is
missing (`real.js`, `real_bg.wasm`, `boot.js`, `wasi.js`, `index.html`,
`runtime.json`), or its `runtime.json` names another engine, Luau or compiler
version than this `real`.

## Example

```text
error[RE0971]: the web runtime in dist/old does not match: engine "0.0.9" (this build needs "0.1.0")
```

## How to fix it

For a failed cargo build, the compiler's errors are printed above this one;
fix them, or pass `--runtime DIR`. For a mismatched runtime, use the web
runtime published with this engine version, or build one by leaving out
`--runtime`.
