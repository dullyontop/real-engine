# RE0900: Unknown diagnostic code

`real explain` was given text that is not a diagnostic code this build knows.
Codes are `RE` followed by four digits, and every code the engine reports has a
page.

## Example

```text
error[RE0900]: unknown diagnostic code RE1999 (did you mean RE1209?)
```

## How to fix it

Copy the code from the diagnostic exactly. `real explain` with no code lists
every code and its title.
