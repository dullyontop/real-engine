# RE0957: A packed file names a file that is not packed

`real build` reads the packed JSON files (scenes, prefabs, materials, graphs)
and checks every string that names an existing project file, such as
`"assets/props/hut.glb#mesh0"` or `"assets/audio/wind.ogg"`. The named file is
not in the archive, so the packaged game would not find it. A file outside the
folders packed by default (`scenes`, `prefabs`, `materials`, `graphs`,
`scripts`, `assets`, `data/seed`) is packed only when `[package] include`
names it, and `[package] exclude` takes files out.

## Example

```text
error[RE0957]: `scenes/main.scene.json` names `art/hut.glb`, which is not packed
  = hint: add it to `[package] include` (or stop excluding it): include = ["art/hut.glb"]
```

## How to fix it

Add the file (or a pattern such as `art/**`) to `[package] include` in
`real.toml`, or remove it from `[package] exclude`. Files under `tests/` and
agent notes (`AGENTS.md`) are never packed: move the file under `assets/`.
