# RE8505: Transcript cannot be written

`real mcp --record FILE` writes one JSON line per tool call to FILE (the
transcript `real agent eval` scores). The server could not create FILE, or
its folder, when it started, so it did not start. When a later line cannot
be written (the disk is full, say), the server reports this code as a
warning and goes on serving: the call itself already happened, but the
transcript misses it.

## Example

```text
error[RE8505]: cannot write the transcript out/run/transcript.jsonl: Permission denied (os error 13)
```

## How to fix it

Pass a FILE in a folder you can write to, with free space. A relative FILE
is relative to the current directory. `real mcp` appends to an existing
transcript, so two servers never cut each other's lines.
