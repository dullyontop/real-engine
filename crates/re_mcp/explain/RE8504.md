# RE8504: Cannot listen on the HTTP address

`real mcp --http ADDR` could not open a socket on `ADDR`. Usually another
program, or another `real mcp`, already listens on that port.

## Example

```text
error[RE8504]: cannot listen on 127.0.0.1:8765: Address already in use (os error 98)
```

## How to fix it

Stop the other program, or choose another port. `127.0.0.1:0` picks any free
port; the URL is then in `.real/mcp-http.json`.
