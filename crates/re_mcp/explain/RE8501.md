# RE8501: Result image unreadable

A tool result (for example from `screenshot` or `play.run`) named a PNG file,
and the MCP server tried to attach it as image content but could not read it.
This is a warning: the command itself succeeded, and the file's path is still
in the result.

## Example

```text
warning[RE8501]: could not attach the image .real/agent/shot-3.png: No such file or directory (os error 2)
```

## How to fix it

Open the file from its path in the result. If it is missing, the command that
wrote it may have failed to save it; run the command again.
