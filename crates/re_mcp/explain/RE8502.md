# RE8502: HTTP address is not loopback

`real mcp --http ADDR` serves MCP over HTTP on this machine only. The address
must be a loopback address (`127.0.0.1`, `[::1]` or `localhost`) with a port.
The HTTP transport has no TLS, so the bearer token would cross the network in
clear text on any other address.

## Example

```text
error[RE8502]: `0.0.0.0:8765` is not a loopback address; real mcp --http serves this machine only
```

## How to fix it

Pass `127.0.0.1:PORT`, or, for `real mcp --http`, `127.0.0.1:0` to let the
system pick a free port (the URL is then in `.real/mcp-http.json`). An agent
on another machine should run `real mcp` there, over stdio, on its own
checkout.
