# RE8507: The MCP server crashed

The thread that serves MCP in `real mcp` stopped with a panic, which is a bug
in the engine. The process wrote a crash report and exits with code 101. The
project lock is released, and every call the server answered before the
crash was applied as usual.

## Example

```text
a crash report was written to ./.real/crash/crash-1793165548114.txt
error[RE8507]: the MCP server stopped with a panic
  = hint: start `real mcp` again, and please report the crash
```

## How to fix it

Start `real mcp` again; your MCP client may do this itself. Please report
the bug with the crash report from `.real/crash/` and, if you can, the
transcript of the session (`real mcp --record FILE`).
