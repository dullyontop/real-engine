# RE8506: Client configs need a fixed port

`real agent init --http ADDR` writes client configs that name the URL of
`real mcp --http ADDR`. With port 0, the system picks a free port each time
the server starts, so no config could name it.

## Example

```text
error[RE8506]: client configs need a fixed port, not 0
  = hint: pass an address such as 127.0.0.1:8765, and start `real mcp --http` with the same one
```

## How to fix it

Pass an address with a port, such as `127.0.0.1:8765`, to
`real agent init --http`, and start `real mcp --http` with the same address.
Port 0 is fine for `real mcp --http` itself, for a client that reads the URL
from `.real/mcp-http.json`.
