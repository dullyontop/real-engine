# RE8503: HTTP token too short

`real mcp --http` takes its bearer token from the `REAL_MCP_TOKEN`
environment variable when it is set. The token must be at least 32 printable
ASCII characters, with no spaces, because anything on this machine that
knows it can drive the project.

## Example

```text
error[RE8503]: REAL_MCP_TOKEN must be at least 32 printable ASCII characters with no spaces (it has 6)
```

## How to fix it

Unset `REAL_MCP_TOKEN` and `real mcp --http` generates a random token and
writes it to `.real/mcp-http.json`. To keep one token across runs (so a
client config can name `${REAL_MCP_TOKEN}`), set it to a long random value,
for example the output of `openssl rand -hex 32`.
