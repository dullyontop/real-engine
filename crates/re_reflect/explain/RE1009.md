# RE1009: Invalid value

The value has the right kind but is not valid for the field: for example a
quaternion that is zero or not finite, a vector with a non-finite component, or an
entity reference to an id that does not exist.

## Example

```text
error[RE1009]: Weld.other: no entity with id "crates"
```

## How to fix it

Check the value. Quaternions must be non-zero (they are normalised on write);
entity references must name an existing entity's stable id, or be `null`.
