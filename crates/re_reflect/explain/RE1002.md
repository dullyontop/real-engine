# RE1002: Unknown field

A component was found, but it has no field of the given name. The message lists
every field of the component in declaration order, and suggests the closest one
when the name looks like a typo.

## Example

```text
error[RE1002]: component RigidBody has no field "mas" (did you mean "mass"?); fields are: kind, mass, friction, restitution
```

## How to fix it

Use one of the listed field names. `real describe` shows each component's
fields with their types, defaults and docs.
