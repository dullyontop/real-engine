# RE1006: Non-finite number

A float field was given NaN or an infinity. Non-finite numbers are rejected
everywhere, so they never reach a scene file (JSON cannot represent them, and
serde_json would silently write `null`).

## Example

```text
error[RE1006]: Light.intensity: expected a finite number, found NaN
```

## How to fix it

Find where the value is computed (a division by zero, an uninitialised variable)
and pass a finite number.
