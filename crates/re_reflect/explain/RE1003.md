# RE1003: Value has the wrong type for its field

The value given for a field has the wrong kind. Field types form a closed set:
`bool`, `i32`, `i64`, `f32`, `f64`, `vec3`, `quat`, `color`, `string`, `entity`
and unit enums. Vectors are written `[x, y, z]` (or `{"x": .., "y": .., "z": ..}`),
quaternions `[x, y, z, w]`, colours `[r, g, b]` or `[r, g, b, a]`, entity references
as the target's stable id string or `null`, and enum values as the variant name.

## Example

```text
error[RE1003]: Transform.translation: expected vec3 as [x, y, z], found list of 2
```

## How to fix it

Write the value in the form the message names. Integers are accepted for float
fields, and integral floats (such as `3.0`) for integer fields.
