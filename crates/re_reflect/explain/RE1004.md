# RE1004: Number out of range for its field

The number does not fit the field's type: an `f32` field cannot hold a value
whose magnitude exceeds `f32::MAX` (about 3.4e38), and an `i32` field cannot hold a
value outside -2147483648..=2147483647.

## Example

```text
error[RE1004]: RigidBody.mass: 1e300 is out of range for f32
```

## How to fix it

Use a smaller value, or a field of a wider type (`f64`, `i64`) if the component
is yours.
