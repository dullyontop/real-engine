# RE1011: Malformed component schema

A component declaration or a full list of field values is malformed: a component
or field name that is not an identifier (`[A-Za-z_][A-Za-z0-9_]*`), a field declared
twice, a non-null default for an entity field, an unknown field type in a scene
file's `script_components`, or a value list whose length does not match the fields.

## Example

```text
error[RE1011]: component name "my health" must be an identifier
```

## How to fix it

Use identifier names and one of the field types `bool`, `i32`, `i64`, `f32`,
`f64`, `vec3`, `quat`, `color`, `string`, `entity` or `enum` (with variants).
