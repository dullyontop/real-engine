# RE1001: Unknown component

A component was named that is not registered. Component names are case-sensitive
identifiers such as `Transform` or `RigidBody`; script-defined components exist only
after the script (or the scene file's `script_components` list) declares them.

When the name is close to a registered one, the message suggests it.

## Example

```text
error[RE1001]: unknown component "Rigidbody" (did you mean "RigidBody"?)
```

## How to fix it

Use the suggested name, or list the registered components with `real describe`.
If the component is defined by a script, make sure the script runs (or the scene
declares it under `script_components`) before the component is used.
