# RE1005: Fractional number for an integer field

An integer field (`i32` or `i64`) was given a number with a fractional part.
Integral floats such as `3.0` are accepted; `2.5` is not.

## Example

```text
error[RE1005]: Collider.layer: expected an integer, found 2.5
```

## How to fix it

Round the value to a whole number before writing it.
