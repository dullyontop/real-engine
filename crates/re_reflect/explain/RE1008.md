# RE1008: Component name already registered

A script or agent tried to declare a component type whose name is already
registered, either as a built-in, a Rust component or an earlier script component.
Component names are unique.

## Example

```text
error[RE1008]: component type "Transform" is already registered
```

## How to fix it

Choose another name. To change the fields of a script component, restart the
session (script components are declared once per world).
