# RE9806: Rojo project file malformed

A Rojo-style project could not be read: the `*.project.json` file is not valid
JSON, its `tree` is missing or is not a place (`"$className": "DataModel"`), a
`$path` does not exist, or a `*.model.json` or `*.meta.json` file is malformed.
As a warning, it also names a file in a mapped directory that maps to no
instance (an image, for example); that file is skipped.

## Example

```text
error[RE9806]: the project's tree is not a place: its "$className" must be "DataModel"
  --> default.project.json
```

## How to fix it

Fix the file the message names. Only place projects can be imported: a model
project has no services to go into.
