# RE9809: Place file malformed

A place or model file (`.rbxl`, `.rbxm`, `.rbxlx` or `.rbxmx`) could not be
read. The binary reader refuses a file whose header is wrong, a chunk that does
not decompress or runs past its end, a count past the importer's limits
(256 MB per chunk, ten million instances) or a parent chain that loops. The XML
reader refuses a document that does not parse, has no `roblox` element of
version 4, nests deeper than 2048 elements or uses a referent twice. Nothing
is imported from a malformed file.

## Example

```text
error[RE9809]: Map.rbxl is not a readable place file: chunk PROP at byte 4120 does not decompress
  --> Map.rbxl
```

## How to fix it

Save the place again from the editor that made it, as binary or as XML, and
import the new file. A file cut short by a download or a copy is the usual
cause.
