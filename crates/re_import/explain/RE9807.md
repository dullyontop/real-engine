# RE9807: Imported script does not compile

A script the input declares does not compile as Luau. It is imported anyway,
so the error can be fixed in the project, but it will fail when it runs. The
location names the script's file in the project and the line of the error.

## Example

```text
warning[RE9807]: ReplicatedStorage.Shared.Util does not compile: Expected identifier when parsing expression, got 'then'
  --> scripts/ReplicatedStorage/Shared/Util.luau:12
```

## How to fix it

Fix the script in the input and import again, or fix the file in the project.
