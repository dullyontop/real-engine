# RE9801: Import input unreadable

`real import` was given an input it cannot read: the path does not exist, a
directory has no `default.project.json`, a loader file is not UTF-8 text, or
the file is a binary or XML place or model (`.rbxl`, `.rbxlx`, `.rbxm`,
`.rbxmx`), which the importer does not read yet.

The importer reads two forms: a Rojo-style project (a `*.project.json` file,
or a directory holding `default.project.json`) and a Studio command-bar loader
script (any other text file).

## Example

```text
error[RE9801]: game.rbxl is a place or model file, which the importer does not read yet
  --> game.rbxl
  = hint: export the scripts as a Rojo project, or use a loader script
```

## How to fix it

Pass the project file or the loader script. For a place file, export its
scripts with a Rojo-style tool first.
