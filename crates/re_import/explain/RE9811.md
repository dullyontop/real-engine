# RE9811: Place file property not imported

A property saved in a place file maps to nothing the compatibility layer can
set: its class is not implemented, the property is not, or it is read-only.
The instance is imported without it. One warning names each class and property
with how many instances had it. Terrain voxels and solid-modelling (union)
geometry are reported here too; they are not imported.

## Example

```text
warning[RE9811]: Map.rbxl: Beam.CurveSize0 is not imported (12 instances): the compatibility layer does not set it
  --> Map.rbxl
```

## How to fix it

Nothing needs fixing to import the rest. `real compat status` lists what the
compatibility layer implements; set what matters by hand or in a script.
