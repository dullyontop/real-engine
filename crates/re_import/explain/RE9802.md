# RE9802: Loader script does not parse

The loader script given to `real import` is not valid Luau, so the importer
cannot read it. Nothing is imported. A common cause is a script source whose
long-bracket string lost its closing `]=]`, so the rest of the file is read as
part of the string.

## Example

```text
error[RE9802]: the loader does not parse: unexpected token `end`
  --> loader.luau:120:1
  = hint: nothing was imported; fix the file or regenerate it
```

## How to fix it

Fix the file at the line shown, or regenerate the loader with the tool that
wrote it.
