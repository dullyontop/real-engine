# RE9810: Unknown value type in a place file

A property in a place file has a value type the importer does not know, so the
property is skipped and the rest of the file is imported. One warning names
each class, property and type.

## Example

```text
warning[RE9810]: Map.rbxl: Part.Future has value type 0x30, which the importer does not know; the property is skipped
  --> Map.rbxl
```

## How to fix it

Nothing needs fixing to import the rest. If the property matters, set it in the
imported project by hand.
