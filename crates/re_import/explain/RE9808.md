# RE9808: Import write failed

The import was planned but a file could not be written or deleted in the
project directory (permissions, a full disk, a path that is a directory).
Scripts are written before the scene, so the scene on disk still matches the
files it names, but some script files may already hold the new text.

## Example

```text
error[RE9808]: cannot write scripts/ReplicatedStorage/Net.luau: Permission denied (os error 13)
  --> my-game/scripts/ReplicatedStorage/Net.luau
```

## How to fix it

Fix the cause the message names and import again; importing is idempotent.
