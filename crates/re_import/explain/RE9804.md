# RE9804: Project cannot take an import

`real import --project DIR` writes into `DIR`. That works when `DIR` does not
exist or is empty (a new project is created), or when it is a compat project:
its `real.toml` has `[compat]` with `api = "roblox"`, and its entry scene
follows the compat scene conventions (a `game` root of class `DataModel`).

This error means `DIR` holds something else, its `real.toml` or entry scene
cannot be read, or the imported scene would break the conventions. Nothing
was written.

## Example

```text
error[RE9804]: the project is not a compat project: real.toml has no [compat] section
  --> my-game/real.toml
```

## How to fix it

Import into a new directory, or into a project made by
`real new --template roblox`. To convert a native project, add the
`[compat]` section yourself and make sure its scene has the `game` root.
