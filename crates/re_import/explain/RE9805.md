# RE9805: Instance not imported

One instance of the input could not be imported; the rest of the input was.
The report's `failed` list names it with the reason:

* its service or class is not defined by the compatibility layer yet;
* a property or attribute value could not be set through the class layer;
* `Source` was set on an instance that is not a script;
* an instance an earlier import created is stale but holds instances the
  importer did not create, so it was kept.

As a warning, the code also marks a duplicate script entry (the later entry
wins, as when the loader runs in Studio) and an instance the loader would
replace but the importer keeps, because it never removes what an import did
not create.

## Example

```text
failed ServerStorage.Tools.Lamp (Tool): unknown class "Tool": the class layer does not define it
```

## How to fix it

For an unknown class or property, check `real check --corpus` and the
coverage table: the class may come with a later work package. For a kept
instance, move or delete the instances the message names, then import again.
