# RE7608: Animation graph clip cannot be loaded

A clip node (or an additive layer's `reference`) names a clip,
`<model path>#<clip name>`, that cannot be loaded or sampled. The related
diagnostic says why: the model is missing, it has no clip of that name, or the
clip's keyframes are malformed.

## Example

```text
error[RE7608]: animation graph: node `run` plays clip `models/hero.glb#Run`, which cannot be loaded
```

## How to fix it

Check the model path and the clip's name (they are case sensitive), or
re-export the animation.
