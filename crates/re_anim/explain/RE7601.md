# RE7601: Unknown easing name

A tween was given an easing name that does not exist. Names are snake case.

The easings are `linear`, `quad_in`, `quad_out`, `quad_in_out`, `cubic_in`,
`cubic_out`, `cubic_in_out`, `sine_in`, `sine_out`, `sine_in_out`, `expo_in`,
`expo_out`, `back_out`, `elastic_out` and `bounce_out`.

## Example

```text
error[RE7601]: unknown easing `easeOutQuad`
  = hint: use one of: linear, quad_in, quad_out, ...
```

## How to fix it

Use one of the names above, for example `quad_out` instead of `easeOutQuad`.
