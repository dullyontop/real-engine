# RE7609: Unknown or mistyped graph parameter

A script (`anim.set`, `anim.get`, `anim.trigger`) or a command
(`anim.set_param`) named a parameter the entity's animation graph does not
have, or gave it a value of the wrong type: a float parameter takes a number,
a bool parameter `true` or `false`, and a trigger is set with `anim.trigger`.
The message lists the graph's parameters with their types.

## Example

```text
error[RE7609]: animation graph parameter `sped`: the graph has no such parameter; the graph's parameters: `speed` (float), `grounded` (bool), `jump` (trigger)
```

## How to fix it

Use one of the listed names with a value of its type, or add the parameter to
the graph.
