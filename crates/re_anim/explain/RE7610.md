# RE7610: Mask joint missing from the skeleton

A joint mask names a joint the skin it is bound to does not have. This is a
warning, not an error, so that one mask can serve skeletons that differ a
little: the entry is skipped and the rest of the mask applies.

## Example

```text
warning[RE7610]: animation graph: mask `upper` names joint `Spine2`, which skin `Rig` lacks
```

## How to fix it

If the joint should exist, check its name in the model (names are case
sensitive). Otherwise remove the entry, or ignore the warning.
