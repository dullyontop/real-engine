# RE7600: Malformed animation clip

An animation clip has a channel that cannot be sampled. Each channel (the
translation, rotation or scale keyframes of one target) needs:

- at least one key time;
- key times that are finite and strictly increasing;
- one value per key time, or three per key time (in-tangent, value,
  out-tangent) for cubic-spline interpolation.

Clips imported from glTF by `re_assets` already follow these rules, so this
usually means a clip was built or edited by hand, or the glTF file is broken.

## Example

```text
error[RE7600]: clip `open`: the rotation channel of `Door` has 3 key times and 2 values (Linear needs 1 value(s) per key, times finite and strictly increasing)
```

## How to fix it

Re-export the animation from your modelling tool, or fix the clip data so
every channel has matching times and values.
