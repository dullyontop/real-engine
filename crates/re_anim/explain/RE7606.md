# RE7606: Malformed skin

A skin cannot be posed. A skin (ADR-0039) needs:

- one inverse bind matrix and one joint bound per joint;
- every joint's parent listed before the joint;
- at most 65,535 joints.

Skins imported from glTF always meet these rules, so this error means the skin
data was built or edited by hand, or comes from a stale cache.

## Example

```text
error[RE7606]: skin `rig`: 52 joints, 50 inverse bind matrices and 52 joint bounds
```

## How to fix it

Re-import the model (delete the project's `.real/cache/` if the file did not
change). Code that builds a `SkinData` should check it with
`SkinData::is_well_formed`.
