# RE7602: Invalid tween duration

A tween's duration must be a finite number of seconds, zero or more. A
duration of zero is allowed and finishes the tween at once, at its end value.

## Example

```text
error[RE7602]: tween duration must be a finite number of seconds >= 0, got -1
```

## How to fix it

Pass a duration of zero or more seconds. If the duration is computed (for
example a distance divided by a speed), check for a zero or negative speed.
