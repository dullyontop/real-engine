# RE7605: Unknown animation priority

An animation clip or track was given a priority name that does not exist.
Names are written in upper camel case and must match exactly.

The priorities, from lowest to highest, are `Core`, `Idle`, `Movement`,
`Action`, `Action2`, `Action3` and `Action4`.

## Example

```text
error[RE7605]: unknown animation priority `action`
  = hint: use one of: Core, Idle, Movement, Action, Action2, Action3, Action4
```

## How to fix it

Use one of the names above with the same capitalisation.
