# RE7603: Unknown pose easing name

A keyframe pose was given an easing style or direction name that does not
exist. Names are written in upper camel case and must match exactly.

The styles are `Linear`, `Constant`, `Cubic`, `Elastic`, `Bounce` and
`CubicV2`. The directions are `In`, `Out` and `InOut`.

## Example

```text
error[RE7603]: unknown pose easing style `cubic`
  = hint: use one of: Linear, Constant, Cubic, Elastic, Bounce, CubicV2
```

## How to fix it

Use one of the names above with the same capitalisation, for example `Cubic`
instead of `cubic`.
