# RE7611: Blend tree cycle

A blend tree node uses itself, directly or through other nodes: a blend space
child, or an additive node's `base` or `additive`, leads back to the node. A
graph with a cycle cannot be evaluated. The message lists the nodes around the
cycle.

## Example

```text
error[RE7611]: the blend tree has a cycle: `move` -> `lean` -> `move`
```

## How to fix it

Point one of the listed references at another node.
