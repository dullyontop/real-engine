# RE7607: Invalid animation graph

An animation graph (`*.animgraph.json`, ADR-0039) breaks one of its rules.
The message names the element by its path in the file, such as
`layers[0].transitions[2].to`, and says what is wrong with it.

The rules:

- `format` is `real-engine/animgraph` and `version` is 1.
- Ids are not empty and are unique among the parameters, nodes, layers and
  masks, and among each layer's states and transitions. No state is called
  `any`.
- Every node, parameter, state and mask a graph element names exists.
- Blend spaces and blend weights read float parameters; a `bool` condition
  reads a bool parameter and a `trigger` condition a trigger.
- Blend spaces have at least one child; 1D children are sorted by threshold
  and 2D children have distinct points.
- Layer and mask weights are from 0 to 1; transition durations and exit times
  are 0 or more; numbers are finite.
- Only an additive layer has a `reference`.

## Example

```text
error[RE7607]: animation graph: `layers[0].transitions[1].to` names state `jump`, which the layer lacks
```

## How to fix it

Correct the named element, in the file or with `animgraph.edit`, and check the
result with `animgraph.validate`.
