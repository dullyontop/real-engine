# RE2052: Not a path of the document's kind

A document command was given a path it cannot use: one that does not end with
its kind's suffix (a material is `*.material.json`, a scene `*.scene.json`, a
prefab `*.prefab.json`), or one outside the project (absolute, or with `..`).
Paths are relative to the project folder, with `/` between folders.

Nothing changes.

## Example

```text
error[RE2052]: `materials/rock.json` is not a material path: a material file ends with `.material.json`
  --> materials/rock.json
```

## How to fix it

Give the path relative to the project, ending with the kind's suffix, such as
`materials/rock.material.json`.
