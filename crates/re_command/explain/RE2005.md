# RE2005: Invalid command arguments

The arguments of a command, or an operation inside `scene.apply`, do not match the
input schema: a required argument is missing, an unknown one is present, or one
has the wrong JSON type.

## Example

```text
error[RE2005]: invalid arguments for entity.set: missing field `field`
```

## How to fix it

Read the command's input schema with `command.describe {"name": "<command>"}` and
send arguments that match it.
