# RE2007: Undo or redo failed

The inverse operations of the last transaction could not be applied, because the
world changed in a way the history did not record (for example a runtime despawn
outside a transaction). The history is left as it was.

The same code reports a failed rollback: when a transaction is rejected, or a dry
run is undone, and one of the inverse operations does not apply. The remaining
inverses are still applied, but the world may be partly changed.

An undo or redo of `set_doc` edits is also refused when the open document they
edited was reopened (for example reloaded from disk after it changed there) or
closed since. Its JSON pointers would land in a different document, so nothing
is applied, and every history entry that edited that document is dropped.

## Example

```text
error[RE2007]: undo failed: command 0: no entity with id "crate"
error[RE2007]: undo failed: command 0: graphs/island.graph.json was reopened or closed since this edit, so its undo history was dropped
```

## How to fix it

Make every scene change through a transaction so the history stays exact. Reload
the scene to start with a clean history. For a reopened document, make the edit
again on the document as it is now.
