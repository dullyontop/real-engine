# RE2002: Component already present

`add_component` (or `component.add`) was used on an entity that already has the
component. An entity has at most one component of each kind.

## Example

```text
error[RE2002]: entity already has a RigidBody component; use set_field to change it
```

## How to fix it

Change the existing component's fields with `set_field` (`entity.set`), or remove
it first with `remove_component` if you want to start from the defaults.
