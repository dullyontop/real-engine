# RE2001: Transaction rejected

One operation of a transaction failed, so every operation before it was rolled
back and the scene is exactly as it was. The message names the zero-based index of
the failing operation; the diagnostic in `related` gives the cause with its own
code (for example `RE1200` for an unknown id). The log records the transaction as
`rejected`.

## Example

```text
error[RE2001]: command 2: no entity with id "crates"
  = related: error[RE1200]: no entity with id "crates"
```

## How to fix it

Fix the operation the message names (see the related diagnostic) and send the
whole transaction again. Use `"dry_run": true` to check a transaction without
applying it.
