# RE2054: A file the document names does not exist

A document command would make a document name a project file that does not
exist, such as a material whose `base_color_texture` is a texture that is not
in the project. The engine would fail to load it later; the command refuses it
now instead.

Nothing changes.

## Example

```text
error[RE2054]: material `base_color_texture` names `textures/rock.png`, which does not exist
  --> materials/rock.material.json
  = help: paths are relative to the project, for example `assets/textures/rock.png`; import a file with asset.import first
```

## How to fix it

- Check the path: it is relative to the project folder, with `/` between
  folders.
- Bring the file into the project first (`asset.import`, or the Assets
  panel's "Import…"), then name it.
