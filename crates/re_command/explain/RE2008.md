# RE2008: Document not valid

A transaction of `set_doc` operations left an open document (a project file the
World holds in memory, such as a `*.graph.json` graph) in a state that its kind's
validator refuses, so the whole transaction was rolled back. Each document kind
registers a validator by file suffix: `re_proc` registers `.graph.json`, which
checks the format, the version, unique node ids and that every edge names
existing nodes.

The document is checked once, after every operation of the transaction ran, so
a transaction may pass through invalid states (remove a node, then its edges).

## Example

```text
error[RE2008]: graphs/island.graph.json is not valid: edge 0 names node `h`, which does not exist
```

## How to fix it

Make the transaction leave the document valid: for example, remove a node's
edges in the same transaction as the node. Read the document's format (for
graphs, `graph.schema.json` from `real schema`) to see what it must contain.
