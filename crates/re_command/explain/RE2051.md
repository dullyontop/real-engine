# RE2051: The file or name exists

A command that makes a document, such as `material.create`, was asked to make
a file that exists already, or that is open in the editor with content (made
by an earlier command and not yet saved). Making a document never overwrites
one. A command that also adds a name, such as a scene name in `real.toml`'s
`[scenes]`, refuses a name that is taken in the same way.

Nothing changes.

## Example

```text
error[RE2051]: materials/rock.material.json exists already
  --> materials/rock.material.json
  = help: edit it with material.edit, or choose another path
```

## How to fix it

- To change the existing document, use its edit command (`material.edit`).
- To make a new one, choose a path (or name) that is free.
