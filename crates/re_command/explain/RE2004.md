# RE2004: Unknown command

No command of this name is registered. Command names are stable dotted names such
as `entity.set`; the message suggests the closest name when there is one.

## Example

```text
error[RE2004]: unknown command "entity.sett" (did you mean "entity.set"?)
```

## How to fix it

List the available commands with `describe`, or read one with
`command.describe {"name": "entity.set"}`.
