# RE2057: A configuration key or value real.toml cannot hold

`config.set` was given a key or a value that `real.toml` cannot hold:

- **A key** is a dotted path of bare TOML keys (letters, digits, `_` and
  `-`), with a number to index an array: `render.post.exposure`,
  `input.axes.move.1.dead_zone`. Quoted keys, empty segments and spaces are
  refused.
- **A value** is any JSON value except `null`, which TOML does not have: to
  remove a key, leave `value` out. A `null` inside a list or object is
  refused too.

Nothing changes.

## Example

```text
error[RE2057]: real.toml cannot hold `null` at `render.vsync`: TOML has no null; leave `value` out to remove the key
  --> real.toml
```

## How to fix it

- Write the key as dotted bare keys, such as `sim.fixed_hz`.
- To remove a key, call `config.set` with the key and no `value`.
