# RE2050: Document opened from a file cannot be emptied

A `set_doc` operation set an open document (a project file the World holds in
memory, such as a `*.material.json` material) to `null`. A `null` document is
absent: it has no file, and the next save removes the file it had. Only a
document that was opened absent, because a command is making its file in this
session, may be emptied again. So a command, an agent or an undo can remove a
file this session made, and never one that was there before.

The transaction is rolled back and nothing changes.

## Example

```text
error[RE2050]: materials/rock.material.json was opened from its file, so it cannot be emptied: a save removes only files this session made
```

## How to fix it

Edit the document's content instead of emptying it. To delete a project file,
delete it outside the engine; the editor reopens the documents whose files
change on disk.
