# RE2006: Engine unavailable

A command was sent through an engine handle (`re_command::remote`), but the engine
side of the channel is gone: the thread or process that owns the world stopped.

## Example

```text
error[RE2006]: the engine is not running (its request channel is closed)
```

## How to fix it

Start the engine again: `real do` opens the project for one command, and
`real edit` runs the editor. Then repeat the call.
