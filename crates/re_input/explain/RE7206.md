# RE7206: Replay file cannot be read or written

The replay file could not be read or written: it does not exist, a directory
is missing, or the process lacks permission.

## Example

```text
error[RE7206]: cannot read replay: No such file or directory (os error 2)
  --> tests/replays/island.replay.json
```

## How to fix it

Check the path (relative to the project root) and that the directory exists.
