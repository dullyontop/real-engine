# RE7200: Invalid input configuration

The `[input]` section of `real.toml` could not be read: the file is not valid
TOML, or `[input]` has a key other than `buttons` and `axes`, or a value of the
wrong type (for example a binding that is not a string).

## Example

```text
error[RE7200]: invalid `[input]` configuration: unknown field `button`, expected `buttons` or `axes`
  --> real.toml:12:1
```

## How to fix it

`[input]` has two tables. `[input.buttons]` maps each action to a list of
bindings, and `[input.axes]` maps each action to a list of axis sources:

```toml
[input.buttons]
jump = ["key:Space", "pad:South"]

[input.axes]
move = [{ composite = ["key:KeyW", "key:KeyS", "key:KeyA", "key:KeyD"] }, { stick = "left", dead_zone = 0.15 }]
```
