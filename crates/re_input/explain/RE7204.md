# RE7204: Invalid replay

A replay document (`tests/replays/*.replay.json`) is not consistent:

- its `version` is not one this engine reads;
- an `input` entry has both `down` and `axis`, or neither;
- `input`, `commands` or `checks` entries are not in frame order;
- an `input` entry is at or past `frames`.

## Example

```text
error[RE7204]: input entry 3 (frame 90, action `jump`) needs exactly one of `down` and `axis`
```

## How to fix it

Fix the entry, or re-record the replay. Button actions use `"down": true` or
`false`; axis actions use `"axis": [x, y]`.
