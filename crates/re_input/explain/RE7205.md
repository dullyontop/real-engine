# RE7205: Replay names an unknown action

A replay changes an action that the project's `[input]` section does not
define, or uses a button action as an axis (or the reverse). The replay was
probably recorded before the action was renamed or removed.

## Example

```text
error[RE7205]: input entry 1 (frame 30, action `walk`) names an action that `[input]` does not define
```

## How to fix it

Add the action back to `real.toml`, rename it in the replay, or re-record the
replay.
