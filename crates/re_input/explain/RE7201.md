# RE7201: Unknown input binding

A binding in `[input]` does not name a real control, so it would never fire.
Bindings have a device prefix and a name:

- `key:<KeyCode>`: a winit key code, by physical position, such as `key:KeyW`,
  `key:Space`, `key:ArrowUp`, `key:ShiftLeft`, `key:Digit1` or `key:F5`;
- `mouse:<button>`: `Left`, `Right`, `Middle`, `Back`, `Forward`, or `Other<n>`;
- `pad:<button>`: a gilrs gamepad button, such as `South` (A on Xbox, cross on
  PlayStation), `East`, `North`, `West`, `LeftTrigger`, `RightTrigger2`,
  `Start`, `Select` or `DPadUp`.

## Example

```text
error[RE7201]: unknown input binding `key:W` in [input.buttons] jump
  --> real.toml
  = hint: did you mean `key:KeyW`? ...
```

## How to fix it

Use the full winit name: letters are `KeyA` to `KeyZ` and digits are `Digit0`
to `Digit9`. The hint suggests the closest valid name.
