# RE7202: Invalid axis source

An entry in `[input.axes]` is not a valid axis source. Each source is a table
with exactly one of these keys:

- `composite = [up, down, left, right]`: four bindings;
- `stick = "left"` or `"right"`, with an optional `dead_zone` in `[0, 1)`
  (0.15 when left out);
- `mouse_delta = <scale>`: raw mouse motion times the scale.

## Example

```text
error[RE7202]: an axis source needs exactly one of `composite`, `stick` and `mouse_delta` in [input.axes] look, source 1
```

## How to fix it

Split a table that mixes kinds into separate sources, for example
`look = [{ mouse_delta = 0.002 }, { stick = "right" }]`.
