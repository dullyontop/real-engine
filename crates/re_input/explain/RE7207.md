# RE7207: Replay file is not valid

The replay file is not a valid replay document. It is not JSON, a key is
missing or unknown (unknown keys are errors), or a value has the wrong type.

## Example

```text
error[RE7207]: invalid replay: unknown field `frame_count`, expected one of `$schema`, `version`, `seed`, `frames`, `input`, `commands`, `checks` at line 1 column 46
  --> tests/replays/island.replay.json:1:46
```

## How to fix it

Compare the file with `schemas/replay.schema.json` (written by `real schema`).
The keys are `version`, `seed`, `frames`, `input`, `commands` and `checks`.
