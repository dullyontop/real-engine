# RE7203: Action is both a button and an axis

The same action name appears in `[input.buttons]` and in `[input.axes]`.
Gameplay reads a button action with `pressed`/`is_down` and an axis action
with `axis`, so one name cannot be both.

## Example

```text
error[RE7203]: action `move` is defined in both `[input.buttons]` and `[input.axes]`
```

## How to fix it

Rename one of them, for example `sprint` for the button and `move` for the
axis.
