# RE8902: No answer from the server

A client sent its handshake for the whole timeout (10 s unless `[net]
timeout_ms` says otherwise) and the server never answered.

## Example

```text
error[RE8902]: no answer from a server at 192.168.1.20:47800 after 10 s
```

## How to fix it

Check that the server is running (`real run --server`), that the address and
port are the ones it printed when it started, and that no firewall between the
machines blocks UDP on that port. On the server machine, allow incoming UDP on
the port.
