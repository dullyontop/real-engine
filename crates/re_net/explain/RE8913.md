# RE8913: Join code does not fit the server

A server either takes only players who give its join code or takes anyone,
and it says which in its first answer. This client stopped before the
handshake because the two do not fit: the server needs a code and the client
has none, or the client was given a code and the server takes none. The
message says which.

## Example

```text
error[RE8913]: the server at 192.168.1.20:47800 needs a join code
```

## How to fix it

- If the server needs a code, ask the host for the one the server printed
  when it started, and join with it.
- If the server takes no code, check that the address is the one the host
  gave, since the code may be for another server, or join without it.
