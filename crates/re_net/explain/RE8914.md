# RE8914: Server key does not match

Every server has a key, and prints its fingerprint when it starts: 16 letters
and digits such as `3QF7-M2XK-9TBA-6RHE`. A client given a server's
fingerprint joins only a server whose key has it, so no one between the
machines can pose as the server. The server at this address has another key.

## Example

```text
error[RE8914]: the server at 192.168.1.20:47800 has the key 8C2J-W5NV-T0QE-4HMA, not the pinned 3QF7-M2XK-9TBA-6RHE
```

## How to fix it

- If the server's key changed on purpose (its `net/server.key` file in the
  data folder was deleted, or the game moved to another machine), use the
  fingerprint the server prints now.
- If it did not, do not join: something between the machines may be posing
  as the server. Try again from another network.
