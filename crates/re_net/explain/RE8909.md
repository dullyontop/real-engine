# RE8909: This run cannot go online

`real run --server`, `--host` and `--connect` play a Roblox-style project
over the network (ADR-0050). This run cannot: the project has no `[compat]`
section in `real.toml`, or the game had already started when it was asked to
go online.

## Example

```text
error[RE8909]: online play needs a Roblox-style project ([compat] in real.toml)
  --> real.toml
```

## How to fix it

Run a project with a `[compat]` section. A project on the engine's own API
has no server and client contexts; a Rust game can use `re_net` directly.
