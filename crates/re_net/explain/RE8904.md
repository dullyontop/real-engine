# RE8904: Server full

The server already has as many players as it allows, so it refused one more.

## Example

```text
error[RE8904]: the server at 192.168.1.20:47800 is full
```

## How to fix it

Try again when a player has left. The server's operator can raise the limit
with `real run --server --max-players N` or `[net] max_players`.
