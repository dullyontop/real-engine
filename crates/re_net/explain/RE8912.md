# RE8912: Server refused the handshake

Online play is encrypted to the server's key, and a game's join code is part
of that key exchange (ADR-0067). The server could not open this client's
first handshake message, so it refused it: the client gave a join code the
server does not have, or something between the machines changed the message
on the way. The server cannot tell the two apart, so it says the same for
both.

## Example

```text
error[RE8912]: the server at 192.168.1.20:47800 refused the join code
```

## How to fix it

- Check the join code with the host. A server makes a new code each time it
  starts, so a code from an earlier game no longer works.
- If the client gave no code, the server's first answer said it needed none
  and its handshake refused the client anyway: something on the way may be
  changing packets. Try again from another network.
