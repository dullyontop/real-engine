# RE8903: Network version mismatch

The client and the server run engine builds whose network formats differ:
the packet layout (the first number) or the game layer's wire format (the
second). There is no compatibility between versions, because both ends must
replicate the same data the same way.

## Example

```text
error[RE8903]: the server at 192.168.1.20:47800 speaks network version 1.3, this client 1.2
```

## How to fix it

Run the same engine version on both machines: rebuild or download the same
release of `real`, or package the game once (`real build`) and run that build
everywhere.
