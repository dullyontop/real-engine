# RE8911: This platform cannot serve

A game in a browser is always a client: a page cannot listen for
connections, so it cannot run a server or host a game (ADR-0049 §10). This
run was asked to serve.

## Example

```text
error[RE8911]: a browser cannot serve a game; it can only join one
```

## How to fix it

Run the server on a desktop machine (`real run --server`, or the packaged
game with `real run --package DIR --server`) and connect the browser to it
with `ws://HOST:PORT`.
