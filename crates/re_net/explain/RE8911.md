# RE8911: This platform cannot serve

A game in a browser is always a client: a page cannot listen for
connections, so it cannot run a server or host a game (ADR-0049 §10). This
run was asked to serve.

## Example

```text
error[RE8911]: a game in a browser cannot serve: it can only join a server
```

## How to fix it

Run the server on a desktop machine, from the same build as the page:
`real run --package DIR --server` on the web build's folder, or a desktop
build of the same project with its executable's `--server`. Then open the
page with `?connect=ws://HOST:PORT/`. A server started from the project
itself (`real run --server`) turns the page's players away with `RE8905`,
because a build stores its scripts differently.
