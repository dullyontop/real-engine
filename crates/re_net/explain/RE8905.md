# RE8905: Server runs a different game

The client and the server do not run the same game: their game hashes
differ. The hash covers a packaged build's archive, or a project's scenes,
scripts and `real.toml`, so two copies of a project that differ in any of
those count as different games. A project and its build are different games
too, because the build stores its scripts compiled: `real run --connect`
from the project cannot join a server that runs the build.

## Example

```text
error[RE8905]: the server at 192.168.1.20:47800 runs a different game (its game is 6c1f0a93d2e4b781, this one is 0f9a3c5e77b21d40)
```

## How to fix it

Run the same build, or the same project content, on both machines: copy the
project again, or package it once with `real build` and use that build on
every machine. To join a built game's server from a machine that has the
project, run the build there: `real run --package DIR --connect HOST:PORT`.
