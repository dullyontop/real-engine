# RE8901: Address does not resolve

An address given to connect to, or to bind a server to, is neither an IP
address with a port nor a host name that resolves.

## Example

```text
error[RE8901]: cannot resolve the address `gameserver.lan`
```

## How to fix it

Write the address as `host:port`, for example `192.168.1.20:47800` or
`[::1]:47800`. Without a port, the default from `[net] port` is used. Check the
host name's spelling and that this machine can resolve it.
