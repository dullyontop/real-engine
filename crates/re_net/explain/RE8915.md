# RE8915: Join code or fingerprint does not parse

A join code is 10 letters and digits, shown as two groups of five
(`KD4RT-7XWQP`), and a server key's fingerprint is 16, in four groups of four
(`3QF7-M2XK-9TBA-6RHE`). Both use Crockford's base32: the digits and the
letters except I, L, O and U. Case, dashes and spaces do not matter, and I
and L read as 1 and O as 0, so a code read aloud still works. This one has
another symbol, or too few or too many.

## Example

```text
error[RE8915]: a join code is 10 letters and digits, such as KD4RT-7XWQP, and this is not one
```

## How to fix it

Copy the code or the fingerprint again from what the server printed, and
check that no symbol is missing. A message about a join code does not repeat
the code, since it is a secret.
