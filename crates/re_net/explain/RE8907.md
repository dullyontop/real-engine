# RE8907: Connection closed by the other end

The other end closed the connection on purpose: a server kicked the player
(`Player:Kick`) or shut down, or a client left. The message gives the reason
the other end sent, if any.

## Example

```text
error[RE8907]: the server at 192.168.1.20:47800 closed the connection: you were kicked: AFK
```

## How to fix it

Nothing is wrong with the network. Connect again if the server allows it.
