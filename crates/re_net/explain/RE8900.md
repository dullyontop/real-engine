# RE8900: Cannot open a network socket

A server or a client could not open its UDP socket: the port is in use by
another program, the address does not belong to this machine, or the
operating system refused (a firewall policy, or a port below 1024 without
the right permission).

## Example

```text
error[RE8900]: cannot open a UDP socket on 0.0.0.0:47800: Address already in use (os error 98)
```

## How to fix it

Stop the other program, or pick another port (`real run --server --port 47801`,
or `[net] port` in `real.toml`). With `--bind`, give an address of one of this
machine's network interfaces.
