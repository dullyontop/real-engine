# RE8916: No server key or random numbers

Online play needs secure random numbers for its keys, and a server needs its
key. A server that keeps its data loads its key from `net/server.key` in its
data folder (`.real/data/` in a project), and makes the file on its first run.
Either the platform gave no secure random numbers, or that file could not be
read, written or understood. The message says which, with the file's path.

## Example

```text
error[RE8916]: the server key file .real/data/net/server.key does not parse: no private-key line
```

## How to fix it

- A file that does not parse was changed or damaged: delete it, and the server
  makes a new key at its next start. Players who pinned the old fingerprint
  then refuse the server until they use the new one.
- A file that cannot be read or written: check the data folder's permissions,
  and that the disk is not full.
- No random numbers: every supported desktop system and browser has them, so
  the platform's random number source failed. Restart the machine or the
  browser.

The key file holds the server's private key. Keep it out of version control
(a project's `.real/` folder already is) and do not share it: whoever has it
can pose as the server.
