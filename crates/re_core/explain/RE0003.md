# RE0003: The worker pool could not be created

The operating system refused to start the worker threads of the engine's task
pool (`re_core::TaskPool`). This usually means the process hit a limit on the
number of threads or on memory for thread stacks.

## Example

```text
error[RE0003]: could not start 64 worker threads: Resource temporarily unavailable (os error 11)
  = hint: lower the worker count, or check the process thread limit
```

## How to fix it

- Ask for fewer worker threads. Zero picks the default: one fewer than the
  number of cores, and at least one.
- Check the limits of the environment, such as `ulimit -u` on Linux or the
  `pids.max` of a container.
