# RE0002: Logging is already initialised

`init_logging` was called after a global log subscriber had already been
installed in this process. Only one global subscriber can exist, and it cannot
be replaced.

## How to fix it

Call `re_core::init_logging` exactly once, at the start of `main`, before any
other code installs a subscriber. Tests should not call it; they build a
subscriber with `re_core::log::subscriber` and install it for one closure with
`tracing::subscriber::with_default`.
