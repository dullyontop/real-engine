# RE0001: Invalid log filter

The log filter is not a valid list of `tracing` directives, so logging could not
be set up.

A filter is a comma-separated list of directives. Each directive is a level
(`error`, `warn`, `info`, `debug`, `trace` or `off`), a target with a level
(`re_render=debug`), or a target alone (which enables every level for it).

## Example

```text
error[RE0001]: invalid log filter `info,re_render=loud`: invalid filter directive
```

## How to fix it

Correct the filter, for example:

```text
info,re_render=debug,re_physics=warn
```

When `RUST_LOG` is set to a valid filter, it replaces the configured one.
