# RE0004: The global worker pool is already initialised

`TaskPool::init_global` was called after the process-wide worker pool already
existed. The pool is created once: either by an earlier `init_global` call, or
on first use by `TaskPool::global()` with the default thread count.

## How to fix it

Call `TaskPool::init_global(threads)` once, at startup, before anything uses the
pool. If the default thread count is fine, do not call it at all.
