# RE8805: The clipboard does not hold entities

Ctrl+V in the editor pastes entities copied with Ctrl+C (in this editor or
another one), or the text of a scene file. This note means the clipboard held
something else, so nothing was pasted.

## Example

```text
note[RE8805]: nothing was pasted: the clipboard does not hold entities
  = hint: copy entities in the editor first; the clipboard takes the editor's own format or a scene file's text
```

## Causes

- The clipboard holds other text, such as a line copied from a script.
- The text is in the editor's format (`"format": "real-engine/entities"`)
  but cannot be read: it was edited by hand, it is another version of the
  format, or an entity does not come after its parent.
- The text is a scene file that does not parse.

## How to fix it

Select the entities in the Hierarchy or the view and press Ctrl+C, then
Ctrl+V. An agent that writes the clipboard itself writes

```json
{ "format": "real-engine/entities", "version": 1,
  "subtrees": [ { "world": [16 numbers, column-major],
                  "entities": [ { "id": "crate_1", "components": { "Transform": {} } } ] } ] }
```

with each subtree's root first and every other entity after its parent, as a
scene file lists them.
