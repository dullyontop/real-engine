# RE8808: A pasted reference was cleared

A component field can refer to another entity (a camera's target, a joint's
other body). When copied entities are pasted, a reference to another pasted
entity follows it to its copy, and a reference to an entity that exists
where they are pasted is kept. This note means the referred entity is
neither: it does not exist here (it was in another project, or it has been
deleted), so the field was cleared.

## Example

```text
note[RE8808]: the copy of door_1 refers to frame_2 in Hinge.body, which does not exist here: the reference was cleared
```

## How to fix it

Set the field again in the Inspector, or copy the referred entity together
with the one that refers to it, so the reference follows the copy.
