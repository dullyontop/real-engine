# RE8803: Inspector text is not a valid value

Some inspector fields are typed as text: an entity reference is typed as the
entity's id, a map's key as its name, and a graph parameter as a JSON value.
The editor reads the text when you press Enter or leave the field; this error
means it could not.

## Example

```text
error[RE8803]: `[1, 2` is not a JSON value for graph parameter terrain.height: EOF while parsing a list
  = help: type a JSON value: a number, true or false, a string in quotes, or a list
```

## How to fix it

- For an entity reference, type the id of an existing entity (the hierarchy
  shows each id), choose one from the list behind `…` or with "pick" in the
  viewport, or clear the field for no entity.
- For a map's key, type a name that no other entry of the map has; a key
  cannot be empty (remove the entry with `×` instead).
- For a graph parameter, type a JSON value, such as `12.5`, `true`, `"sand"` or
  `[1, 2, 3]`; `null` removes the override.

Nothing was changed: the field keeps its previous value.
