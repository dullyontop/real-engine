# RE8850: A parameter's value does not fit its schema

The node canvas and the Procedural panel give each node parameter a widget
from its node kind's schema: a checkbox, a drag or slider, a list of choices,
a colour or a file picker, a list or map editor. A parameter whose schema has
no such widget, such as a list of records, is typed as JSON text. This
warning says that a value does not fit the parameter's schema, in one of two
ways:

- **Typed text.** Text typed into a parameter's JSON box is not JSON, or is
  JSON of another type than the parameter takes. Nothing was changed: the
  parameter keeps its value.
- **A value in the file.** The graph file (or the source's
  `GraphSource.params`) gives the parameter a value of another type than its
  schema's, such as `"size": "big"` for a whole number, so its widget cannot
  show it. The editor shows the value as JSON text instead, and generation
  reports the node's own error when it runs.

## Example

```text
warning[RE8850]: `[{"tag": "tree"` is not JSON: EOF while parsing an object at line 1 column 15, so parameter `choices` of node `pick` is unchanged
  --> graphs/island.graph.json
  = help: type a JSON value of the parameter's type (its description says what it takes): a number, true or false, a string in quotes, a list in [ ] or an object in { }
```

```text
warning[RE8850]: parameter `size` of node `h` is "big", which is not of its type (integer), so it is shown as JSON text
  --> graphs/island.graph.json
  = help: set a value of its type, or remove it so the node kind's default applies
```

## How to fix it

- Hover the parameter's name: its description says what it takes.
- Type a whole JSON value of that type, such as `[{"tag": "tree", "weight": 2}]`
  for a list of records, or press Escape to leave the box unchanged.
- For a value in the file, type a value of the right type into the box, or
  press × to remove it so the node kind's default applies.

A value of the right type can still be refused by the node kind (a number out
of its range, for example); that refusal comes from the command, with the
node kind's own code.
