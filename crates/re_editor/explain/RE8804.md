# RE8804: The editor layout could not be read

The editor saves where its panels are docked, the gizmo's mode, orientation
and snapping, the editor camera, what the view shows and the selection in the
project's `.real/editor/layout.json`. It is editor state, not part of the
project: it is not under version control and no command changes it. This
warning means the file is there but the editor could not use it.

## Example

```text
warning[RE8804]: the editor layout my-game/.real/editor/layout.json could not be read: unknown variant `Profiler`, expected one of `Viewport`, `Hierarchy`, `Inspector`, `Graph`, `Console`, `Debugger` at line 40 column 22
  = help: the default layout is used; it replaces the file when the layout next changes
```

## Causes

- The file was edited by hand and is no longer valid JSON.
- It was written by a newer editor, with a panel or a layout version this
  editor does not know.

## How to fix it

Nothing needs fixing: the editor opens with the default layout, and saves
over the file as soon as you move a panel or the camera, select something or
change a setting. To start from the default layout on purpose, delete the
file.
