# RE8802: Invalid command-palette arguments

The command palette (`Ctrl+P` in the editor) runs any registered command with
the arguments typed into its text box. The arguments must be one JSON object,
like the `args` of `real do` or an MCP tool call.

## Example

```text
error[RE8802]: the arguments of `entity.spawn` are not a JSON object: expected `:` at line 1 column 8
  = help: type a JSON object such as {"name": "Rock"}; the palette lists the command's fields
```

## How to fix it

Write the arguments as a JSON object whose keys are the command's fields, as
listed under the command in the palette (or by `real do command.describe
--args '{"name": "<command>"}'`). A command without arguments takes `{}`.
