# RE8801: The editor window could not be opened

`real editor` draws into a window. It needs a display (an X11 or Wayland
session on Linux) and a GPU adapter that can present to the window's surface.
This error means the event loop, the window or its surface could not be
created.

## Example

```text
error[RE8801]: cannot open the editor window: the event loop could not be created
  = help: run it in a desktop session, or under a virtual display: xvfb-run -a real editor
```

## How to fix it

- Run `real editor` from a desktop session, or under a virtual X server
  (`xvfb-run -a -s "-screen 0 1280x720x24" real editor`).
- If a GPU error is listed with it (`RE6002`, `RE6004`), pick another backend
  with `RE_BACKENDS=gl` or `RE_BACKENDS=vulkan`.
- To edit without a window, use `real do <command>` or `real mcp`: they take
  the project lock themselves when no editor is running.
