# RE8806: A paste names a component the project does not define

A copied entity carries its components by name. When one of them is not
defined in the project you paste into (usually a script component of the
project it was copied from), the editor refuses the whole paste rather than
paste the entities without it.

## Example

```text
error[RE8806]: nothing was pasted: door_1 has the component `Hinge`, which this project does not define
  = hint: define the component in this project (a script component), or remove it from the copied text
```

## How to fix it

- Define the component in this project: copy the script that declares it,
  with the same fields, then paste again.
- Or paste the copied text into a text editor, remove the component from
  each entity that has it, copy the text again and paste it into the editor.

Nothing was changed: the paste is one edit, and it was not made.
