# RE8852: A builder graph is read-only on the canvas

A procedural source's graph comes from a graph file (`GraphSource.graph`) or
from a builder script (`GraphSource.builder`), a Luau script that returns the
graph when the scene loads. The node canvas shows both, but it edits only
graph files: a builder's graph is made again from the script whenever the
script changes, so an edit made on the canvas would be lost.

So the canvas shows a builder's graph read-only: it has no menus, wires
cannot be connected or cut, the parameter widgets are disabled, and a node
moved or a wire rerouted goes back when the mouse button is released.
Collapsing nodes still works. This note says so the first time an edit is
tried on that source's graph; nothing was changed.

## Example

```text
note[RE8852]: the graph of `island` is made by the builder script scripts/tools/island_graph.luau, so the canvas shows it read-only
  --> entity `island`
  = help: edit the script, or press "Convert to a graph file" to edit the graph on the canvas; parameter overrides still work in the Procedural panel
```

## How to fix it

- Edit the builder script ("Open script" names it): the graph is made again
  from it.
- Or press "Convert to a graph file" (`proc.convert_builder`): it makes
  `graphs/<source>.graph.json` holding the graph as the canvas shows it, and
  the source reads its graph from that file from then on, so the canvas can
  edit it. One undo puts the builder back.
- To try other values for one source without changing its graph, set
  parameter overrides in the Procedural panel (`graph.set_param`).
