# RE9402: Data file unreadable

A data file under the project's `.real/data/` directory, or under its
`data/seed/` directory, did not read or did not write. A file that does not
parse is renamed to `<file>.bad` and its store or structure starts empty, so
the run continues. A failed write keeps the change for this run only.

## Example

```text
warning[RE9402]: 501: the data file datastore/_^coins/_global.json did not read (expected value at line 1 column 3); it was set aside as datastore/_^coins/_global.json.bad and the store starts empty
```

## How to fix it

Look at the `.bad` file: it is JSON in the format `real-engine/datastore`
version 1 and can be repaired and renamed back, or deleted. Edit data files
only while the game is not running. For a write that failed, check that the
`.real/data/` directory is writable and the disk has space.
