# RE9302: Player step refused

A host step about players could not run:
* `say`, `remove_player` or another player step named an entity that is not
  a `Player` under `Players` (it left, or the id is wrong);
* `[compat] players` in `real.toml` is 0. A game starts with at least one
  player, the client's local player.

## Example

```text
error[RE9302]: say: the entity is not a Player in the game
```

## How to fix it

Name a player that is in the game when the step runs: players join in order
as `Player1`, `Player2`, and so on, and a player that left must join again
before it can act. Set `players` to 1 or more, or leave it out (the default
is 1).
