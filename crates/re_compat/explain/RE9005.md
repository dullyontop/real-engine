# RE9005: Read-only property

A script assigned to a property that scripts may only read, such as an
instance's `ClassName`. The engine keeps such properties up to date itself.

## Example

```text
error[RE9005]: Instance.ClassName is read-only
  --> scripts/server/main.luau:7
```

## How to fix it

Remove the assignment. To get an instance of another class, create one with
`Instance.new` and move the children over.
