# RE9352: Property cannot be tweened

`TweenService:Create` was given a goal for a property whose type has no
interpolation. Numbers, booleans, `Vector3`, `Vector2`, `CFrame`, `Color3`,
`UDim`, `UDim2`, `Rect` and `NumberRange` properties can be tweened. Enum
items, strings, instances and sequences cannot.

## Example

```text
error[RE9352]: Part.Material (Enum.Material) cannot be tweened
  --> scripts/client/door.luau:12
```

## How to fix it

Set the property directly when the tween completes, for example from the
tween's `Completed` event.
