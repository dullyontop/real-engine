# RE9200: Character rig could not be built

The engine builds a character from its rig data (the R6 or R15 layout in
`crates/re_compat/assets/rigs/`) and a `HumanoidDescription`. One of them was
malformed: a joint names a part the rig does not have, a size or scale is not
a positive number, or the rig type is neither R6 nor R15.

## Example

```text
error[RE9200]: HumanoidDescription.HeightScale must be a positive number, got -1
  --> scripts/server/spawn.luau:12
```

## How to fix it

Give every scale in the `HumanoidDescription` a positive value, and use
`Enum.HumanoidRigType.R6` or `Enum.HumanoidRigType.R15`. If the message names
a rig data file, the engine's own data is broken: report it.
