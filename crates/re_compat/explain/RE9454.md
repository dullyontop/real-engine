# RE9454: Unreliable message too large

An `UnreliableRemoteEvent` was fired with arguments too large for one
datagram (about 1,150 bytes once encoded), so it was dropped on the sender, as
the vendor drops oversized unreliable payloads. Unreliable events are never
split across packets.

## Example

```text
warning[RE9454]: an UnreliableRemoteEvent message of 1480 bytes was dropped: more than fits in one datagram (1150)
```

## How to fix it

Send less in each event, or use a `RemoteEvent`, which is reliable and can be
large.
