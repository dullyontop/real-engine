# RE9400: Data store request rejected

A `DataStoreService` call was refused before it reached the store. The
message starts with the error number a script can match on, then says what was
wrong: a name or key that is empty or too long, a value that cannot be stored
(a function, an instance, a table with mixed keys, a number that is not
finite), a value or metadata over its size limit, a call from a client, or data
access turned off for the project.

## Example

```text
error: 104: SetAsync: the value cannot be stored: a table key must be a string or an array index [RE9400]
```

## How to fix it

Store plain data: strings, numbers, booleans and tables of them, with array
tables numbered from 1 or tables keyed by strings only. Call the data services
from server scripts. If the message names error 403, data access is turned
off in `real.toml` (`[compat.data] enabled = false`).
