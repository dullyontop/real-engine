# RE9301: Remote call failed

A `RemoteFunction` or `BindableFunction` call, or a remote event call, could
not complete:
* the handler on the other side raised an error (the message includes it);
* `BindableFunction:Invoke` was called while no `OnInvoke` handler was set;
* a call was made from the wrong side (`FireServer` or `InvokeServer` on the
  server, `FireClient`, `FireAllClients` or `InvokeClient` on a client);
* the player an `InvokeClient` was waiting on left, or the first argument of
  `FireClient` or `InvokeClient` was not a `Player`.

## Example

```text
error[RE9301]: RemoteFunction:InvokeServer: the server's handler raised: Shop.luau:31: not enough coins
  --> scripts/client/shop.client.luau:22
```

## How to fix it

Wrap calls that can fail in `pcall`. Set `OnInvoke`, `OnServerInvoke` and
`OnClientInvoke` before anything calls them. Call `FireServer` and
`InvokeServer` only from client scripts, and the others only from server
scripts.
