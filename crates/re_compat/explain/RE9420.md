# RE9420: Changed script did not compile

A `Script`, `LocalScript` or `ModuleScript` source under `scripts/` changed
on disk while the game was running (in `real run` or editor play), but the
new source does not compile. Nothing restarts: the version that was running
keeps running, and modules keep their cached results. The next save that
compiles restarts the script, or every script that required the module.

## Example

```text
error[RE9420]: scripts/ServerScriptService/Main.server.luau changed but does not compile, so the running version stays: Main.server.luau:4: Expected 'end' (to close 'function' at line 2), got <eof>
```

## How to fix it

Fix the error the message gives and save again. A changed script always
restarts from the top, so its local state (variables, running loops) starts
over; the instances it made stay.
