# RE9401: Data store request queue full

A data store request needed budget its request type did not have, and that
type's queue already held 30 waiting requests, so the request was dropped.
Each request type (reads, writes, lists, removes, for standard and ordered
stores) has its own budget per minute that grows with the number of players.

## Example

```text
error: 305: SetAsync was dropped: the request queue is full (30 waiting for budget) [RE9401]
```

## How to fix it

Make fewer requests: cache values in the server's memory, write a player's
data once when they leave or every few minutes instead of on every change,
and check `DataStoreService:GetRequestBudgetForRequestType` before bursts.
