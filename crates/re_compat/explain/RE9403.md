# RE9403: Memory store request failed

A `MemoryStoreService` queue, sorted map or hash map call failed. The message
starts with the name of the error a script can match on:
`TotalRequestsOverLimit` (the place's request units for this minute are
spent), `TotalMemoryOverLimit` (the place's memory quota is used up),
`DataStructureMemoryOverLimit` or `DataStructureItemsOverLimit` (one
structure is full), `ItemValueSizeTooLarge` (a value is over 32 KB once
serialized), or no name for a bad argument.

## Example

```text
error: ItemValueSizeTooLarge: the value is 40211 bytes once serialized; the limit is 32768 [RE9403]
```

## How to fix it

Give items expirations so old ones go away, keep values small, remove queue
items once they are handled, and spread requests out. The quota and the
request units grow with the number of players.
