# RE9008: Parent change refused

A script set an instance's `Parent` to a value the tree cannot take:
* the instance was destroyed, and a destroyed instance's `Parent` is locked;
* the new parent is the instance itself or one of its descendants, which
  would make a cycle.

## Example

```text
error[RE9008]: The Parent property of Crate is locked: it was destroyed
  --> scripts/server/main.luau:20
```

## How to fix it

Do not reuse an instance after `Destroy()`: make a new one, or `Clone()` it
before destroying the original. To move a whole subtree, set the `Parent` of
its root to an instance outside it.
