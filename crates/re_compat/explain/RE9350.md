# RE9350: Asset id not in the substitute table

A script set an asset id (a `SoundId`, an `Image` or a `Texture`) that the
project does not map to a file. Online assets are not available offline, so
the engine looks each id up in the `[compat.assets]` table of `real.toml`. An
id that is not there plays or draws nothing: the sound stays silent and the
image shows as a plain placeholder. The game keeps running.

## Example

```text
warning[RE9350]: rbxassetid://1234567 is not in [compat.assets]; the sound is silent
```

## How to fix it

Add the id to `real.toml` with a file of the project:

```toml
[compat.assets]
"rbxassetid://1234567" = "assets/sfx/door.wav"
```
