# RE9452: Owned part moved too fast

A client moved a part its player owns faster than
`[compat.net] max_owned_speed` (1,000 studs per second by default) between two
of its frames. The server did not move the part, and sent its own position
back to the client, which puts the part back. The player is not disconnected.

## Example

```text
warning[RE9452]: Player2 moved HumanoidRootPart faster than 1000 studs/s; it stays where the server has it
```

## How to fix it

Teleport characters from a server `Script` (`PivotTo` on the server), not
from a `LocalScript`. If the game really moves owned parts that fast, raise
the limit:

```toml
[compat.net]
max_owned_speed = 5000
```
