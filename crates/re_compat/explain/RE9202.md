# RE9202: Bad animation substitute table

The `[compat.animations]` table in `real.toml` maps animation asset ids to
clips the engine can play. Loading the project refused it because a key is
not an asset id, a value names neither a built-in clip nor a place path, or
the same id appears twice (`"1234"` and `"rbxassetid://1234"` are the same
id).

## Example

```text
error[RE9202]: real.toml [compat.animations]: asset id 1234 is listed twice
```

## How to fix it

Write each id once, as its number or as `rbxassetid://<number>`, and map it
to `builtin:<clip>` or to the dotted path of a `KeyframeSequence` in the
place:

```toml
[compat.animations]
"1234" = "builtin:r15_walk"
"5678" = "game.ReplicatedStorage.Animations.Wave"
```

The built-in clip names are `r6_` and `r15_` followed by `idle`, `walk`,
`run`, `jump`, `fall`, `climb` or `sit`.
