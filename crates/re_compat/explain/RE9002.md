# RE9002: Not available offline

A script called a member that needs an online service, such as a data store,
a memory store, teleporting between places, text filtering or a marketplace
purchase. Real Engine runs a place in one process with no online backend, so
these members exist but fail with this error instead of hanging or quietly
returning `nil`.

## Example

```text
error[RE9002]: DataStoreService.GetDataStore is not available offline
  --> scripts/server/save.luau:4
```

## How to fix it

Guard the call with `pcall` and fall back to in-memory state when it fails,
the way a script already has to handle the service being unreachable. Local
persistence is planned for a later milestone.
