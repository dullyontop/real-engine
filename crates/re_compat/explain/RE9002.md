# RE9002: Not available offline

A script called a member that needs an online service, such as an HTTP
request, teleporting between places, text filtering, a marketplace purchase,
badges, cross-server messaging or a player's friends and groups, or it
`require`d a module by asset id. Real Engine runs a place with no online
backend, so these members exist but fail with this error instead of hanging or
quietly returning `nil`. Data stores and memory stores are not among them:
they work locally (saved data, in the project's `.real/data/` folder).

## Example

```text
error[RE9002]: TeleportService.TeleportAsync is not available offline
  --> scripts/server/lobby.luau:4
```

## How to fix it

Guard the call with `pcall` and carry on without it when it fails, the way a
script already has to handle the service being unreachable. `real verify`
counts these calls with the unsupported members, so its report shows what a
game needs from online services.
