# RE9450: Remote message dropped

A network client sent the server a remote message (`FireServer`,
`InvokeServer`, a reply to `InvokeClient`, a proximity prompt action or a
kick of itself) that the server did not deliver. Either it was larger than
64 KiB once encoded, or it was not a message this build of the engine reads.
The player stays connected; the message is lost, and an `InvokeServer` that
was dropped never returns.

## Example

```text
warning[RE9450]: a remote message from Player2 was dropped: 70412 bytes, more than 65536
```

## How to fix it

Send less in one message: split a large table over several calls, or keep
the data in replicated instances and send only what changed. A message that
does not decode comes from a client running a different engine build or a
modified client.
