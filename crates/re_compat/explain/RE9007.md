# RE9007: Attribute refused

`SetAttribute` was given a name or a value it does not accept. An attribute
name is 1 to 100 characters of letters, digits and underscores, and does not
start with `RBX`. A value is `nil` (which removes the attribute), a boolean, a
number, a string, a `Vector3`, or one of the datatypes the layer stores
(`Color3`, `UDim2`, `NumberRange` and the like). Tables, functions, threads
and instances cannot be attributes.

## Example

```text
error[RE9007]: SetAttribute: an attribute cannot hold a table
  --> scripts/server/main.luau:12
```

## How to fix it

Store simple values in attributes, one per attribute. Keep tables in a
module or in a script's own variables, and refer to instances by an
`ObjectValue` or by name.
