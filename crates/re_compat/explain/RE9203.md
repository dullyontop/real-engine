# RE9203: Offline default returned

A script asked for data that lives online, such as the avatar of a user id
(`Players:GetHumanoidDescriptionFromUserId`). Real Engine has no online
backend, so the call returns a default value instead of failing, and this
warning says so once per call. The script goes on with the default.

## Example

```text
warning[RE9203]: Players:GetHumanoidDescriptionFromUserId(42) has no avatar to read offline; it returns a default HumanoidDescription
```

## How to fix it

Nothing has to change for the place to run. To give characters a chosen
look, build a `HumanoidDescription` in the place (or in a script) and pass
it to `Players:CreateHumanoidModelFromDescription` or
`Humanoid:ApplyDescription`.
