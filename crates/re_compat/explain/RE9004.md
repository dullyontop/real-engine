# RE9004: Compat scene breaks the scene conventions

A scene of a compat project (`real.toml` has `[compat] api = "roblox"`) does not
follow the layout the compatibility layer expects:

* one root entity with id `game` and class `DataModel`;
* each service a child of `game`, with its class name as id and a `ServiceTag`;
* every instance's `ClassMarker` naming a known class;
* every script instance's `ScriptRef.context` matching its class: `server` for
  a `Script` (or `client` when its `RunContext` is `Client`), `client` for a
  `LocalScript`, `module` for a `ModuleScript`.

Entities without a `ClassMarker` are native entities and are not checked.

## Example

```text
error[RE9004]: a LocalScript instance must have script context client, found server
  --> entity "hud-controller"
```

## How to fix it

Re-run the importer, or edit the entity the message names so it follows the
convention it states.
