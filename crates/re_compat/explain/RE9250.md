# RE9250: Collision group refused

A `PhysicsService` call could not change or read the collision groups. The
message says which rule it broke:

* the group is not registered (register it with `RegisterCollisionGroup`
  first);
* the name is empty or longer than 100 characters, or another group already
  has it;
* every group is in use (a place has at most 32, `Default` included);
* the call would remove or rename `Default`.

## Example

```text
error[RE9250]: collision group "Debris" is not registered
  --> scripts/server/groups.luau:4
```

## How to fix it

Register each group once, when the place starts, before setting which groups
collide. Unregister groups the place no longer needs to free their slots.
A part whose `CollisionGroup` names a group that is not registered collides
as `Default`.
