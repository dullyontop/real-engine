# RE9251: Physics setup missing

A physics member needs something the place does not have:

* `SetPrimaryPartCFrame` and `GetPrimaryPartCFrame` need the model's
  `PrimaryPart` to be set to a part inside the model;
* `Workspace.Terrain` needs the workspace's `Terrain` child, which the engine
  adds when it starts the place.

## Example

```text
error[RE9251]: SetPrimaryPartCFrame: Model has no PrimaryPart
  --> scripts/server/spawn.luau:12
```

## How to fix it

Set the model's `PrimaryPart` first, or use `PivotTo`, which works without
one. If the workspace lost its `Terrain`, reload the place.
