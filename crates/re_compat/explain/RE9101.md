# RE9101: Deprecated member used

A script used a member that still works but is deprecated in the API it is
written against. The warning names the member to use instead; behaviour does
not change.

## Example

```text
warning[RE9101]: Instance.children is deprecated
  --> scripts/server/main.luau:12
  = hint: use GetChildren
```

## How to fix it

Switch to the replacement the hint names.
