# RE9201: Unknown animation id

`Animator:LoadAnimation` was given an `Animation` whose `AnimationId` the
engine cannot turn into keyframes. The engine has no access to an online
asset store, so an id resolves only through the project's substitute table,
the engine's built-in character clips, or a `KeyframeSequence` in the place.
The track still loads and plays, but it moves nothing.

## Example

```text
warning[RE9201]: animation "rbxassetid://1234" is not in the substitute table or the built-in clips; it plays as an empty clip
```

## How to fix it

Map the id in `real.toml`, either to a built-in clip or to a
`KeyframeSequence` kept in the place:

```toml
[compat.animations]
"1234" = "builtin:r15_walk"
"5678" = "game.ReplicatedStorage.Animations.Wave"
```

The built-in clip names are `r6_` and `r15_` followed by `idle`, `walk`,
`run`, `jump`, `fall`, `climb` or `sit`.
