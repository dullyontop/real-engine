# RE9453: Too many remote messages

A network player sent the server more remote messages in one second than
`[compat.net] remote_rate` allows (600 by default, all remotes together). The
messages past the limit were dropped. It is reported at most once a second
per player, with how many were dropped, and the player stays connected.

## Example

```text
warning[RE9453]: Player2 sent more than 600 remote messages in a second; 112 were dropped
```

## How to fix it

Send less often: fire on a change rather than every frame, or batch values
into one message. If the game needs more, raise the limit:

```toml
[compat.net]
remote_rate = 1200
```
