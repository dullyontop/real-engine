# RE9300: Value cannot be sent

A script passed a value through a `RemoteEvent`, `RemoteFunction`,
`BindableEvent` or `BindableFunction` that cannot be copied to the receiver.
Arguments and results are deep copies, and these values have no copy:
* a function or a thread;
* a table that contains itself, or nests deeper than 64 levels;
* a table key that is neither a string nor a number (an instance, a table);
* a userdata that is not an instance, a datatype or an enum item (a signal,
  a connection, a `Random`).

The message names the call and where in the arguments the value was found.

## Example

```text
error[RE9300]: RemoteEvent:FireServer: argument 2.onHit cannot be sent: it is a function
  --> scripts/client/shop.client.luau:14
```

## How to fix it

Send data, not behaviour: pass a name or an id that the receiver looks up,
and keep the function on the side that runs it. Turn instance keys into
string keys (`inst.Name`, or an attribute holding an id) before sending.

Some values are dropped by rule rather than refused, as in Roblox: in a table
whose key `1` is set, only the entries `1..n` up to the first `nil` arrive;
in any other table, number keys arrive as strings; metatables never arrive.
