# RE4022: Open graph differs from its file

A migration report found a procedural source whose graph is open with edits
that are not in its graph file. `real migrate-graph` reads and rewrites the
file, so the open edits are neither migrated nor written. This is a warning,
and an error that makes the report not ok (so nothing is written) when the
graph is an open document with unsaved edits (ADR-0044): saving it afterwards
would overwrite the migrated file. An open document without unsaved edits is
reloaded from the file once the migration rewrote it.

## Example

```text
warning[RE4022]: island: the open graph differs from graphs/island.graph.json; the migration reads and rewrites the file, not the open graph
```

## How to fix it

Save the open graph (or discard its edits), then run the migration again.
