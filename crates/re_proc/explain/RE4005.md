# RE4005: Invalid node parameters

A node's parameters do not match its kind's parameter schema: an unknown
parameter, a value of the wrong type, or a value out of range. Parameters
that are left out take their defaults.

## Example

```text
error[RE4005]: node `h` (terrain.heightfield): unknown field `octave`, expected one of `size`, `cell`, `scale`, …
```

## How to fix it

Fix the parameter as the message says. `describe` and `graph.schema.json`
list each node kind's parameters with their types, ranges and defaults.
`graph.set_param` checks a value before it stores it.
