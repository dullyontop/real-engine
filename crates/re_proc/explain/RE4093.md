# RE4093: The source does not generate the key

`proc.revert` puts back what a procedural source generates, read from the
source's output computed against the scene as it is. It was asked to revert
an override of a key that output does not have, so there is nothing to put
back:

- the source no longer generates the key (its parameters, seed or graph
  changed since the override was made), so the override is an orphan;
- the key is under an entity that is deleted too, or suppressed for this
  play session, so a regeneration would not make it;
- the entity is part of a stream cell, which a streamed source generates per
  cell: `proc.revert` reads what the source generates outside its cells.

Nothing changes.

## Example

```text
error[RE4093]: `island` does not generate `rocks/3/moss` while `rocks/3` is deleted: restore `rocks/3` first
  --> entity `island`
```

## How to fix it

- Bring the deleted parent back first (`proc.revert {"source", "key"}` with
  the parent's key), then the entity.
- An orphan override does nothing: a regeneration warns about each one
  (`RE4010`), and a `set_override` operation through `scene.apply` removes
  it.
- For an entity of a stream cell, set the field with `entity.set`, or
  remove the override with `scene.apply` and a `set_override` operation.
