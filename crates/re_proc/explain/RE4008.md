# RE4008: Node failed

A node could not compute its output from its inputs and parameters, for
example because a mesh would be empty or an input field is unusable. Nodes
after it are skipped, and a procedural source whose graph fails keeps its
previous output.

## Example

```text
error[RE4008]: node `inst` (points.instance): no prefab for tag `rock`
```

## How to fix it

Fix the parameters or inputs the message names. `graph.report` shows the
last evaluation of a source with every node's diagnostics.
