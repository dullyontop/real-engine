# RE4000: Invalid graph document

A `*.graph.json` file (or the graph a builder script returned) is not a valid
graph document. The document must:

- parse as JSON with only the keys `format`, `version`, `name`, `seed`,
  `nodes` and `edges` (and `id`, `kind`, `version`, `params` per node);
- have `"format": "real-engine/graph"` and a supported `version`;
- give every node a unique `id`;
- only name existing nodes in `edges`.

## Example

```text
error[RE4000]: graph `island`: node id `h` is used twice
```

## How to fix it

Fix the document as the message says. `real schema` writes
`graph.schema.json`, which editors use to check graph files as you type.
