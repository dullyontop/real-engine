# RE4003: Port type mismatch

An edge connects an output to an input that does not accept its type. The
port types are `Field` (a grid of heights or weights), `Mesh`, `Points` and
`Fragment` (entities to create).

## Example

```text
error[RE4003]: edge 0: `scatter` outputs Points, but input `field` of `mesh` (terrain.mesh) takes Field
```

## How to fix it

Connect a node with the right output type, or put a converting node in
between (for example `points.instance` turns Points into a Fragment).
