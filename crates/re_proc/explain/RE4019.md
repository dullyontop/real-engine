# RE4019: Older node version in use

A node is written for an older version of its kind than this engine's
current one. This is a warning: the node still evaluates exactly as that
version did, so the world does not change. Newer versions may fix problems or
add parameters.

Builder scripts record version 1 unless they ask for another, as in
`g:node("terrain.heightfield@2", ...)`, because a builder runs on every load
and must keep meaning the same thing.

## Example

```text
warning[RE4019]: graph `island`: node `h` (terrain.heightfield) is written for version 1; this engine's current version is 2
```

## How to fix it

Run `real migrate-graph --dry-run` to see what upgrading changes (outputs,
added and removed keys, overrides that would lose their target), then
`real migrate-graph` to write it. For a builder script, change the call the
report names to the version it gives.
