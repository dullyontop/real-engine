# RE4204: Misplaced graph param reference

`{"$param": "<name>"}` binds a node param to a graph param only as the node
param's whole value. Here `"$param"` appears elsewhere: inside a list or an
object in a node param, in a per-source override, or in a node kind's
migration `set`. The key `"$param"` is reserved for references, so it is
refused wherever it cannot be one.

## Example

```text
error[RE4204]: graph `island`: node `h`'s param `offset` holds `"$param"` inside its value; a reference is a param's whole value: {"$param": "<name>"}
```

## How to fix it

Bind the whole node param, or declare a graph param of the node param's
type (`vec2`, `vec3`, `color`, `curve`) and bind to it.
