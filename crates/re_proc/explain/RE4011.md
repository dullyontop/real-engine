# RE4011: Override names an unknown node or parameter

A per-node parameter override (`GraphSource.params`, written by
`graph.set_param`) names a node the graph does not have, a parameter the
node's kind does not have, or a value that the node does not accept. The
node keeps its value from the graph document. This usually means the graph
file or builder script changed after the override was set.

`graph.set_param` refuses such an override with the same code.

## Example

```text
warning[RE4011]: island: override of `h.octave` ignored: node `h` (terrain.heightfield) has no parameter `octave` (did you mean `octaves`?)
```

## How to fix it

Set the override again on the right node and parameter with
`graph.set_param`, or clear it by setting the value to `null`.
