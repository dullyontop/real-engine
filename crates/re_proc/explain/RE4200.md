# RE4200: Invalid graph param declaration

A graph file's `params` list (graph file version 2, ADR-0061) declares
something that cannot work:

- a name that is not letters, digits and `_` starting with a letter (at
  most 64 bytes), or a name declared twice;
- `min` or `max` on a param that is not a `number` or an `integer`, or
  `min` above `max`;
- an `enum` with no `values` or with a value listed twice, or `values` on
  another type;
- `extensions` on a param that is not a `file`, or an extension that does
  not start with `.`;
- a `default` that the param's own type, range or values refuse;
- no `default` in a graph without a `kind` block. A source must always have
  a value for every param, so only a node kind's params, which each instance
  sets, may leave it out.

## Example

```text
error[RE4200]: graph `island`: param `height`: its default is refused: 500 is outside 0 to 400
```

## How to fix it

Correct the declaration in the graph file, or replace it with
`graph.declare_param`, which checks it before writing.
