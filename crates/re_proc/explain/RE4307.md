# RE4307: Cell generation failed

Evaluating a streamed source's graph for one cell, or its `terrain.chunks`
field for one terrain chunk, failed. The related diagnostic gives the cause
(a node error, a prefab that does not load, a height that is not a finite
number). The cell stays empty for that source, a failed collision chunk has
no collider, and a failed view chunk's ground is not drawn. Each is
generated again when the source's graph, parameters or seed change.

## Example

```text
error[RE4307]: terrain: cell c/3_-2 could not be generated
  related: error[RE4014]: graph `world`: prefab `prefabs/tree.prefab.json` could not be instantiated
```

```text
error[RE4307]: land: terrain view chunk 0/2_-1 failed; its ground is not drawn
  related: error[RE4307]: invalid heightfield: sample 412 is NaN
```

## How to fix it

Fix the cause the related diagnostic names. `graph.generate` on the source
shows the whole evaluation report.
