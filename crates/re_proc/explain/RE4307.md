# RE4307: Cell generation failed

Evaluating a streamed source's graph for one cell, or its `terrain.chunks`
field for one terrain chunk, failed. The related diagnostic gives the cause
(a node error, a prefab that does not load, a height that is not a finite
number).

The cell stays empty for that source, and it is generated again when the
source's graph, parameters or seed change. A collision chunk that fails has
no collider, or keeps the one made from the source's earlier inputs. A view
chunk that fails is left bare, and is not tried again while it stays in view
with the same inputs. The view reports one failure for each code of cause
(chunks over heights that are not finite fail at other samples, all with the
node's error), so one report can stand for many chunks; it reports again once
the source's inputs change.

## Example

```text
error[RE4307]: terrain: cell c/3_-2 could not be generated
  related: error[RE4014]: graph `world`: prefab `prefabs/tree.prefab.json` could not be instantiated
```

```text
error[RE4307]: land: terrain view chunk 0/2_-1 failed; its ground is not drawn
  related: error[RE4008]: node `up` (field.remap): invalid heightfield: sample 412 is inf
```

## How to fix it

Fix the cause the related diagnostic names. `graph.generate` on the source
shows the whole evaluation report.
