# RE4307: Cell generation failed

Evaluating a streamed source's graph for one cell failed. The related
diagnostic gives the cause (a node error, a prefab that does not load). The
cell stays empty for that source, and it is generated again when the
source's graph, parameters or seed change.

## Example

```text
error[RE4307]: terrain: cell c/3_-2 could not be generated
  related: error[RE4014]: graph `world`: prefab `prefabs/tree.prefab.json` could not be instantiated
```

## How to fix it

Fix the cause the related diagnostic names. `graph.generate` on the source
shows the whole evaluation report.
