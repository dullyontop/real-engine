# RE4018: Retired node version

A node is written for a version of its kind that this engine no longer
evaluates. Every node evaluates at the version it was written for, so that
an engine upgrade never changes a world by itself; a kind keeps its old
versions until a release retires them, and the release notes say which.

## Example

```text
error[RE4018]: graph `island`: node `h` (terrain.heightfield): version 1 is retired; this engine evaluates versions 2 to 3
```

## How to fix it

Upgrade the graph with `real migrate-graph` using an engine release that
still evaluates the old version, then open it with this one. The migration
report says what the upgrade changes in the world.
