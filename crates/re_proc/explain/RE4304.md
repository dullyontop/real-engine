# RE4304: Entity in an unloaded cell

A command, script or agent named an entity that lies in a cell of the
streamed world that is not loaded. Its id is valid, but the entity does not
exist until the cell loads.

## Example

```text
error[RE4304]: `terrain/c/3_-2/trees/17` is in cell c/3_-2, which is not loaded
```

## How to fix it

Wait for the cell to load (`stream.on_loaded`), or check `stream.is_loaded`
first. In the tools context and the editor, `stream.load` loads a cell
explicitly and keeps it loaded until it is released.
