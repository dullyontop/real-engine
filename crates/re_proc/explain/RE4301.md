# RE4301: Node does not stream

A procedural source with a `Streamed` component has its graph evaluated one
cell at a time (ADR-0042). Every node in that graph has to work on a window of
the world. This node's kind cannot do that. For example, `terrain.island_mask`
shapes its output relative to the size of the whole field. A cell's window is
also built from the graph's sample spacing (the `cell` of its
`terrain.heightfield` nodes), so `[stream] cell_size` has to be a whole
multiple of that spacing, and every heightfield has to use the same one.

Shapes and road paths are the same in every cell: their nodes stream as
`global` and run once for the whole source (ADR-0043). A streamed graph is
also refused when what a global node sees could differ from cell to cell:
shapes or a path that come from a node that is not global, a global node that
takes a field from a node that is not pointwise or region (it samples the
field on the source's grid) or another input from a node that is not global,
or a `cell` or `whole` node anywhere upstream of a global node.

`real graph describe <kind>` shows how each kind streams: `pointwise`,
`region`, `cell`, `global` or `whole` (does not stream).

## Example

```text
error[RE4301]: island: node `mask` (terrain.island_mask) does not stream
error[RE4301]: valley: node `road` (path.spline) is global, but its input `field` comes from node `wet` (game.wetness), which streams as `cell`; a global node takes fields from pointwise or region nodes and its other inputs from global nodes
```

## How to fix it

Remove the node from the streamed graph, or replace it with one that
streams. A falloff that depends on world position can be built with
`field.remap`. To fix a spacing problem, change `cell` or `[stream] cell_size`
so that one divides the other exactly. Drape roads on fields that pointwise
or region nodes make (`terrain.heightfield`, `field.combine`, `field.remap`,
`terrain.erode`), not on fields made cell by cell. A graph that has to see the
whole field at once cannot be streamed: remove `Streamed` from the source.
