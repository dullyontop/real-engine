# RE4001: Unknown node kind

A node's `kind` is not one of the node kinds the project can use: the
engine's built-in kinds, such as `terrain.heightfield`, `scatter.poisson` or
`road.mesh`, and the project's own kinds, which its Luau scripts declare
under `project.` names (ADR-0043 §4). The message suggests the nearest name
when there is one.

## Example

```text
error[RE4001]: node `h`: unknown node kind `terrain.heighfield` (did you mean `terrain.heightfield`?)
```

## How to fix it

Correct the spelling. `real describe` lists every node kind this build and
project have, with its ports and parameters (`nodes` in
`real describe --json`). For a `project.` kind, check that the script that
declares it loads without errors.
