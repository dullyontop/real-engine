# RE4001: Unknown node kind

A node's `kind` is not one of the registered node kinds. M1 shipped sixteen:
`terrain.heightfield`, `terrain.island_mask`, `field.combine`, `field.remap`,
`terrain.mesh`, `terrain.water_plane`, `scatter.poisson`,
`scatter.grid_jitter`, `points.filter`, `points.pick`, `points.instance`,
`mesh.primitive`, `mesh.transform`, `mesh.merge`, `material.assign` and
`fragment.merge`; world streaming adds `terrain.chunks`.

## Example

```text
error[RE4001]: node `h`: unknown node kind `terrain.heighfield` (did you mean `terrain.heightfield`?)
```

## How to fix it

Correct the spelling. `describe` lists every node kind with its ports and
parameters.
