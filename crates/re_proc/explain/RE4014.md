# RE4014: Prefab failed

A `points.instance` node could not use a prefab file: the file is missing,
does not parse as a prefab (`"format": "real-engine/prefab"`), or names a
component or field the engine does not know. Prefab paths are relative to
the project root.

## Example

```text
error[RE4014]: node `inst` (points.instance): prefab `prefabs/tree.prefab.json` could not be read: No such file or directory
```

## How to fix it

Check the path and the prefab file. A prefab is a scene file with
`"format": "real-engine/prefab"`; `real check` validates it.
