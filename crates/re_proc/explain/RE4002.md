# RE4002: Unknown port

An edge names a port the node does not have. Every node has one output port,
named after its type (`field`, `mesh`, `points` or `fragment`), and a fixed
set of named inputs. `mesh.merge` and `fragment.merge` accept inputs on any
port name.

## Example

```text
error[RE4002]: edge 2: node `mesh` (terrain.mesh) has no input `height` (inputs: field)
```

## How to fix it

Use the port names the message lists. In a builder script, the table of
inputs names the input ports: `g:node("terrain.mesh", {}, { field = t })`.
