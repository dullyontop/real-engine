# RE4010: Orphaned override

An override of a generated entity (a field value or a deletion, stored on its
procedural source) names a key that the source no longer generates, usually
after a new seed or parameter changed what the graph produces. The override
is **kept** in the scene file, so it applies again if the key comes back.
This is a warning.

## Example

```text
warning[RE4010]: island: override of Transform.translation on "inst/17" has no target in the new output; kept
```

## How to fix it

Nothing, if you may go back to the earlier seed. Otherwise remove the
override from the source's `overrides` list in the scene file.
