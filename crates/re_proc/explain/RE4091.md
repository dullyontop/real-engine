# RE4091: Graph file exists or is open

`proc.convert_builder { source, graph? }` makes a new graph file, by default
`graphs/<source>.graph.json`, holding the graph the source's builder made. It
never replaces a file: it refuses when the project has a file at that path,
or when the editor has the path open with content (made or changed by an
earlier command and not yet saved).

Nothing changes.

## Example

```text
error[RE4091]: cannot make graphs/island.graph.json: the file exists
  --> graphs/island.graph.json
  = help: pass `graph` to make another file
```

## How to fix it

- Pass `graph` with a free path, such as `graphs/island_built.graph.json`.
- If the existing file is the graph you want, point the source at it
  instead: set `GraphSource.graph` to it and `GraphSource.builder` to `""`
  with `entity.set`.
