# RE4302: Streamed source is not at the origin

A streamed procedural source generates its cells at world positions, so the
source entity has to have an identity transform: no translation, no rotation
and a scale of one, on itself and on every parent. Otherwise the content
would not line up with the cells it belongs to. The source is not streamed
until this is fixed.

## Example

```text
error[RE4302]: streamed source `world/terrain` is not at the origin (translation [10, 0, 0])
```

## How to fix it

Reset the source's Transform, and the Transform of its parents, to the
identity. To move the content, change the graph instead, for example the
heightfield's `offset`.
