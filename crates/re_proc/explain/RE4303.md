# RE4303: Reference into an unloaded cell

An authored entity outside a streamed subtree holds an entity field (a
`Weld.other`, a script's target) that points into that subtree, and the
subtree's cell has just unloaded. While the cell is unloaded the reference
reads as empty. When the cell loads again it points at the entity again, and
saving writes it unchanged in the meantime. The warning is reported once per
subtree.

## Example

```text
warning[RE4303]: 1 entity references into `tower`, unloaded with cell c/3_-2; the references read as empty until it loads
```

## How to fix it

If the referring entity needs its target at all times, put both in the same
streamed subtree, or remove `Streamed` from the target's root so that it
stays loaded. A script can check `stream.is_loaded(key)` before it follows
the reference.
