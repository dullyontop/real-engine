# RE4212: Override replaces a graph param binding

A per-node override in `GraphSource.params` sets a node param that the graph
binds to a graph param. The override applies (it wins over the binding for
this source, as overrides always win), but the graph's author exposed the
value as a graph param so that it is set there: the override hides later
changes to the param, and the inspector shows the param's value, not the
override's.

## Example

```text
warning[RE4212]: island: `h.height` is bound to graph param `height`; the override replaces the binding for this source
```

## How to fix it

Set the graph param instead with `graph.set_param { source, param }`
(without `node`), and clear the override with a null value.
