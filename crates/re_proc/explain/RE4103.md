# RE4103: Invalid Luau node output

A Luau node's `eval` returned a value that does not fit the output type it
declared. Fields need `n * n` finite samples and a positive `spacing`; points
need whole 28-byte records and finite positions and normals; meshes need
whole triangles with indices inside the vertices; fragments need non-empty
keys without `/` at the start, parents that come earlier, and component
names as strings.

## Example

```text
error[RE4103]: node `rocks` (project.rocks): field: 99 samples, expected 100 (n = 10)
```

## How to fix it

Fix the script's output; the message names the node and what was wrong.
