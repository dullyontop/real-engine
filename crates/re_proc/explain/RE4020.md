# RE4020: Node migration failed

A node's parameters, written for an older version of its kind, could not be
rewritten into the kind's current shape. Each version step that changed the
parameters has a migration; this one refused the values it was given, so the
node cannot be evaluated.

## Example

```text
error[RE4020]: graph `island`: node `h` (terrain.heightfield): its parameters could not be migrated from version 1 to 2: `octaves` must be an integer
```

## How to fix it

Fix the parameter the message names in the graph file (or in the builder
script), keeping the node's version, and open the project again. `describe`
lists each kind's parameters.
