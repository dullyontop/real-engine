# RE4100: Invalid Luau node declaration

A script under `scripts/generators/` does not declare a usable node kind
(ADR-0043 §4). Each `.luau` file directly in that folder must return
`proc.node{ kind, version, doc, inputs, output, params, uses_seed, eval }`.
The message says what is wrong:

- the file does not compile, or raises an error while it runs;
- it returns something other than `proc.node{...}`;
- `kind` does not start with `project.`, or another script or the engine
  already uses it;
- `version`, `oldest`, `inputs`, `output` or a parameter is malformed;
- `eval` (or `migrate`, when given) is not a function.

The kind is not registered, so graphs that use it report `RE4002`.
Modules in subfolders of `scripts/generators/` are not declarations; nodes
`require` them.

## Example

```text
error[RE4100]: scripts/generators/rocks.luau: `kind` must start with `project.` (found `rocks`)
```

## How to fix it

Follow the message, save the file, and the node is declared again.
