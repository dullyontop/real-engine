# RE4306: Streaming memory budget too small

The streamed data in memory has passed `[stream] memory_mb`, and evicting
the cells outside `radius` was not enough. The effective load radius shrinks
until the loaded cells fit, and this warning is reported once. Memory is
accounted from data sizes (meshes, heightfields, physics shapes and entities),
not measured from the process, so eviction is the same on every machine.

## Example

```text
warning[RE4306]: streamed data needs 1210 MiB within radius 768 m, over memory_mb 1024; the load radius shrinks to 512 m
```

## How to fix it

Raise `[stream] memory_mb`, lower `radius`, or generate less per cell.
