# RE4009: No graph for a procedural source

A procedural source uses the `graph` generator, but no graph document is
stored for it. `re_app` stores one for every `GraphSource` when the scene
loads: it reads the `graph` file, or runs the `builder` script in the tools
context.

## Example

```text
error[RE4009]: no graph is stored for procedural source `island`
```

## How to fix it

Give the source's `GraphSource` a `graph` file (`graphs/island.graph.json`)
or a `builder` script (`scripts/tools/island_graph.luau`), and check that the
file exists or the script returns a graph. In Rust, insert the document with
`GraphStore::insert`.
