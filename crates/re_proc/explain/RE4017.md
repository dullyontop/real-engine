# RE4017: Not a graph source

A `graph.*` command was given an entity that is not a procedural source of
the `graph` generator: it needs `Procedural { generator: "graph" }` and a
`GraphSource`.

## Example

```text
error[RE4017]: `crate_1` is not a graph source (it has no Procedural component)
```

## How to fix it

Pass the id of the entity that carries the `GraphSource` (for example
`island`). `query {"with": ["GraphSource"]}` lists them.
