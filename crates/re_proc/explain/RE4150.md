# RE4150: Unknown group or attribute

A modelling node (`poly.*`) names a face group, an attribute or a material
that its input polygon mesh does not have, or has with another type. A group
is a `bool` face attribute; primitives make their own (`poly.box` makes
`top`, `bottom` and `side`), `poly.group` makes others, and operations that
make faces put them in the groups their parameters name. An empty group name
means every face.

## Example

```text
error[RE4150]: node `paint` (poly.material): the mesh has no face group `roof` (its groups: bottom, side, top)
```

## How to fix it

Use one of the groups the message lists, or make the group first with a
`poly.group` node upstream. For an attribute of the wrong type, give the
node's `type` to match the existing attribute, or use another name. For a
material, name a path that a `poly.material` node upstream has set.
