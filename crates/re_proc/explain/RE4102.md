# RE4102: Luau node stopped by the wall-clock backstop

A Luau node ran for more than 60 seconds of wall-clock time without running
out of its safepoint budget, usually inside one long builtin call such as
sorting a huge table. Unlike `RE4101` this depends on the machine: a faster
one might finish.

## Example

```text
error[RE4102]: node `sort` (project.sort): the Luau node ran past the 60 s wall-clock backstop (this depends on the machine)
```

## How to fix it

Split the work into smaller calls, or move it to a Rust node.
