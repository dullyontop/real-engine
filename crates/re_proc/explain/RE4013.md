# RE4013: Duplicate key in a graph's output

Two entities in a graph's output have the same key. Keys are
`<node id>/<local key>`, so this happens when one node's output reaches the
graph's output twice (for example through two `fragment.merge` nodes).

## Example

```text
error[RE4013]: graph `island`: key `water/water` is produced twice
```

## How to fix it

Make each fragment reach the output once: connect it to a single
`fragment.merge`, or leave it as an unconnected output node.
