# RE4015: Procedural cache I/O failed

The disk cache of node outputs (`.real/cache/proc/<key>.bin`) could not be
read or written, an entry was damaged, or the cache could not keep to its size
limit (`[proc] disk_cache_mb`) because the folder could not be listed or an
entry could not be removed. Evaluation goes on without it: the node is
computed again, and a cache that could not keep to its limit tries again once
another tenth of the limit has been written. This is a warning.

## Example

```text
warning[RE4015]: node `h`: cache entry could not be written: Permission denied
```

## How to fix it

Check that `.real/cache/proc/` is writable and that its files can be removed.
The cache is always safe to delete.
