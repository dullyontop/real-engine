# RE4015: Procedural cache I/O failed

The disk cache of node outputs (`.real/cache/proc/<key>.bin`) could not be
read or written, or an entry was damaged. Evaluation goes on without it: the
node is computed again. This is a warning.

## Example

```text
warning[RE4015]: node `h`: cache entry could not be written: Permission denied
```

## How to fix it

Check that `.real/cache/proc/` is writable. The cache is always safe to
delete.
