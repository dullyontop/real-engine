# RE4007: Input connected twice

An input port that takes one value has several edges leading to it. Only
`mesh.merge` and `fragment.merge` take any number of inputs (on any port
names).

## Example

```text
error[RE4007]: node `c` (field.combine): input `a` has 2 edges, it takes one
```

## How to fix it

Remove the extra edges, or combine the values first (for example with
`field.combine`).
