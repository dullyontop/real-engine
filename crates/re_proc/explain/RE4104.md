# RE4104: Cannot create a source from a node kind

`proc.create_source { kind, params }` makes a procedural source whose graph
is one node of `kind`. It refuses when the kind is not registered (a Luau
kind whose script has a declaration error is not), when the kind's output
is not a fragment, when the kind has a required input, when the graph file
it would write already exists, or when the world has no project root.

## Example

```text
error[RE4104]: `project.ground` outputs a field, not a fragment: only a kind that outputs a fragment can be a source
```

## How to fix it

Pick a kind from `describe`'s `nodes` whose output is `fragment` and whose
inputs are all optional, or wire the kind into a graph file of your own.
Pass `graph` to choose another file name.
