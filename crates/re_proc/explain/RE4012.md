# RE4012: Unsupported node version

A node's `version` is newer than the version of its kind in this engine, or
is 0. Node versions let a later engine migrate older parameters; an engine
cannot read parameters written for a newer one.

`graph.set_default` refuses such a node with this code: it cannot check a
parameter in a shape this engine does not know.

## Example

```text
error[RE4012]: node `h` (terrain.heightfield): version 3 is not supported (this engine has version 1)
```

## How to fix it

Use a newer engine, or rewrite the node for this engine's version (see
`describe` for its parameters).
