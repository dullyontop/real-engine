# RE4203: Bound node param refuses a graph param's value

A node param bound to a graph param must accept every value the graph param
allows, so that a value the inspector or a recipe offers never fails when
the source regenerates. When the graph loads, each bound node is checked
with the param's `min`, its `max`, each `enum` value and both booleans in
turn (the default is checked as the node's own value, `RE4005`). One of
them is refused.

## Example

```text
error[RE4203]: graph `post`: graph param `height` allows 0 to 12, but `pole.height` (mesh.primitive) refuses 0: `height` must be above 0
```

## How to fix it

Narrow the graph param's range or values to what the node accepts (with
`graph.declare_param`), or bind the node param to another param.
