# RE4206: Graph output or input wired wrongly

Each declared output of a graph takes exactly one edge into
`["$out", "<output>"]`, from a node output of exactly the declared type.
Here an output has no such edge or several, the edge carries another type,
or an edge from `["$in", ...]` or into `["$out", ...]` names a port the
graph does not declare.

## Example

```text
error[RE4206]: graph `post`: output `post` (fragment) has no edge into ["$out", "post"]
```

## How to fix it

Connect one node output of the declared type to the output with
`graph.connect`, remove the extra edges, or correct the port name.
