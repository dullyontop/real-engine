# RE4310: Streaming job cancelled

A streamed cell was being generated in the background, and the request was
cancelled before the job finished. This happens when the cell is no longer
wanted (the focus turned away or moved on), when its source's graph,
parameters or seed changed (a new request replaces it), or when the world
closes. The job stops before its next level of nodes, and its result is
dropped. Nothing needs fixing: this code only appears in an evaluation report
of a cancelled job.

## Example

```text
error[RE4310]: evaluation of `world` was cancelled
```

## How to fix it

Nothing is wrong. If cells are cancelled and requested again often, raise
`[stream] unload_margin`, so that a focus moving back and forth does not keep
leaving and re-entering the load radius.
