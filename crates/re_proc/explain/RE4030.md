# RE4030: Combined fields cover different areas

`field.combine` pairs its two fields sample by sample by normalised
position: `b` is resampled onto `a`'s grid as if both covered the same
square. When they do not (a different size, cell or position), `b` is
stretched or squeezed over `a`, so a hill or a road in `b` lands somewhere
else than where it is in the world. This is a warning: the node still
combines the fields, as it always has.

Fields that cover the same square at different cells are resampled
correctly and give no warning. A `terrain.island_mask` field is made to be
stretched (it is relative to the field it masks), so it gives no warning
either.

## Example

```text
warning[RE4030]: node `land` (field.combine): `a` covers 190.5 m from (-95.25, -95.25) and `b` 254 m from (-127, -127): `b` is stretched over `a` by normalised position, not matched by world position
```

## How to fix it

Give both fields the same extent: the same `size × cell` (samples per side
times metres between them) and the same centre. `graph.report` shows each
node's output size.
