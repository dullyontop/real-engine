# RE4021: Bake failed

`proc.bake` could not turn a procedural source's output into authored
entities. Nothing changed. The message says why: the entity is not a
procedural source, it has no generated output yet, a key in `keys` is not in
its output, a chosen key sits under a generated parent that is not baked, or a
derived mesh or heightfield could not be written under `assets/baked/`.

## Example

```text
error[RE4021]: `crates/7/lid` is generated under `crates/7`, which is not baked
  = hint: bake `crates/7` too, or the whole source
```

## How to fix it

Follow the hint: regenerate the source first, pick keys from its output
(`query` lists the generated entities), bake the parent as well, or make the
project folder writable.
