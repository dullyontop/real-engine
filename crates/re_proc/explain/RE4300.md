# RE4300: Invalid [stream] settings

The `[stream]` section of `real.toml` has a key the engine does not know, or a
value outside its range. World streaming (ADR-0042) reads these settings when
the project opens.

| key | default | range |
|---|---|---|
| `cell_size` | 256.0 | 1 to 65536 metres per cell side |
| `radius` | 768.0 | 0 or more metres |
| `radius_ahead` | 1280.0 | at least `radius` |
| `unload_margin` | 128.0 | 0 or more metres |
| `memory_mb` | 1024 | at least 1 |
| `workers` | 0 | 0 (pool threads − 1) to 256 |
| `delay_ticks` | 30 | 0 to 3600 |
| `apply_entities` | 400 | at least 1 |
| `apply_chunks` | 8 | at least 1 |
| `terrain_view` | 6000.0 | 0 or more metres |
| `physics_radius` | 256.0 | 0 or more metres |
| `origin_grid` | 1024.0 | at least 1 metre |
| `origin_shift` | 2048.0 | at least `origin_grid` |

## Example

```text
error[RE4300]: [stream] radius_ahead: 500 is less than radius (768)
```

## How to fix it

Correct the key or the value that the message names. A key you do not need
can be left out, and its default applies.
