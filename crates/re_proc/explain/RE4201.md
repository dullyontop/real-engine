# RE4201: Unknown graph param

Something names a graph param that the graph does not declare:

- a node param bound with `{"$param": "<name>"}` (an error: the graph does
  not load);
- `graph.set_param { source, param }` without a `node` (the command is
  refused);
- a value stored for a source under `"$graph"` in `GraphSource.params` (a
  warning: the value is ignored). This usually means the graph's param was
  renamed or removed after the value was set.

## Example

```text
error[RE4201]: graph `island`: node `h`'s param `height` is bound to `hieght`, which the graph does not declare (did you mean `height`?)
```

## How to fix it

Bind the node param to a declared param, or declare the missing one with
`graph.declare_param`. For a stored value, set the right param with
`graph.set_param`, or clear the old one with a null value.
