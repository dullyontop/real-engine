# RE4202: Graph param value refused

A value for a graph param does not fit its declaration: it has the wrong
type (a string for a `number`, three numbers for a `vec2`), it is outside
`min` and `max`, it is not one of an `enum`'s `values`, or a `file` path is
not a project path or does not end with one of the param's `extensions`.

`graph.set_param` refuses such a value. A value stored for a source that no
longer fits, because the graph's declaration changed, is skipped with a
warning and the param's default is used.

The same code reports a bound param that has no value at all: a node kind's
param without a default, used where no value is given for it.

## Example

```text
error[RE4202]: graph param `height`: 500 is outside 0 to 400
```

## How to fix it

Give a value of the param's type inside its range (`graph.params` lists each
param with its type, range and default), or change the declaration with
`graph.declare_param`.
