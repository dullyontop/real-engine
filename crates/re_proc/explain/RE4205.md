# RE4205: Invalid graph input or output declaration

A graph file's `inputs` or `outputs` (graph file version 2, ADR-0061 §4)
declare a port that cannot work: a name that is not letters, digits and
`_`, a name used twice on the same side, a type that is not a port type
(`field`, `mesh`, `points`, `fragment`, `shapes`, `path`, ...), an input of
type `fragment`, or `required` on an output. Inputs exist only on node kinds,
so a graph without a `kind` block cannot declare them.

## Example

```text
error[RE4205]: graph `island`: output `ground` has type `feild`, which is not a port type (did you mean `field`?)
```

## How to fix it

Correct the declaration in the graph file. `describe` lists the port types
each node kind takes and makes.
