# RE4031: Builder nodes without explicit ids

A builder script (`scripts/tools/*.luau`) made nodes without giving them
ids, so they are numbered by position: `n1`, `n2`, and so on. A node's id
decides its seed and is what overrides and moved or replaced entities name,
so inserting or removing a node renumbers every later one: their random
results change and their overrides no longer find them. This is a note:
the graph is generated as it is.

## Example

```text
note[RE4031]: builder `scripts/tools/island_graph.luau`: 3 nodes have ids from their position (`n1`, `n2`, `n4`)
```

## How to fix it

Give each node an id as the fourth argument of the builder call, as in
`g:node("scatter.poisson", { radius = 6 }, { field = land }, "trees")`.
Choose ids for what the nodes are, so they stay the same as the script
grows.
