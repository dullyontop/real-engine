# RE4090: Not a builder source

`proc.convert_builder { source }` turns a procedural source whose graph a
builder script makes (`GraphSource.builder`, a Luau script run in the `tools`
context) into one that reads a graph file. It was given a source whose graph
no builder makes: the source reads a graph file already (`GraphSource.graph`
is set, and a graph file wins over a builder), or it has no builder script.

Nothing changes.

## Example

```text
error[RE4090]: `island` is not a builder source: it reads the graph file graphs/island.graph.json
  --> entity `island`
```

## How to fix it

- A source that reads a graph file is edited on the node canvas, or with the
  `graph.*` commands, already: there is nothing to convert.
- To convert a source, pick one with `GraphSource.builder` set and
  `GraphSource.graph` empty: `query {"with": ["GraphSource"]}` lists the
  sources with their fields.
