# RE7020: Invalid asset sidecar

An asset's `.meta.json` sidecar is not valid. The sidecar holds the asset's
stable id and import settings:

```json
{ "version": 1, "uuid": "0b6d3f9e-7f5c-4c55-9a43-2f4b6b0e3c11", "settings": {} }
```

Textures read one setting, `color_space`: `"srgb"` (the default) or
`"linear"` (normal and data maps).

## Example

```text
error[RE7020]: invalid asset sidecar: invalid character: expected an optional prefix of `urn:uuid:` followed by [0-9a-fA-F-], found `z` at 1 at line 1 column 40
  --> assets/textures/rock.png.meta.json:1:40
```

## How to fix it

Fix the JSON. Deleting the sidecar also works, but the asset then gets a new
id, and scenes or materials that refer to the old id must be updated.
