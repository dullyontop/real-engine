# RE7001: Asset file cannot be read

An asset file (or a sidecar or material file) could not be read: it does not
exist, or the process lacks permission.

## Example

```text
error[RE7001]: cannot read `assets/models/tree.glb`: No such file or directory (os error 2)
  --> assets/models/tree.glb
```

## How to fix it

Check the path. Asset paths are relative to the project root and use `/` on
every platform.
