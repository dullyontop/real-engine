# RE7021: Asset file cannot be written

A file the asset system writes could not be written: a new `.meta.json`
sidecar, or a processed-asset cache entry under `.real/cache/`. The directory
may be read-only or the disk full.

## Example

```text
error[RE7021]: cannot write `assets/models/tree.glb.meta.json`: Permission denied (os error 13)
```

## How to fix it

Make the project directory writable. Cache write failures only slow loading
down; sidecar write failures stop the import, because the id must be stable.
