# RE7062: Joint names are not unique

A warning: a skin joint shares its name with another node of the glTF file.
Clips and animation graphs find joints by name, so each joint with that name is
renamed `<name>#<node index>`. Clips in the same file follow the rename, but
clips from other files and graph masks that use the plain name will not find
the joint.

## Example

```text
warning[RE7062]: several nodes are called `Bone`; its joints are renamed `Bone#<node index>`
  --> assets/models/hero.glb
```

## How to fix it

Give every joint (bone) a unique name in the modelling tool and re-export.
