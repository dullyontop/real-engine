# RE7063: Skinned mesh without weights

A warning: a node uses a skin, but its mesh has no `JOINTS_0` and `WEIGHTS_0`
attributes, so nothing ties its vertices to joints. The mesh is drawn as a
static mesh instead.

## Example

```text
warning[RE7063]: mesh `Helmet` is on a skinned node but has no JOINTS_0 and WEIGHTS_0; it is drawn unskinned
  --> assets/models/hero.glb
```

## How to fix it

Weight the mesh to the armature before export (Blender: parent it with automatic
weights), or parent the mesh to a bone instead of giving its node the skin.
