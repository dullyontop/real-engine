# RE7070: Unsupported audio file

An audio file in the project is not one the engine plays. The engine plays
WAV files of 8-, 16-, 24- or 32-bit PCM or 32- or 64-bit float samples, and
Ogg files holding one Vorbis stream, mono or stereo. `real check` and
`real build` read each `.wav` and `.ogg` file's headers and refuse:

- a WAV file without a RIFF `WAVE` header, a `fmt ` chunk or a `data` chunk,
  or whose samples are compressed (ADPCM, µ-law and the like);
- an Ogg file whose stream is not Vorbis (Opus, FLAC, Speex);
- an Ogg file with several streams, chained one after another or multiplexed;
- a file with more than two channels.

`real build` stops on this error, so a packaged game never ships a sound it
cannot play. A game that plays such a file anyway reports `RE7409` when it
does.

## Example

```text
error[RE7070]: `assets/music/theme.ogg` is not an audio file the engine plays: its stream is Opus, not Vorbis
  --> assets/music/theme.ogg
  = hint: the engine plays WAV and Ogg Vorbis, mono or stereo, one stream per file: convert it, for example `ffmpeg -i in.flac -ac 2 -c:a libvorbis out.ogg`
```

## How to fix it

Convert the file to Ogg Vorbis or WAV, mono or stereo. With ffmpeg:
`ffmpeg -i in.opus -ac 2 -c:a libvorbis -q:a 4 out.ogg`. With oggenc, from a
WAV file: `oggenc -q 4 in.wav`. Split a chained Ogg file into one file per
stream.
