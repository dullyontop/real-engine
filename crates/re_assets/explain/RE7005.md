# RE7005: Part of a glTF file was skipped

A warning: part of a glTF file is not supported and was left out. The rest of
the file imported normally. Skipped parts are:

- primitives that are not triangle lists (points, lines, strips, fans);
- primitives whose indices are not whole triangles over their vertices;
- morph-target weight animations (M1 animates node transforms only);
- animation channels without keyframe data.

## Example

```text
warning[RE7005]: mesh `Grass`: Points primitives are not supported; skipped
  --> assets/models/field.glb
```

## How to fix it

Triangulate the mesh on export, and bake morph-target animations if you need
them.
