# RE7041: Unknown asset

An asset id, or a clip reference, does not name an asset that is loaded. Asset
ids are a UUID (from a sidecar) or `derived:<hex>` (a part of another asset,
such as an image inside a glTF file). Clip references are
`<glTF path>#<clip name>`.

## Example

```text
error[RE7041]: `assets/models/door.glb` has no clip named `Open`
  = hint: its clips are: open, close
```

## How to fix it

For clips, use one of the names the hint lists (names are case-sensitive).
For texture ids, load the material or glTF file that refers to the texture
first.
