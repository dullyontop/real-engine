# RE7002: Invalid glTF file

The file is not valid glTF 2.0, or one of its buffers could not be loaded
(a missing `.bin` file next to a `.gltf`, or a buffer shorter than it claims).

## Example

```text
error[RE7002]: invalid glTF: buffer 0: expected 1000 bytes but received 192 bytes
  --> assets/models/tree.glb
```

## How to fix it

Re-export the model as glTF 2.0 (`.glb` keeps everything in one file). For a
`.gltf`, keep its `.bin` and image files next to it with the names it uses.
