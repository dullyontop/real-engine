# RE7004: Mesh has no positions

A glTF mesh primitive has no `POSITION` attribute, so it has no geometry.

## Example

```text
error[RE7004]: mesh `Rock/1` has no POSITION attribute
  --> assets/models/rocks.glb
```

## How to fix it

Re-export the model; every exporter writes positions for real geometry. A
primitive without positions is usually an exporter bug.
