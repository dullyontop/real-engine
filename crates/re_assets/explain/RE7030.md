# RE7030: File watching cannot start

Hot reload could not start watching the project directory. On Linux the
usual cause is the inotify watch limit (one watch per directory).

## Example

```text
error[RE7030]: cannot watch `/home/me/my-game` for changes: OS file watch limit reached
```

## How to fix it

On Linux, raise the limit, for example
`sudo sysctl fs.inotify.max_user_watches=524288`. The engine runs without hot
reload until then.
