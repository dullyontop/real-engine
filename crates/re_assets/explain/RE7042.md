# RE7042: Unsupported asset type

The file's extension has no importer. The asset system imports `.gltf` and
`.glb` models, `.png`, `.jpg` and `.jpeg` textures, and `.material.json`
materials. Audio (`.wav`) is loaded by the audio system, and scripts by the
script runtime.

## Example

```text
error[RE7042]: no importer for `assets/models/tree.fbx`
```

## How to fix it

Convert the file, for example export FBX or OBJ models as glTF 2.0.
