# RE7003: Image cannot be decoded

An image (a texture file, or an image inside a glTF file) could not be
decoded. Textures must be PNG or JPEG; WebP, KTX2 and other formats are not
supported yet.

## Example

```text
error[RE7003]: cannot decode image 0 (`bark`) of `assets/models/tree.glb`: WebP images are not supported
```

## How to fix it

Convert the image to PNG (for colour with alpha, normal and data maps) or JPEG
(for photos without alpha).
