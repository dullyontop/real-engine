# RE7012: Material value out of range

A material value is outside its range: `metallic`, `roughness` and
`alpha_cutoff` are in `[0, 1]`; colours and `emissive_strength` are finite and
not negative.

## Example

```text
error[RE7012]: material `roughness` is 1.5; it must be in [0, 1]
  --> materials/rock.material.json:4:3
```

## How to fix it

Use a value inside the range. For a brighter glow, raise `emissive_strength`
rather than the `emissive` colour.
