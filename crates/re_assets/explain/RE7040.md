# RE7040: Invalid asset path

An asset path must be relative to the project root: not absolute, not empty,
and not leaving the project with `..`. Paths use `/` on every platform.

## Example

```text
error[RE7040]: `../shared/rock.png` is not a project-relative path: it leaves the project
```

## How to fix it

Copy the file into the project and use its path from the project root, for
example `assets/textures/rock.png`.
