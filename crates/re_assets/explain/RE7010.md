# RE7010: Invalid material file

A `*.material.json` file is not valid: it is not JSON, a key is unknown, or a
value has the wrong type. Every key is optional; the keys are `base_color`
(4 numbers), `base_color_texture` (a path), `metallic`, `roughness`,
`metallic_roughness_texture`, `normal_texture`, `emissive` (3 numbers),
`emissive_strength`, `alpha_mode` (`opaque`, `mask` or `blend`),
`alpha_cutoff`, `double_sided` and `unlit`.

## Example

```text
error[RE7010]: invalid material: unknown field `colour`, expected one of ... at line 2 column 10
  --> materials/rock.material.json:2:10
```

## How to fix it

Rename or remove the key, or fix the value type.
