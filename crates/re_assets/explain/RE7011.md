# RE7011: Material texture not found

A material names a texture file that does not exist. Texture paths in a
material are relative to the project root, not to the material file.

## Example

```text
error[RE7011]: material `base_color_texture` names `assets/textures/rok.png`, which does not exist
  --> materials/rock.material.json:3:3
```

## How to fix it

Correct the path, for example `assets/textures/rock.png`, or add the file.
