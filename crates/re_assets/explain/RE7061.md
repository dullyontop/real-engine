# RE7061: More than four joint influences

A warning: some vertices of a skinned mesh are weighted to more than four joints
(through `JOINTS_1` and `WEIGHTS_1`). The engine skins with four influences per
vertex (ADR-0039), so each such vertex keeps its four largest weights, scaled
so they sum to one. The mesh still imports.

## Example

```text
warning[RE7061]: mesh `Body`: 312 vertices have more than four joint influences; each keeps its four largest
  --> assets/models/hero.glb
```

## How to fix it

Limit influences to four per vertex in the modelling tool (Blender: Weights >
Limit Total) and re-export, so you see the result before the engine trims it.
