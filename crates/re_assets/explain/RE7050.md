# RE7050: Hot reload failed

A warning: a loaded asset's file changed, but the new version could not be
imported. The last good version stays loaded, so the game keeps running. The
related diagnostic says what is wrong with the new version.

## Example

```text
warning[RE7050]: `materials/rock.material.json` changed but could not be re-imported; keeping the last good version
  --> materials/rock.material.json
error[RE7010]: invalid material: expected `,` or `}` at line 3 column 5
```

## How to fix it

Fix the problem the related diagnostic names and save again; the asset reloads
on the next change.
