# RE0500: Not a project directory

The directory given to `real` (with `--project DIR`, or the current directory)
has no `real.toml`, so it is not a Real Engine project.

## Example

```text
error[RE0500]: ./my-game is not a project: it has no real.toml
```

## How to fix it

Pass the project directory with `--project DIR`, or create a new project with
`real new DIR`, which writes `real.toml`, an entry scene and the standard folders.
