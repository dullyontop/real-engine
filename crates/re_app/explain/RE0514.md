# RE0514: Project did not boot

`real verify` could not open the project headless, or its warm-up frames failed.
The cause is attached as a related note. Later stages are skipped.

## Example

```text
error[RE0514]: the project did not boot
  note[RE0502]: the entry scene scenes/main.scene.json does not load
```

## How to fix it

Fix the related diagnostic, then run `real run --headless --frames 60` to check
that the project starts.
