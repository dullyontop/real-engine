# RE0512: Verify stage skipped

A `real verify` stage did not run, and the note says why: the build lacks the
feature it needs (the static scan needs `tooling`), the project has nothing for
it to check (no replays), or an earlier stage failed (no boot). A skipped stage
counts as ok.

## Example

```text
note[RE0512]: stage `scan` skipped: the static API scan needs a `real` built with the `tooling` feature
```

## How to fix it

Nothing to fix unless you expected the stage to run; then supply what the note
names.
