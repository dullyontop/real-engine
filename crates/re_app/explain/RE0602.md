# RE0602: Game archive built for another runtime

`game.rpak` records the engine version, the Luau version, the bytecode version
and the compiler options it was built with. The game executable reading it
was built with different ones. Scripts are stored as Luau bytecode, which must
match the VM that loads it, so the runtime refuses the archive rather than run
it.

## Example

```text
error[RE0602]: game.rpak was built for another runtime: engine 0.3.0 (this runtime 0.4.0)
```

## How to fix it

Rebuild the package. The archive and the executable come from one `real build`
and are shipped together; do not mix files from two builds.
