# RE0510: Golden image missing

A replay's screenshot check names a golden image that does not exist for the
backend the run used.

## Example

```text
error[RE0510]: golden tests/goldens/gl/island_600.png does not exist
```

## How to fix it

Run the replay with `real run --headless --replay F --screenshot out.png`,
check the image, and copy it to the golden path for that backend.
