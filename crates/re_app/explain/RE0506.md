# RE0506: Collider source not available

A `Convex`, `Mesh` or `Heightfield` collider names a `source` whose data is not
loaded: the asset path is wrong, the asset failed to import, or the derived key
comes from a procedural node that has not run. The entity gets no body until
the source is available.

## Example

```text
error[RE0506]: the heightfield "derived:9f2c…" named by this collider's `source` is not loaded
  --> entity `island/terrain/0`
```

## How to fix it

Point `Collider.source` at an imported mesh (`assets/rock.glb`) or at the
`derived:` key a procedural node wrote. Box, Sphere and Capsule shapes need no
source.
