# RE0605: No folder for the game's user data

A packaged game keeps its cache, saved data, crash reports and captures in
per-user folders named after `[package] identifier`: under `$XDG_CACHE_HOME`
and `$XDG_DATA_HOME` (by default `~/.cache` and `~/.local/share`) on Linux,
`~/Library/Caches` and `~/Library/Application Support` on macOS, and
`%LOCALAPPDATA%` and `%APPDATA%` on Windows. None could be found from the
environment, or the folder could not be created.

## Example

```text
error[RE0605]: no folder for the game's user data: HOME is not set
```

## How to fix it

Run the game as a user with a home folder, or pass `--data-dir DIR` to keep
everything in `DIR` (for portable installs and tests).
