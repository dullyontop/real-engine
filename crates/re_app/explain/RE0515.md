# RE0515: Replay command failed

A command listed in a replay's `commands` failed when it was dispatched at its
frame. The command's own diagnostics are attached.

## Example

```text
error[RE0515]: replay command "graph.regenerate" at frame 300 failed
  note[RE1200]: no entity with id "isle"
```

## How to fix it

Fix the command's arguments in the replay, or the project so the command
applies.
