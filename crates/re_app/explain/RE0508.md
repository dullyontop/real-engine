# RE0508: Replay is not deterministic

`real verify` runs each replay twice from a fresh start and compares the World's
`state_hash` at the end. Different hashes mean something in the run depends on
more than the replay's input: wall-clock time, unseeded randomness, iteration
over an unordered map, or a script reading external state.

## Example

```text
error[RE0508]: tests/replays/walk.replay.json: two runs ended with different state hashes (3f…, 9a…)
```

## How to fix it

Seed random numbers from the world or the replay seed, avoid wall-clock time in
gameplay, and iterate in a stable order. Re-run with fewer frames to find the
first frame where the runs diverge.
