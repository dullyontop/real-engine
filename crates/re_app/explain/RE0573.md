# RE0573: Save or settings file not read or written

A run that keeps data keeps its save slots in the data folder
(`saves/<slot>.json`: `.real/data/` in development, the player's own folder
in a packaged game, the browser's storage on the web), and the engine could
not read or write one there: the folder is read-only, the disk is full, or
something else holds the path. This is a warning. A slot that could not be
written stays in memory, so the game goes on reading what it saved until the
run ends; a slot that could not be read reads as empty.

## Example

```text
warning[RE0573]: cannot write save slot "slot-1" (/home/ada/game/.real/data/saves/slot-1.json): No space left on device (os error 28); the run goes on with the slot in memory
```

## How to fix it

Free space on the disk, or make the data folder writable. A packaged game
can be given another data folder with `--data-dir`. The game writes the slot
again the next time it saves it.
