# RE0513: Invalid content file

A content file (a scene, prefab, graph or replay) does not parse, has an unknown
key, or does not load. The underlying diagnostic is attached as a related note
when there is one.

## Example

```text
error[RE0513]: prefabs/collectible.prefab.json does not instantiate
  --> prefabs/collectible.prefab.json
  note[RE1001]: unknown component "Colider" (did you mean "Collider"?)
```

## How to fix it

Fix the file at the reported location. Every content file has a JSON Schema in
`schemas/` that editors can use for completion and checking.
