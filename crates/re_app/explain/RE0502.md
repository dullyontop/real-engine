# RE0502: Entry scene failed to load

The scene named by `[project] entry_scene` in `real.toml` could not be read,
does not parse, or does not load into a World. The scene's own diagnostic
(`RE12xx`) is attached as a related note.

## Example

```text
error[RE0502]: the entry scene scenes/main.scene.json does not load
  --> scenes/main.scene.json
  note[RE1205]: entities[3] (id "crate_1"): parent "crates" is not defined before its child
```

## How to fix it

Check that the file exists at the path in `real.toml`, then fix the problem the
related diagnostic names. `real verify` checks every scene file.
