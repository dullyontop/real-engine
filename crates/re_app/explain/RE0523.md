# RE0523: Procedural graph unavailable

A procedural source (an entity with `GraphSource` and `Procedural`) names a
graph that could not be made: its `graph` file is missing or is not a valid
`real-engine/graph` document, or its `builder` script (run in the `tools`
context) failed or did not return a graph. The source generates nothing (or
keeps its previous output after a reload).

## Example

```text
error[RE0523]: the builder scripts/tools/island_graph.luau did not return a graph
  --> scripts/tools/island_graph.luau
```

## How to fix it

Check the related diagnostics: they carry the script error or the graph
validation error. A builder must `return` the graph made with `proc.graph(...)`.
`real explain RE4000` describes graph documents.
