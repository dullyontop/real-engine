# RE0521: Window failed

`real run` without `--headless` could not open a window or a GPU surface for it:
there is no display, or no GPU adapter can present to it.

## Example

```text
error[RE0521]: cannot create the event loop (no display?): neither WAYLAND_DISPLAY nor DISPLAY is set
```

## How to fix it

Run with `--headless`, or under a virtual display:
`xvfb-run -a -s "-screen 0 1280x720x24" real run --frames 300 --exit-after`. Set
`RE_BACKENDS=gl` to try another graphics API.
