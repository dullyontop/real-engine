# RE0501: Invalid real.toml

`real.toml` could not be read, has a TOML syntax error, an unknown key, a value
of the wrong type or a value out of range (for example `[sim] fixed_hz = 0`).
The same code is used when the `[input]` bindings name keys or buttons that do
not exist; the input diagnostics are attached as related notes.

## Example

```text
error[RE0501]: invalid real.toml: unknown field `bogus`, expected one of `fixed_hz`, `max_steps_per_frame`, `gravity`
  --> real.toml:5:1
```

## How to fix it

Fix the key or value at the reported line. The sections and their keys are
`[project]`, `[sim]`, `[render]`, `[scripts]`, `[input]` and `[verify]`
(ARCHITECTURE §8). `real new` writes a complete example.
