# RE0606: A packaged game cannot write project files

Only a development run writes into the project: creating a missing asset
sidecar (`.meta.json`), following a rename, or saving the scene. A packaged
game reads its files from `game.rpak` and may be installed where it cannot
write, so it refuses these writes.

## Example

```text
error[RE0606]: cannot write the scene back to scenes/main.scene.json: a packaged game does not write project files
```

## How to fix it

Run `real build` again: it creates missing sidecars in the project before
packing and lists them in its report, so they can be committed. Saved game
data belongs in the data services (`DataStoreService`), which write to the
game's per-user folder.
