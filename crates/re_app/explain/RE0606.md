# RE0606: A packaged game cannot write project files

Only a development run writes into the project: saving the scene, or creating
an animation graph file with `animgraph.create`. A packaged game reads its
files from `game.rpak` and may be installed where it cannot write, so it
refuses these writes. (A packaged game that finds an asset without its sidecar
reports `RE7021`.)

## Example

```text
error[RE0606]: cannot write the scene back to scenes/main.scene.json: a packaged game does not write project files
```

## How to fix it

Make the change in the project, in a development run (`real run` or
`real editor`), then run `real build` again. Saved game data belongs in the
data services (`DataStoreService`), which write to the game's per-user folder.
