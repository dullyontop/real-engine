# RE0516: Screenshot cannot be taken

A screenshot was asked for (by `real run --screenshot`, the `screenshot` command,
`play.run` or a script) but no frame could be captured: the GPU could not be
opened, or the capture could not be written. The `screenshot` command also
refuses a path that is not inside the project or does not end in `.png`, so
that it never replaces another kind of file.

## Example

```text
error[RE0516]: cannot write the screenshot out/f600.png: No such file or directory
error[RE0516]: the screenshot path "real.toml" does not end in `.png`
```

## How to fix it

Check that a GPU or a software rasteriser (lavapipe, llvmpipe) is available and
that the output directory exists. Name a `.png` file inside the project, or
leave the `screenshot` command's `path` out to write one under `.real/out/`.
