# RE0518: Scene could not be saved

After a command changed the World, the scene could not be written back to the
entry scene file. The change is applied in memory but not on disk.

## Example

```text
warning[RE0518]: cannot write the scene back to scenes/main.scene.json: Permission denied
```

## How to fix it

Check that the file and its directory are writable, then repeat the edit (or
run `undo` and `redo`) so the scene is written again.
