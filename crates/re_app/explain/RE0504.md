# RE0504: Invalid argument to a runtime service

A script passed a value a runtime service cannot use: a non-finite vector, a
negative volume, an empty clip or source id, a screenshot path outside the
project, or an impulse for a body that is not dynamic.

## Example

```text
error[RE0504]: volume -1 must be 0 or more
```

## How to fix it

Check the value the script passes. Screenshot paths are relative to the project
and may not contain `..`.
