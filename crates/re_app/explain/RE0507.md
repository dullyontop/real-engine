# RE0507: Replay cannot be played

A replay file could not be read, or it does not match the project: it names an
action that `real.toml [input]` does not define, uses a button action as an axis,
or lists inputs out of frame order. The input crate's diagnostics are attached.

## Example

```text
error[RE0507]: the replay does not match this project's actions
  note[RE7205]: input entry 2 (frame 30, action `mvoe`): unknown action
```

## How to fix it

Fix the replay, or add the action to `[input]`. Replays store actions, not
device events, so they survive key rebinding.
