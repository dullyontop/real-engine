# RE0621: The canvas stopped drawing

The page's WebGPU surface reported a validation error while presenting a frame,
so the web build stopped drawing. This points at a browser or driver problem, or
at an engine bug.

## Example

```text
error[RE0621]: the canvas's WebGPU surface reported a validation error
```

## How to fix it

Reload the page. If it happens again, open the browser's developer console,
copy the errors above this one, and report them with the browser's version.
