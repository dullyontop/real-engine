# RE0603: File found only by ignoring case

The game asked for a file under a spelling that differs from the one stored in
`game.rpak` only by upper and lower case, such as `Assets/Rock.glb` for
`assets/rock.glb`. Development runs on Windows and macOS ignore case, so the
packaged game serves the file anyway and warns. `real verify --package`
treats this as an error, so it is fixed before the game ships.

## Example

```text
warning[RE0603]: `assets/Rock.glb` is stored in the package as `assets/rock.glb`; the spellings differ only by case
```

## How to fix it

Use the file's exact spelling where it is referenced (a scene, a material, a
script's `require`), or rename the file to match.
