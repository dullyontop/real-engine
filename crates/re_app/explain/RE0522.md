# RE0522: Animation target missing

An `AnimPlayer` plays a clip that animates a glTF node, but no entity at or below
the player has that `name`, so that part of the clip has no effect. A clip with a
single target animates the player entity itself.

## Example

```text
warning[RE0522]: clip `assets/door.glb#open` animates `Hinge`, but no entity under `door` is named `Hinge`
```

## How to fix it

Name the entity that should move after the glTF node (the message names it), or
put the `AnimPlayer` on that entity's parent.
