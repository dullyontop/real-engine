# RE0600: Unreadable game archive

A packaged game reads its files from `game.rpak`, beside the executable (in
`Contents/Resources/` of a macOS app). This archive could not be read: it does
not start like a game archive, it is shorter than its header says, or its
index is damaged. A download or copy that stopped early is the usual cause.

## Example

```text
error[RE0600]: game.rpak is not a readable game archive: its index is not where the header says (truncated?)
```

## How to fix it

Reinstall or copy the game again. If you made the package, run `real build`
again and ship the whole output folder.
