# RE0511: Frame time over budget

The PerfReport's frame-time 95th percentile is above the budget in
`real.toml [verify.perf] frame_ms_p95`. In M1 this is a warning, not an error,
because CI renders in software.

## Example

```text
warning[RE0511]: frame time p95 is 41.20 ms, over the 33.00 ms budget
```

## How to fix it

Look at the per-phase times in the report to find the expensive phase, or raise
the budget if the machine is slower than the one the budget was set for.
