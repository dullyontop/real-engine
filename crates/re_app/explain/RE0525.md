# RE0525: Regeneration broke the game

`real verify` replays each `tests/replays/*.replay.json` and watches every
regeneration of the terrain (a `graph.regenerate` command, or a script's
`proc.regenerate`). After one, the runtime promises that:

- every character keeps its `Entity` (scripts holding it keep working);
- every character stands on the new ground within 60 frames (it was
  re-grounded, not dropped through the terrain);
- items a game script removed (collected) stay removed.

This error says which promise broke, and at which frame.

## Example

```text
error[RE0525]: frame 312: after the regeneration at frame 251, hero did not stand on the ground
  --> tests/replays/regenerate.replay.json
```

## How to fix it

- A character that does not land: keep it over the generated terrain, and
  check `RE0524` warnings in the same run.
- A lost `Entity`: do not give characters a generated id (keep them out of the
  graph's output) and do not respawn them in scripts after regenerating.
- A collected item that came back: remove it with `entity:destroy()` in the
  game script, which suppresses its generated key for the session.
