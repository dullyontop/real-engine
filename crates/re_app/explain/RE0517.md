# RE0517: Asset import failed

The `asset.import` command could not bring a file into the project: the source
file does not exist or cannot be read, the destination is outside `assets/`,
the destination already exists, or the file or its `.meta.json` sidecar cannot
be written.

## Example

```text
error[RE0517]: cannot import /tmp/rock.glb: No such file or directory
```

## How to fix it

Pass an existing file as `source` and a new path under `assets/` as `dest` (or
leave `dest` out to use `assets/<file name>`). Pass `"overwrite": true` to
replace an existing asset; its sidecar, and so its asset id, is kept.
