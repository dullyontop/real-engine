# RE0622: The engine panicked in the browser

The web build hit an internal error (a Rust panic) and stopped. The browser's
console shows the message and where it happened.

## Example

```text
RE0622 panic: panicked at crates/re_app/src/app.rs:120:9:
index out of bounds: the len is 0 but the index is 0
```

## How to fix it

This is an engine bug. Reload the page to start again, and report the console
message, the browser's version and what you were doing.
