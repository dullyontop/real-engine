# RE0572: Invalid [scenes]

`[scenes]` in `real.toml` maps scene names to scene files, and something in
it is wrong:

- a name that is not 1 to 64 characters from `a`–`z`, `0`–`9`, `_` and `-`;
- a path that is not a project path ending in `.scene.json`;
- two names for one scene file;
- a listed name that the entry scene already has: the entry scene is named
  after its file (`main` for `scenes/main.scene.json`) unless `[scenes]` names
  its path.

## Example

```text
error[RE0572]: [scenes] names "level1" and "start" are the same scene ("scenes/level1.scene.json"); keep one
  --> real.toml
```

## How to fix it

```toml
[project]
entry_scene = "scenes/title.scene.json"

[scenes]
title = "scenes/title.scene.json"
town = "scenes/town.scene.json"
```
