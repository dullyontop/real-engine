# RE0571: Scene changes differ from the replay's

A replay lists the scene changes its run made (`scenes`: each switch, load,
unload and restart with the frame that applied it), and this run made other
ones: another scene, another frame, a change the replay does not list, or a
listed change that never happened. The message names the first difference.
Replays only check scene changes; scripts make them.

## Example

```text
error[RE0571]: the replay expects `switch: town` at frame 120, but this run applied `switch: harbour` at frame 120
```

## How to fix it

A script now changes scenes differently from when the replay was recorded.
If the change is intended, record the replay again
(`real run --headless --replay old.json --record new.json`); otherwise find
what changed in the scripts that call `scene.switch`, `scene.load` and
`scene.unload`.
