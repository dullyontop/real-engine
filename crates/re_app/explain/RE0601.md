# RE0601: Damaged entry in a game archive

Every file in `game.rpak` carries a hash of its contents, checked on each read.
This file's bytes do not match, so the archive was changed or damaged after
`real build` wrote it. The game reports the file as unreadable instead of
running with wrong data.

## Example

```text
error[RE0601]: `scripts/main.luau` in game.rpak is damaged: its contents do not match the archive's hash
```

## How to fix it

Reinstall or copy the game again, or rebuild it with `real build`. The hashes
detect damage; they are not a signature.
