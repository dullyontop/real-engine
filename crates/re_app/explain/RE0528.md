# RE0528: Open document changed on disk

A project file that is open in the World as a document (a graph file being
edited in the editor or by an agent, ADR-0044) changed on disk, and the engine
could not take the new file:

- the open document has unsaved edits, so the in-memory version is kept, and
  the next save overwrites the file with it; or
- the file was removed, or no longer parses or validates, so the open document
  is kept as it was.

An open document without unsaved edits whose file changed is simply reloaded
(its undo history is dropped, since it applied to the old content).

## Example

```text
warning[RE0528]: graphs/island.graph.json changed on disk while it has unsaved edits; saving will overwrite the file
```

## How to fix it

Decide which version to keep. To keep the edits, save; the file on disk is
replaced. To take the file, discard the edits (undo them, or reopen the
document) and touch the file again so it is reloaded. Fix a file that does not
parse or validate; `real check` and `graph.schema.json` show what it must
contain.
