# RE0526: A script waits forever

At the end of the boot run of `real verify`, a script in a `[compat]` project
was still waiting in `WaitForChild` for an instance that never appeared. The
diagnostic names the context (`server` or `client`), what the call waits for and
the waiting script.

## Example

```text
error[RE0526]: a client script still waits in WaitForChild("Remotes") after 600 frames
  = note: waiting: Players.Player1.PlayerScripts.Hud
```

## How to fix it

Create the instance the script waits for (in the scene, or from a server
script that runs at start), fix a misspelled name, or pass a timeout
(`WaitForChild("Remotes", 5)`) and handle `nil` when the instance is optional.
`real run --headless --frames 600 --json` lists the waits under
`compat.stuck_yields`.
