# RE0620: No WebGPU in this browser

The web build asked the browser for a WebGPU adapter and device for the page's
canvas and got none. The game cannot draw.

## Example

```text
error[RE0620]: the browser gave no WebGPU device for the canvas
  = hint: use a current Chrome or Edge, served over HTTPS or from localhost
```

## How to fix it

- Use a browser with WebGPU turned on: current Chrome and Edge on Windows,
  macOS and ChromeOS have it. Firefox and Safari are not supported yet.
- Serve the page over HTTPS or from `localhost`; browsers offer WebGPU only in a
  secure context.
- Check that hardware acceleration is on in the browser's settings and that the
  GPU is not blocklisted (`chrome://gpu`).
