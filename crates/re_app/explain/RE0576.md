# RE0576: Invalid [saves] or [settings]

`[saves]` or `[settings]` in `real.toml` has a value the engine cannot use.
For `[saves]`, `version` is the game's data version: a whole number from 1,
raised each time the shape of the saved data changes (with a `save.migrate`
step from the version before).

## Example

```text
error[RE0576]: [saves] version is 0; data versions start at 1
  --> real.toml
```

## How to fix it

```toml
[saves]
version = 2        # the data version this build writes
mode = "persist"   # or "session": never keep saves past the run
```
