# RE0604: No game archive beside the game

A game executable made by `real build` runs the game in `game.rpak`, which
must sit beside it (in `Contents/Resources/` of a macOS app). There is no such
file, so there is no game to run.

## Example

```text
error[RE0604]: there is no game.rpak beside /opt/island/island
```

## How to fix it

Ship the whole folder `real build` writes, not the executable alone. To run a
project during development, use `real run`.
