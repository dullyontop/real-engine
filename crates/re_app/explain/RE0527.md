# RE0527: A play.run step failed

A step of `play.run` could not run. `add_player`, `say` and `invoke` need a
`[compat]` project (`real.toml`), and the `path` of an `invoke` or `dump_tree`
step must name an instance, as dotted names from `game`
(`ServerStorage.Hooks.Score`). The play goes on with the next step; the failed
step's result has `ok: false` and this diagnostic.

## Example

```text
error[RE0527]: no instance named "Hooks" under game.ServerStorage
```

## How to fix it

Check the path against `scene.dump_tree`, which lists the instances by name,
or add `[compat] api = "roblox"` to `real.toml` for a Roblox-style project.
Errors the game raised while the step ran (a `BindableFunction` handler that
fails, a player that cannot join) have their own codes: `RE9301` and `RE9302`.
