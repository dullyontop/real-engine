# RE0505: Physics field out of range

A `Collider` or `CharacterController` field has a value physics cannot
represent. `layer` must be 0 to 65535 (an object layer) and `groups` must be 0
to 4294967295 (a 32-bit mask). The value is reported, not truncated, and the
entity gets no body until it is fixed.

## Example

```text
error[RE0505]: Collider.groups = -1 is out of range (0 to 4294967295)
  --> entity `crate_1`
```

## How to fix it

Use a value in range. `groups` is a bit mask: bit g is group g, so group 0 is 1,
group 1 is 2 and groups 0 and 1 together are 3.
