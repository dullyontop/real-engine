# RE7701: UI style not in the theme

A `UiNode.style` names a style that the node's theme does not have. The node
is drawn with its components' own fields. It is reported once per name.

## Example

```text
warning[RE7701]: no style `buton` in the theme; the node keeps its own look
  --> entity menu/play
```

## How to fix it

Check the spelling. The engine's default theme has `panel`, `title`,
`heading`, `body`, `button`, `button.primary`, `bar`, `input`, `list` and
`row`; a project's `[ui] theme` file adds its own, and a `UiRoot.theme`
replaces the project's theme for that root.
