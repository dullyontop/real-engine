# RE7700: Theme file invalid

A theme file (`*.theme.json`, the project's `[ui] theme` or a `UiRoot`'s
`theme`) cannot be used: it is not JSON, it does not match
`schemas/theme.schema.json` (an unknown key, a wrong type, a colour that is
not 3 or 4 numbers), its `format` is not `real-engine/theme` or its `version`
is not 1, or a style's `base` names no style that the file or a theme under
it defines, or leads back to the style itself. The game keeps the theme it
had: at start, the one under it (the engine's default theme in place of the
project's, the project's in place of a root's). A development run reads a
changed theme file again.

## Example

```text
error[RE7700]: style `button.wide` extends `buton`, which neither its theme nor one under it has
  --> ui/game.theme.json
```

## How to fix it

Point the editor at `schemas/theme.schema.json` (`"$schema"` in the file) to
see each problem as you type. A style's fields are named as the components
name them: `panel` takes `UiPanel`'s visual fields, `text` `UiText`'s, `bar`
`UiBar`'s and `scroll` `UiScroll`'s. A `base` names a style of the same file
or of a theme under it (the engine's default theme, and for a root's theme the
project's); to extend the style of the same name under it, give the style its
own name as its base.
