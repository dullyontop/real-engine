# RE7702: UI field hidden by its style

A node's component field differs from its default, but the node's style sets
that field, so the style's value shows instead. It is reported in
development runs, once per node and field.

## Example

```text
warning[RE7702]: `UiPanel.color` is set, but style `button` sets it too, so the value does not show
  --> entity menu/play
```

## How to fix it

Put the look in the theme: change the style, or give the node a style of its
own that extends it (`"base": "button"`). To change the field on this node
alone, clear its `UiNode.style`. To fade a styled node, use
`UiNode.opacity`, which no style sets.
